# 물리학 커리큘럼 v5: 일반물리 전 범위 + 전자기학 심화

> **대목적:** 자연을 지배하는 몇 개의 법칙으로, 물체의 움직임을 숫자로 예측하는 사람이 된다. 공대·자연대 1학년 일반물리학 전 범위 + 전자기학 일부 심화까지.
> **수단:** 역학은 대수로 직관을 쌓고, E&M 은 처음부터 미적분으로 배운다.
> **원칙:** 그림을 그리고, 식을 세우고, 숫자를 넣는다. 모든 세션은 이 3단계로 구성.
> **규모:** 54세션, 약 64시간. 대학 일반물리학 I·II + 전자기학 입문.
> **v5 변경:** 전송선·도파관·안테나·자성체 추가. 결합진동·고체물리·레이저·초전도 추가.

## 왜 E&M 은 처음부터 미적분으로 하는가

```
역사적 사실:
  쿨롱(1785) → 비오-사바르(1820) → 앙페르(1820) → 패러데이(1831)
  → 맥스웰(1865): 4개 방정식으로 전기·자기·빛 통합

  이 모든 발견은 미적분 위에서 이루어졌다.
  ∮E·dA, ∮B·dL, dΦ/dt — 적분과 미분 없이는 말할 수 없는 세계.

교육적 현실:
  "대수-only E&M" 은 존재하지 않는다.
  전하 연속분포(적분), 가우스 법칙(면적분), 전위(선적분),
  패러데이(시간미분) — 전부 미적분 개념이다.

  대수로 가르치면:
  "공식을 외우세요. 왜 그런지는 묻지 마세요."
  → E&M 이 가장 어려운 과목이 되는 이유.

  미적분으로 가르치면:
  "쿨롱에서 출발해서, 적분하면 가우스가 나오고,
   미분하면 전위가 나오고, 전류가 시간에 따라 변하면 자기장이 생긴다."
  → 하나의 사슬로 연결된다.

반면 역학은:
  $F=ma$, $W=Fd$, $E_k=\frac{1}{2}mv^2$ — 대수만으로도
  충분히 많은 현상을 예측할 수 있다.
  미적분은 "그 공식들이 왜 그런지"를 나중에 알려준다.
  인지부하를 줄이고 물리적 직관을 먼저 쌓는 게 효과적이다.
```

## 이 커리큘럼의 철학

```
물리학은 종이 위에서 세상을 숫자로 예측하는 기술이다.

시작은 항상 그림이다 — 자유물체도, 광선 추적, 회로도.
그다음 식을 세운다 — 뉴턴, 에너지, 운동량, 맥스웰.
마지막으로 숫자를 넣는다 — 단위를 맞추고 계산한다.

Phase 1: 역학 — 대수로 물리 감각을 쌓는다.
Phase 2: 역학 공식을 미적분으로 다시 증명한다.
Phase 3: 전기·자기 — 처음부터 미적분으로, 전송선·도파관·안테나까지.
Phase 4: 진동·파동·유체·열·재료 — 일상의 물리.
Phase 5: 빛·현대물리·고체·초전도 — 20-21세기 물리.

54개 예측 도구의 분해 매뉴얼.
이 도구들을 손에 쥐고, 당신이 예측하고 싶은 현상을 종이 위에 풀어내라.
```
