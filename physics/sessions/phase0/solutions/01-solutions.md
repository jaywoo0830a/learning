# Session 01 — Solutions

## 🔧 Basic Drills

**1.** $\vec{a}+\vec{b} = (2, 2, 7)$, $|\vec{a}+\vec{b}| = \sqrt{4 + 4 + 49} = \sqrt{57}$

**2.** $F_x = 15\cos 45^\circ = \frac{15}{\sqrt{2}} \approx 10.6\text{ N}$, $F_y = 15\sin 45^\circ = \frac{15}{\sqrt{2}} \approx 10.6\text{ N}$

**3.** $\vec{F}_{\text{net}} = (8, 4)$, $|\vec{F}_{\text{net}}| = \sqrt{64 + 16} = \sqrt{80} \approx 8.94\text{ N}$, direction $\tan^{-1}(4/8) = \tan^{-1}(0.5) \approx 26.6^\circ$ above the $+x$ axis.

**4.** $\vec{a}\cdot\vec{b} = 2\cdot4 + 3\cdot(-1) = 8 - 3 = 5$. Positive → angle is less than $90^\circ$.

**5.** $\vec{\tau} = \vec{r}\times\vec{F} = (0,2,0)\times(3,0,0) = (0,0,-6)\text{ N·m}$. Magnitude = $6\text{ N·m}$, direction = $-z$ (into the page, by right-hand rule).

## 🔥 Advanced Drills

**1.** Wind: northwest = $(-15/\sqrt{2},\; 15/\sqrt{2})$ (since $\cos 45^\circ=\sin 45^\circ=1/\sqrt{2}$). Plane: $(0, 80)$. Net: $(-10.6,\; 90.6)$. Speed: $\sqrt{112.5 + 8210} \approx 91.2\text{ m/s}$. Direction: $\tan^{-1}(90.6/10.6)$ — about $83^\circ$ north of west, or $7^\circ$ west of north.

**2.** $\vec{n} = \vec{a}\times\vec{b} = (2\cdot(-1) - 3\cdot2,\; 3\cdot1 - 2\cdot(-1),\; 2\cdot2 - (-1)\cdot1) = (-2-6,\; 3+2,\; 4+1) = (-8, 5, 5)$. $|\vec{n}| = \sqrt{64+25+25} = \sqrt{114}$. Unit: $\frac{1}{\sqrt{114}}(-8, 5, 5)$.

**3.** $W = \vec{F}\cdot\vec{s} = 2\cdot4 + 3\cdot1 = 8 + 3 = 11\text{ J}$. Projection onto $\vec{n}$: $\frac{\vec{F}\cdot\vec{n}}{|\vec{n}|} = \frac{-6+6}{\sqrt{13}} = 0$. The force is perpendicular to $\vec{n}$.

**4.** Ground velocity: $\vec{v} = (3, 0) + (0, 4) = (3, 4)$. Speed $= 5\text{ m/s}$. Time to cross $= 100/4 = 25\text{ s}$.

**5.** $|\vec{a}| = \sqrt{1+4+4} = 3$, unit vector $= (\frac{1}{3}, \frac{2}{3}, \frac{2}{3})$. $\vec{a}\cdot\vec{b} = 2 - 2 + 4 = 4$, $|\vec{b}| = \sqrt{4+1+4} = 3$. $\cos\theta = \frac{4}{3\cdot3} = \frac{4}{9}$, $\theta \approx 63.6^\circ$.

## 🧠 Intuitional Drills

**1.** Draw the rhombus: two sides of length 10 at $120^\circ$. The short diagonal (net force) also has length **10 N**. (The triangle is equilateral: $120^\circ$ external angle means $60^\circ$ internal angle.)

**2.** $W = |\vec{F}|\cos\theta \cdot d = 10\cos\theta$ per meter. Half of max: $\cos\theta = 1/2 \Rightarrow \theta = 60^\circ$.

**3.** Exactly $5\text{ m/s}$. The 3-4-5 right triangle: $3^2 + 4^2 = 5^2$.

**4.** $\vec{F}_3 = -\vec{F}_1 - \vec{F}_2 = (-5, 0) - (-3, 4) = (-2, -4)$. If you draw $\vec{F}_1$ then $\vec{F}_2$ head-to-tail, the vector from the final head back to the start is $\vec{F}_3$.

**5.** $\vec{a}\cdot\vec{b}=0 \Rightarrow \theta = 90^\circ$ (perpendicular). $\vec{a}\times\vec{b}=0 \Rightarrow \sin\theta=0 \Rightarrow \theta=0^\circ$ or $180^\circ$ (parallel/antiparallel).
