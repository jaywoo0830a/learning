# Physics Problem Sets — Deep Mixed Practice, 5/Day

> Concept-based Regular Physics ("SAT Regular Physics") problems that deliberately **mix topics within each domain** — physics is thinking in wholes, not in chapters.

## Structure

```
physics/problems/
├── mechanics/1.md   ─┐
├── mechanics/2.md    │  one file = one day = 5 problems,
├── mechanics/3.md   ─┘  topics mixed inside each day
├── em/1.md ... 3.md     Electricity & Magnetism (mixed)
└── others/1.md ... 3.md Waves & Optics · Heat & Thermo · Modern · Measurement (mixed)
```

## Rules of Engagement

- **No calculus.** Every problem is solvable algebraically with Regular Physics tools (kinematic equations, $F=ma$, work–energy, momentum, conservation laws, Ohm's law, etc.).
- Draw a **diagram first**. Almost every deep mistake is a diagram mistake.
- **Name the principle** before each step ("conservation of energy", "Newton's 2nd law, radial direction", "Lenz's law").
- Keep **units on every number**; check units at the end of every part.
- Solve symbolically where possible, then plug numbers at the end.
- Answers are **collapsed** at the bottom of each file — solve fully before peeking.

## Suggested Rotation

- Day 1: `mechanics/1.md` → Day 2: `em/1.md` → Day 3: `others/1.md` → Day 4: `mechanics/2.md` → ... to keep all three pillars warm.
- Aim for ~90 min per day: 5 problems, each with parts (a)–(d).
