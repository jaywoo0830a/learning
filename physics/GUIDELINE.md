# 물리학 교재 작성 가이드라인 v1

> 모든 세션은 이 문서의 규칙을 따른다. v1: 예시-우선, 계산-절차 중심으로 통일.
> **핵심 원칙:** "종이 위에 무엇을 그리고, 어떤 숫자를 어디에 넣는지"로만 설명한다. 추상 설명 절대 금지.

---

## 1. 핵심 원칙: 예시 → 방법 추출 → 연습 → 용어

```
[구체적 예시 다수] → [방법 추출 ("방금 우리가 한 일")] → [연습] → [용어 (맨 마지막)]
        60%                        15%                    20%           5%
```

- **예시**: 추상적 규칙을 먼저 말하지 않는다. 구체적 사례 4~8개로 시작한다.
- **방법 추출**: "방금 우리가 한 일" 코너에서 예시들의 공통 패턴을 뽑아낸다.
- **용어와 기호는 세션 맨 마지막**에만 등장한다. 그 전까지는 설명하는 말로만 표현한다.
- 세션 제목은 개념명이 아닌 **방법 설명형**. 예: "네 개의 식으로 물체의 움직임 예측하기"

## 2. 물리학 교재의 고유 원칙 — "종이 위 조작법"

```
추상적 설명 → 절대 금지.
"종이 위에 무엇을 그리고, 어느 숫자를 어디에 넣는지"로만 설명 → 허용.
```

### 2-1. 모든 설명은 이 틀을 따른다

"그림 위에 ___ 를 그린다. ___ 방향의 식에 ___ 숫자를 넣는다. 그러면 ___ 가 나온다."

**작성 규칙:**
1. 주어는 항상 **종이 위 위치**: "그림의 왼쪽 화살표", "식의 오른쪽 항", "표의 맨 윗줄"
2. 동사는 항상 **구체적 조작**: "그린다", "넣는다", "나눈다", "곱한다", "비교한다"
3. 추상 기호는 **괄호 안에만** 표기. 본문 주역 금지.
4. 표 컬럼 헤더도 위치 기반 말로: "왼쪽 항", "오른쪽 결과"

### 2-2. 물리 설명 금지 목록

아래 개념들에 대해 **어떤 비유·은유·직관 설명도 하지 않는다.** 오직 계산법만 제시한다.

| 개념 | 금지된 설명 | 허용된 설명 |
|:---:|------|------|
| 힘 | "밀거나 당기는 것", "상호작용" | **자유물체도에 화살표를 그린다. 각 화살표 방향으로 $F=ma$ 식을 쓴다.** |
| 에너지 | "일을 할 수 있는 능력" | **$E_k = \frac{1}{2}mv^2$, $E_p = mgh$. 처음 합 = 나중 합.** |
| 운동량 | "움직임의 양" | **$p=mv$. 충돌 전 $\sum p$ = 충돌 후 $\sum p$.** |
| 엔트로피 | **"무질서도"** | **$\Delta S = Q/T$. $\Delta S > 0$: 비가역.** |
| 전기장 | "전기력을 전달하는 공간의 성질" | **$E = F/q = kQ/r^2$. 점전하에서 거리 $r$ 떨어진 곳의 숫자.** |
| 자기장 | "자기력을 만들어내는 장" | **$F = qvB\sin\theta$. 오른손으로 방향을 잡는다.** |
| 파동 | "에너지를 전달하는 진동" | **$v = f\lambda$. 주기 $T = 1/f$. $y(x,t) = A\sin(kx-\omega t)$.** |
| 광자 | "빛의 입자" | **$E = hf = hc/\lambda$. 문턱 진동수보다 크면 전자가 튀어나온다.** |

### 2-3. 물리 특유의 3단계 문제 풀이 구조

모든 물리 문제는 이 3단계를 거친다. 어떤 주제든 동일한 틀을 적용한다.

```
[1] 그림을 그린다 — 자유물체도, 광선 추적, 회로도, 파면 etc.
[2] 식을 세운다 — 그림에서 읽은 정보를 표준 공식에 대입.
[3] 숫자를 넣는다 — 단위를 통일하고 계산.
```

세션은 항상 이 3단계로 구성한다. "그림 없이 푸는 물리"는 가르치지 않는다.

## 3. 언어적 명료성 원칙

### 3-1. 문장 구조: 동작 → 대상 → 결과

```
[조건이 있다면 먼저] → [무엇을] → [어떻게 한다] → [그러면 무엇이 나온다]
```

| 나쁨 | 좋음 |
|------|------|
| "뉴턴의 제2법칙을 이용하여 가속도를 구할 수 있다" | "자유물체도에서 알짜힘을 찾는다. $a = F/m$에 넣는다. 가속도가 나온다." |
| "에너지 보존을 적용하면 높이를 알 수 있다" | "처음 운동에너지 + 처음 위치에너지를 더한다. 나중 위치에너지와 같다고 놓는다. $h$에 대해 푼다." |
| "운동량이 보존되므로 충돌 후 속도를 계산한다" | "충돌 전 $mv$를 전부 더한다. 충돌 후 $mv$와 같다고 놓는다. 미지수를 푼다." |

핵심: **한 문장 = 동작 하나**. 두 동작은 문장을 나눈다.

### 3-2. 위치 기반 지시: "그림의 어디에 무엇을"

추상 변수명 대신, 시각적·공간적 위치를 가리킨다.

| 나쁨 | 좋음 |
|------|------|
| "$F_N$ = 수직항력" | "바닥에서 물체를 수직으로 밀어올리는 화살표" |
| "$T$ = 장력" | "줄을 따라 물체를 당기는 화살표" |
| "$v_0$ = 초기속도" | "$t=0$일 때의 속도. 문제에 주어진 숫자" |
| "빛의 입사각 = 반사각" | "들어가는 선과 수선 사이 각 = 나가는 선과 수선 사이 각" |

한 번 위치를 정의했으면, 그 세션 안에서는 **같은 표현만** 쓴다.

### 3-3. 어휘 일관성: 하나의 동작 = 하나의 단어

| 동작 | 이 단어만 쓴다 | 이 단어는 안 쓴다 |
|:---:|:---:|------|
| + | "더한다" | 합한다, 합산한다 |
| − | "뺀다" | 감산한다, 차분을 구한다 |
| × | "곱한다" | 승산한다 |
| ÷ | "나눈다" | 제산한다 |
| 대입 | "넣는다" | 대입한다, 치환한다 |
| 그리기 | "그린다" | 작도한다, 스케치한다 |
| 분해 | "쪼갠다" | 성분 분해한다, 벡터 분해한다 |
| 같다고 놓기 | "같다고 놓는다" | 등식으로 설정한다, 방정식을 세운다 |
| 단위 변환 | "고친다" | 환산한다, 변환한다 |

### 3-4. 조건문: 문장 맨 앞에

"만약 ~라면"은 문장 맨 앞에. 중간에 끼우지 않는다.

| 나쁨 | 좋음 |
|------|------|
| "마찰이 없는 경우 역학적 에너지가 보존된다" | "마찰이 0인지 확인한다. 0이면 처음 에너지 합 = 나중 에너지 합." |

### 3-5. 부정문 금지 — "~하지 마라" 대신 "~한다"

| 나쁨 | 좋음 |
|------|------|
| "중력을 빼먹지 않는다" | "자유물체도에 중력 화살표를 반드시 포함한다." |
| "단위를 틀리지 않는다" | "모든 길이를 m로, 질량을 kg으로, 시간을 s로 고친다." |

## 4. 뇌과학·언어학 원칙

### 4-1. 3단위 청킹

작업기억은 3~5개 항목만 붙잡을 수 있다 (Miller, Sweller). **모든 절차는 3단계로.** 4단계 이상이면 상위 3단계 + 하위 3단계로 중첩한다.

### 4-2. 예측 오류 각인 — "자주 하는 실수" 코너

1. **먼저 틀린 방법을 보여준다** — "많은 사람이 이렇게 한다: (틀린 방법)"
2. **틀린 이유를 한 줄로** — "하지만 이러면 ___가 성립하지 않는다."
3. **그다음 옳은 방법을 보여준다.**

### 4-3. 운동 언어 — "손이 기억하게 한다"

체화인지 연구: 신체 동작 단어는 운동피질을 활성화해 기억을 강화한다.

| 추상 동사 | → 운동 동사 |
|------|------|
| 성분분해한다 | 화살표를 **쪼갠다** |
| 등식으로 놓는다 | 두 항을 **맞붙인다** |
| 대입한다 | 숫자를 **밀어넣는다** |
| 소거한다 | **지운다** |
| 이항한다 | 오른쪽으로 **옮긴다** |
| 유도한다 | 식을 **끌어낸다** |

### 4-4. 생성 효과 — 구성형 문제

정보를 직접 생성할 때 기억이 2~3배 강해진다 (Slamecka & Graf).
연습문제 중 최소 2개는 템플릿 적용이 아닌 **구성형**으로.

### 4-5. 숫자에 감정 싣기

결과가 깔끔할 때 언어로 표시한다: "딱 떨어진다.", "깔끔하게 나온다.", "한 방에 풀린다."

## 6. 단위와 숫자 규칙

1. **모든 문제에 단위를 명시한다.** 숫자만 던지지 않는다.
2. **SI 단위를 기본으로 한다.** m, kg, s, N, J, W, Pa, etc.
3. **단위 변환은 문제 시작 전에 먼저 한다.** cm→m, g→kg, km/h→m/s.
4. **유효숫자는 Phase 1에서 가르치고, 이후 모든 계산에 적용한다.**
5. **답에 항상 단위를 붙인다.** "속도 = 5" → 금지. "속도 = 5 m/s" → 허용.
