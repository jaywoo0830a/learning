# 04 — Maximizing Retrieval

> The effect of retrieval is proportional not to "did I get it right" but to **"how hard was it to get right"** (Bjork, desirable difficulties).
> With one condition: **success + immediate feedback.** Retrieval that ends in failure is waste.

## 1. 4 Switches That Set Retrieval Strength

| Switch | Evidence | Setting |
|---|---|---|
| **Spacing** | Cepeda et al. | Day 2 → Day 7 → Day 21 (right when about to forget) |
| **Format** | free recall > cued recall > recognition | blank-paper dump, explain aloud (teach-back) first |
| **Interference** | Rohrer & Taylor | mix problem types + retrieve **confusable pairs together** |
| **Feedback delay** | Butler et al. | check 30 s–a few minutes after recall (delayed beats immediate grading for retention) |

## 2. Three Evidence-Based Techniques

### 1. Successive Relearning (Rawson & Dunlosky) — the strongest
- Recall an item until **3 consecutive `○` passes**
- On `?` failure, peek at the book for **10 s**, close it, and **immediately re-recall** → reset the count
- At session end, one free recall of everything covered today

### 2. Pre-testing (Kornell et al.)
- Before studying, glance at the problem for 2 min. Getting it wrong is OK — failed retrieval + immediate feedback strengthens learning.

### 3. Blank-Paper Dump (Brain Dump)
- Reconstruct the whole unit **as a map** from nothing (nodes + `→` edges + one Example per node)
- **Completeness** is the score, not speed → especially favorable for slow processors.

## 3. Turn Reading into Retrieval (R-R-R)

- **Read–Recite–Review**: read a section → close the book and explain aloud → re-check only what failed
- **Predictive reading**: before reading each line of a worked solution, predict the next line
- → "reading time" becomes "retrieval practice time."

## 4. Daily 5-Minute Routine

1. **Note quiz (2 min)**: recall random `?` entries from the indexing note (confusable pairs together)
2. 3 straight `○` → delete (absorbed into the map)
3. **Yesterday's map dump (3 min)**: structure + conditions + sketch the solution path of the "Violated problem"
4. **Do it before bed** → overlaps with sleep consolidation for a boost

## 5. Calibration Rules

- Success rate **< 50%** → shorten spacing (Day 7 → Day 4), lower difficulty
  → many failed retrievals are not "hard retrieval" but "wasted retrieval."
- Success rate **> 90%** → lengthen spacing, upgrade format (cued recall → free recall → reconstruct solution paths)
