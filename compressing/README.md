# 📦 Compressing — Study Efficiency Strategy Notes

**One-line definition**: a collection of strategies for processing bigger learning chunks with the same time and energy.

**Target profile**: learner with high reasoning, language, and memory but slow processing speed.
→ The axis of strategy is not "reading faster" but **removing unnecessary processing and making each processing unit bigger (chunking)**.

## System at a Glance

```
textbook ──(stuck)──→ indexing note ──(3 straight ○)──→ absorbed into map note ──→ automated
                    ▲
                    │ → anchor (each entry's "Map Node" column = the link)
                 map note (skeleton in your head, 1 page of paper)
```

- **Map note** = structure (stable; growing is normal)
- **Indexing note** = conditions & exceptions (volatile; shrinking and refilling is normal)

## ⭐ Daily Morning 30-Second Card

1. Is today **Day 0** (just learned) or **Day 7** (review)? → switch the selection rules
2. Where will today's unit attach to my **map**? Predict in one line
3. If the full solution path is visible in 30 s → `○` skip
4. If you can't see a starting point → `?` predict-reconstruct with the solution
5. Solve symbolically only; plug in numbers once, at the end
6. When stuck, in order: **locate on map (10 s) → blank-paper recall (30 s) → note → textbook**
7. One-line error log: cause word (concept / condition·notation / calculation / trap) + missing link
8. Before bed, 5 min: blank-paper dump of today's concept **as a map** + one example per node

## Weekly Calibration

- Type B (`★`) accuracy < 50% → lower difficulty & spacing / > 90% → raise
- Note cleanup: `?` entries with 3 straight `○` → absorb into map, then delete
- Merge the week's chapter maps into a one-page **subject master map**
