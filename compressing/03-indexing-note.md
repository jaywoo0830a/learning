# 03 — Indexing Note: Queue of Conditions & Exceptions

> Records only the moments when you had to look up a condition or explanation in the textbook while solving — a **queue of conditions not yet automated**.
> If the map is the structure, the note is **decompression insurance**.

## 1. The Note's Triple Identity

1. **Cache** — eliminates textbook re-lookup latency
2. **Queue** — only non-automated conditions (shrinking is normal)
3. **Trap library** — stores the problem numbers that violated a condition

## 2. Entry Format (1 line, anchor required)

| Concept·condition | → Map node | Textbook | Condition in my own words | Violated problem | State |
|---|---|---|---|---|---|
| log argument condition | log | §5.2 p.142 | argument > 0 | Ex 3.5(b) | ? |

- No copying — write the condition **in your own words, 1 line** (generation effect; copying builds almost no memory strength)
- One condition per entry
- The `→` column (map node) is the only link that makes the two notes **one system**

## 3. When Stuck — the 4-Step Buffer

1. **Locate on the map (10 s)** — "where is this problem on my map?"
2. Blank-paper recall (30 s)
3. Check the **note**
4. Open **only that textbook section** → add a new entry

→ Re-reading the whole textbook disappears.

## 4. Lifespan Rules

- 3 consecutive recall successes → `○` (pass)
- `○` = absorb into the map as a one-word edge, then **delete**
- Weekly 5 min: assign `?`, delete `○`
- The note is not for reading — it's a **quiz sheet**. Recall attempts are its entire value.

## 5. Day 0 / Day 7 Connection

- **Day 0**: 1 min before solving, skim the unit's entries (priming) → update immediately on errors
- **Day 7**: start the review's first 5 min with a **note quiz** → re-solve the "Violated problem" column first
  → Day 7 review automatically starts from "where you actually failed last week"

## 6. Separation Rules from the Map

- Never write **structure/diagrams** in the note (if structure appears, send it to the map)
- Never write **prose/conditions** on the map (if an explanation grows long, send it to the note)
- Data flows one way: **textbook → note → map → automation**
