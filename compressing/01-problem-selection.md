# 01 — Problem Selection Strategy

> If a textbook section has 60 problems, you must not solve them all. For a learner with slow processing speed, **the ability to choose** determines efficiency.

## 1. Scientific Basis

- **85% rule** (Wilson et al., 2019): learning rate peaks at ~85% accuracy.
  → Ratio: "5–6 problems you solve easily + 1–2 that make you struggle + 1 you study from the solution."
- **Worked-example effect** (Sweller): at the novice stage, following a good solution is more efficient than solving from scratch.
- **Expertise reversal effect**: as skill grows, switch to solving directly.

## 2. 4-Type Classification — 30 s judgment, mark the margin

| Symbol | Type | Judgment | Action |
|---|---|---|---|
| `★` | B. Sweet spot | ~70% of path visible, 1–2 links missing | **Solve it** ← the whole strategy |
| `○` | A. Trivial | full path visible within 30 s | Skip |
| `○` | D. Computation grind | concept obvious, only long algebra | Solve symbolically, skip number-plugging |
| `?` | C. Too hard | no starting point at all | Predict-reconstruct the solution / defer complex ones to Day 7 |

- Recommended per chapter: **`★` 3–4 + trap 1 + concept/proof 1 = 5–7 problems**
- Most wasted time comes from clinging to A out of perfectionism and grinding through D to the end.

## 3. Operating the 10-Minute Rule

1. Timer 10 min → if the path is still expanding, allow **one +5 min extension** (max 15 min; beyond that, no return)
2. No progress → switch to the solution
3. **Solution protocol**: predict the next line before reading it → check → after finishing, close the book and **reconstruct from scratch on blank paper**. Passive reading = zero effect.
4. **One-line post-log**: cause word (concept / condition·notation / calculation / trap) + the missing link

## 4. Day 0 vs Day 7 — Different Criteria

| | **Day 0 (just learned)** | **Day 7 (one week later)** |
|---|---|---|
| Brain's job | schema formation | retrieval & consolidation |
| Target accuracy | ~90% (almost all solvable) | ~70% (getting stuck is normal) |
| Problem type | standard patterns, numbers-only changes | mixed, judgment, traps |
| Arrangement | blocking allowed | interleaving required |
| Solution use | actively | minimally |
| Time cap | 5–8 min | 10 min (+5 once) |

- **Day 0**: study 2 worked examples by predict-reconstruct → 2–3 basic problems → 1 standard application. Defer mixed problems to Day 7 with `?`.
- **Day 7**: 5 min blank-paper map → judgment problems + mixed problems + 1 trap + 1 upper-middle application.

## 5. Subject-Specific Priorities (high school level)

- **Math**: only problems that force the decision tree (which test/tool?). Long computations: symbolic only.
- **Physics**: 1) must name the principle 2) must draw the diagram first 3) answer is symbolic 4) limit checks are possible ($\theta \to 0$, $m \to \infty$).
- **Chemistry**: only "layered" problems — limiting reagent + percent yield, dilution + titration, combustion analysis, two-unknown mixtures. Stop simple conversions after 3 consecutive correct.
- **Biology**: level 2–3 + Make Connections + process explanation. Redrawing figures and explaining aloud beats 10 more problems.

## 6. Weekly Calibration Loop

| Metric | Verdict |
|---|---|
| Type B (`★`) accuracy < 50% | lower selection difficulty, return to theory/examples |
| Type B (`★`) accuracy > 90% | raise difficulty |
| Solution-switch rate > 30% | too hard |
| Time spent on type A (`○`) > 0 | perfectionism alert |
