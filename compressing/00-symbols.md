# 00 — Symbol System

> Design principle: **one symbol = one verb.** Symbols command action, they don't describe.
> Exactly 4 symbols. The same symbol means the same action everywhere.

## The 4 Symbols

| Symbol | Verb | Meaning |
|---|---|---|
| `★` | **DO** | Do it now — problems to solve, today's review targets |
| `○` | **DROP** | Finished — skip, pass, automated |
| `?` | **DON'T KNOW** | Defer — study via solution, still unstable, failed |
| `→` | **CONNECT** | Relation — map edge, note-to-map anchor |

## Meaning by Context

### Problem Margin (next to problem numbers)

- `★` Solve now — you see ~70% of the path with 1–2 missing links
- `○` Skip — the full path is visible / computation grind (check symbolically only)
- `?` Study via solution predict-reconstruct, or **defer to Day 7**

### Indexing Note

- `?` Queue — condition not yet stable
- `○` Pass — 3 consecutive recall successes → absorb into map, then **delete**
- `→` Anchor — write the map-node name in the "Map Node" column (that column is the connection)

### Map

- Every relation is `→` + a label word:
  `powers →inverse→ logs` · `power rules →contrast→ log rules` · `ratio test →but ρ=1→ another tool`
- Node whose condition lives in the note: `log →condition in note→ (argument>0)`

### Retrieval

- `○` Pass (success)
- `?` Fail → peek at the book 10 s → close and immediately re-recall
- 3 consecutive `○` → delete from note

## Not Symbols (use words)

- Error-log cause: one word from **concept / condition·notation / calculation / trap**
  Format: `problem number | trap | the missing link, one line`
- Example problem on a map node: `Example: Exercise 3.5(a)`
- Vertical strokes in diagrams (`│`, `▼`, `▲`) are drawing lines, not symbols

## Rules

- These 4 symbols only. Never invent new ones.
- If unclear, write a one-line note instead of a symbol. A symbol is an action — marking = deciding.
