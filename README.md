# learning

> **방법 중심, 선경험 후개념**
>
> 각 세션은 하나의 계산 절차를 가르치고, 충분한 연습 후 마지막에만 수학 용어를 소개합니다.

## 구성 원칙

1. **절차 우선** — "이렇게 한다"라는 구체적인 단계를 먼저 제시합니다.
2. **숫자로 설명** — 대수 기호(a, b, x, y) 대신 실제 숫자 예시로 설명합니다.
3. **용어는 마지막에** — 모든 연습이 끝난 후에야 수학 용어를 공개합니다.
