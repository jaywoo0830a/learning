# HEPTA-HAND: 7원소 필기체 주석 체계

> **목표** — 뇌 에너지 100%를 내용에 집중. 사고의 구조는 기호가 대신 잡아준다.
> **원칙** — 모든 기호 1~2획, 필기체에 자연스럽게 녹아든다, 시험지 여백에 낙서하듯 빠르게.

---

## 1. 왜 7개인가?

학습 중 뇌가 소모하는 에너지를 분석하면:

| 에너지 사용처 | 기존 비율 | HEPTA-HAND 적용 후 |
|:---|:---:|:---:|
| 내용 이해 | 40% | **95%** ← 여기에 거의 모든 에너지 |
| 구조 파악 ("지금 뭘 하고 있지?") | 30% | **3%** ← 기호가 대신함 |
| 메타인지 ("아는가 모르는가?") | 20% | **1%** ← `?` `◎` 가 대신함 |
| 기억 유지 ("아까 그게 뭐였더라?") | 10% | **1%** ← 기호가 트리거 역할 |

> **Miller's Law**: 인간 작업기억은 7±2개 청크를 동시 유지 가능.
> 7원소는 뇌가 **한 번에 품을 수 있는 최대치**와 정확히 일치한다.

---

## 2. 7대 기초 원소

### 2.1 원소 일람

| # | 기호 | 이름 | 획수 | 질문 | 인지 역할 |
|:---:|:---:|:---|:---:|:---|:---|
| 1 | `·` | **점** (DOT) | 1 | "이게 뭔가?" | 식별·명명·범주화 |
| 2 | `→` | **흐름** (FLOW) | 1 | "어디로 가나?" | 인과·추론·예측 |
| 3 | `◯` | **눈** (EYE) | 1 | "어딜 봐야 하나?" | 주의·선택·강조 |
| 4 | `[ ]` | **틀** (FRAME) | 2 | "무슨 전제 위에 있나?" | 맥락화·조건 명시 |
| 5 | `?` | **틈** (GAP) | 1 | "뭐가 비었나?" | 호기심·미지 인식·메타인지 |
| 6 | `!` | **불꽃** (SPARK) | 1~2 | "어떻게 연결되나?" | 창의·유추·패턴 발견 |
| 7 | `◎` | **잠금** (LOCK) | 2 | "이게 맞나?" | 검증·판단·종결 |

### 2.2 각 기호의 필기 동작

---

**`·` — 점 (DOT)**

> 펜 끝으로 종이를 톡 찍는다. 손목 무게만 실어서. 개념 하나당 점 하나.
> **가장 빠른 기호.**

---

**`→` — 흐름 (FLOW)**

> 왼쪽에서 오른쪽으로 한 번 긋는다. 화살촉은 생략 가능 — 그냥 긴 선이어도 의미가 통한다.
> 필기체의 자연스러운 손 흐름과 완전히 일치.

---

**`◯` — 눈 (EYE)**

> 시계 반대방향으로 한 바퀴. 완벽한 원 아니어도 된다. 찌그러진 타원도 OK.
> '감싼다'는 동작 자체가 의미를 가진다.

---

**`[ ]` — 틀 (FRAME)**

> 세로획 두 개, 각각 위에서 아래로. 손에 익은 괄호 치기.
> 필기체에서 이미 빠르다. 살짝 구부러져도 인식에 문제 없다.

---

**`?` — 틈 (GAP)**

> 귀에서 시작해 아래로 말아 내린다. 필기체에서는 점을 생략하고 곡선만 써도 의미가 통한다.

---

**`!` — 불꽃 (SPARK)**

> 위에서 아래로 수직선을 긋고, 아래에 점을 찍는다.
> 수직선만으로도 의미는 충분 — 점은 정말 강조하고 싶을 때만 추가.

---

**`◎` — 잠금 (LOCK)**

> 원(1획) + 가운데 점(2획). 과녁 조준선을 떠올리면 자연스럽다.
> 원 안에 점을 찍는다는 하나의 덩어리 동작으로 익히면 빠르다.

---

## 3. 조합 문법

### 3.1 기본 규칙

| 연산 | 표기 | 의미 |
|:---|:---|:---|
| **병치** | `A B` | 두 기호를 나란히 — "A이면서 B", 순차적 사고 |
| **포함** | `A[B]` | 틀 `[ ]` 안에 넣기 — "A라는 맥락 안의 B" |
| **중첩** | `A` 다음 줄 `B` | 줄바꿔 쓰기 — "A 다음 단계로 B" |

### 3.2 핵심 조합 7선

| # | 조합 | 의미 | 구체적 예 |
|:---:|:---|:---|:---|
| 1 | `· → ·` | 개념 A가 개념 B로 이어진다 | `미분 → 기울기` |
| 2 | `◯·` | 이 개념에 집중하라 | `◯엡실론-델타 정의` |
| 3 | `[?]` | 이 가정이 의심스럽다 | `[x > 0 ?]` |
| 4 | `!·` | 이 개념에 대한 통찰 | `!미분은 접선의 기울기` |
| 5 | `· → ◎` | 개념에서 출발해 확정된 결론 | `f'(x)=0 → ◎극값 후보` |
| 6 | `◯? → !` | 모르는 것에 주목 → 통찰 | `◯왜 분모가 0? → !발산` |
| 7 | `[? → ·] → ◎` | 의심을 해소하고 결론 확정 | `[연속? → 아님] → ◎불연속` |

## 4. 4대 사고 패턴

### 패턴 A — 개념 이해 사이클

```
◯?  →  !  →  ·  →  ◎
```

| 단계 | 기호 | 의미 |
|:---|:---:|:---|
| 모르는 것에 집중 | `◯?` | "내가 정확히 뭘 모르는가?" |
| 통찰이 떠오름 | `!` | "아, 이렇게 되는구나" |
| 개념으로 굳힘 | `·` | 한 문장으로 정리 |
| 확정 | `◎` | "이해했다" |

### 패턴 B — 문제 해결 사이클

```
[조건] → ·접근 → ·계산 → ◎답 → ?검산
```

| 단계 | 기호 | 의미 |
|:---|:---:|:---|
| 전제 확인 | `[ ]` | 주어진 조건을 틀에 담기 |
| 접근법 선택 | `·` | 어떤 방법으로 풀지 결정 |
| 계산 수행 | `·` | 단계별 실행 |
| 답 확정 | `◎` | 최종 답안 |
| 검산 | `?` | 단위, 부호, 논리 확인 |

### 패턴 C — 증명·논증 사이클

```
[가정] → ·₁ → ·₂ → ·₃ → ◎결론
                            ↓
                     [?반례는 없나]
```

| 단계 | 기호 | 의미 |
|:---|:---:|:---|
| 가정 명시 | `[ ]` | 증명의 출발점 |
| 명제 전개 | `·₁ → ·₂ → ·₃` | 논리적 연쇄 |
| 결론 도출 | `◎` | 증명 완료 |
| 반례 탐색 | `?` | 결론의 견고함 확인 |

### 패턴 D — 암기·숙지 사이클

```
◯·₁ → ◯·₂ → ◯·₃ → ◎전체 구조
```

| 단계 | 기호 | 의미 |
|:---|:---:|:---|
| 개념1 집중 | `◯·₁` | 첫 개념 완전히 보기 |
| 개념2 집중 | `◯·₂` | 다음 개념으로 이동 |
| 개념3 집중 | `◯·₃` | 마지막 개념 |
| 구조 파악 | `◎` | 전체 연결고리 확정 |

## 5. 복합 기호 (단축형)

자주 쓰는 패턴은 하나로 압축해서 더 빠르게:

| 복합 기호 | 의미 | 전개형 |
|:---|:---|:---|
| **학습** | 모름→통찰→확정 | `◯? → ! → ◎` |
| **증명** | 가정에서 결론까지 | `[···] → ◎` |
| **비판** | 틀을 의심하고 분석 | `?[ ] + ◯·` |
| **창의** | 두 개념의 불꽃 | `!(·, ·) → ·` |
| **결정** | 후보 중 하나 선택 | `◯{·,·,·} → ◎·` |
| **검토** | 결론의 경로 되짚기 | `◎→ → ?→` |

---

## 6. 빠르게 쓰는 요령

1. **점(`·`)** — 손목 무게만으로, 팔 힘 빼고 톡
2. **화살표(`→`)** — 화살촉 없이 그냥 긴 선, 의미 충분히 통함
3. **원(`◯`)** — 타원이어도 OK, '감싼다'가 핵심
4. **괄호(`[ ]`)** — 손에 이미 익은 동작, 구부러져도 무방
5. **물음표(`?`)** — 점 생략 가능, 곡선만으로 인식
6. **느낌표(`!`)** — 세로선만으로 충분, 점은 강조용
7. **과녁(`◎`)** — 원+점을 하나의 덩어리로, 두 동작을 붙여서

## 7. 주의사항

| 하지 말 것 | 이유 |
|:---|:---|
| 모든 문장에 기호 달기 | 과하면 기호가 소음이 된다 |
| 기호 쓰는 데 1초 이상 쓰기 | 너무 복잡한 기호라는 신호 |
| 남에게 보여주려고 예쁘게 쓰기 | 나만 알아보면 된다 |

| 할 것 | 이유 |
|:---|:---|
| 페이지당 5~10개 유지 | 20개 넘으면 의미 희석 |
| 나만의 변형 만들기 | 7원소는 출발점일 뿐, 손에 맞게 진화시켜라 |
