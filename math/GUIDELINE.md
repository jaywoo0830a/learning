> 모든 세션은 이 문서의 규칙을 따른다. v4: 풀이 분리, 풀이집 구조 추가.

---

## 1. 핵심 원칙: 방법 → 경험 → 용어

```
[방법 제시 + 충분한 예제] → [연습 (문제만)] → [맨 마지막에 용어와 기호 공개]
        약 60%                 30%              마지막 10%
```

용어와 기호는 세션 끝에서 처음 등장. 세션 제목은 개념명이 아닌 **방법 설명형**.

---

## 2. 언어 규칙

| 금지 | 대신 사용 |
|:----:|------|
| $\neg, \land, \lor, \to, \leftrightarrow$ | "아니다", "그리고", "또는", "이면", "일 때만" |
| $\forall, \exists$ | "모든", "어떤" |
| $p, q, r$ | 구체적 문장: "비가 온다", "사과가 있다" |
| $x, y, a, b$ | 구체적 숫자: $2, 3, 5, 7$ |
| $f(x), y=mx+b$ | "넣은 수", "나온 수", "늘어나는 양" |
| T, F | "참", "거짓" |

명령형·구어체로 절차 설명. "미분법 = 얘 찾아서 앞에 놓고 빼고" 수준.

## 3. 풀이 분리 규칙 (신규)

### 3-1. 풀이는 별도 파일에

연습문제의 풀이를 세션 파일에 포함하지 않는다. 대신 `solutions/` 폴더 아래에 별도 풀이집 파일을 둔다.

```
math/sessions/phase1/
├── 01-judging-truth-of-sentences.md       ← 문제만
├── 02-transforming-sentences-without-tables.md
├── 03-handling-all-and-some.md
└── solutions/
    ├── 01-solutions.md                    ← 풀이만
    ├── 02-solutions.md
    └── 03-solutions.md
```

### 3-2. 세션 파일의 연습문제 형식

각 연습문제 아래에 풀이집 링크만 남긴다.

```markdown
## 연습 1

(문제 내용)...

> 풀이: [풀이집](solutions/01-solutions.md#연습-1)
```

`<details>` 블록을 사용하지 않는다. 풀이는 모두 풀이집에 있다.

### 3-3. 풀이집 파일 형식

```markdown
# 풀이집 — 세션 0X: (세션 제목)

---

## 연습 1

(문제 간략 재진술)

### 풀이

(단계별 풀이. 표, 변환 과정, 최종 답 포함)
```

각 연습의 풀이에 포함할 내용:
- 최종 답뿐 아니라 중간 단계
- 함정 문제는 "이렇게 생각하면 틀린다" 명시
- 실전 문제는 풀이 후 해석 추가

## 4. 2시간 분량 확보 규칙

| 구간 | 최소 분량 | 요구사항 |
|:----:|:--------:|------|
| 방법 제시 | 60분 | 각 규칙마다 표 1개 + 예제 1개. "자주 하는 실수" 코너 최소 1개 |
| 연습 | 45분 | 5~6문제. 마지막 1~2개에 "실전" 레이블 |
| 용어 정리 | 10분 | 새 용어 최대 10개. 표준 도입 문구 사용 |
| 절차 카드 | 5분 | 코드 블록 3~4단계. 다음 예고 |

---

## 5. 표 규칙

표 헤더에 기호 금지. "참"/"거짓" 사용. 각 규칙 소개는 **표 → 규칙 한 줄 → 구체적 예문** 순서.

---

## 6. "자주 하는 실수" 코너

모든 세션의 방법 구간에 최소 1개 포함. 연습이 아닌 방법 설명의 일부.

```markdown
### 자주 하는 실수: (제목)

(설명 + 왜 틀렸는지 구체적 예시)
```

---

## 7. 연습문제 규칙

### 7-1. 난이도 배치

| 번호 | 유형 |
|:---:|------|
| 1~2 | 직적용 (절차 그대로) |
| 3~4 | 변형 + 함정 (흔한 실수 유도) |
| 5~6 | 통합, 마지막은 **실전** 레이블 |

### 7-2. 풀이 참조 형식

모든 연습문제 끝에 반드시 다음 줄을 넣는다.

```markdown
> 풀이: [풀이집](solutions/0X-solutions.md#연습-N)
```

---

## 8. 용어 정리

세션 마지막. **표준 도입 문구 필수.**

```markdown
## 용어 정리

지금까지 우리는 (쉬운 말)만 썼다. **방법은 이미 다 배웠다.**
이제 수학에서 쓰는 이름과 기호를 소개한다.
이것은 이미 익숙한 방법에 이름을 붙이는 것뿐이다.

| 우리가 써온 말 | 수학 용어 | 기호 |
|:------------:|:--------:|:---:|
```

---

## 9. 절차 요약 카드

```markdown
## 오늘 배운 절차

```
1단계: ...
2단계: ...
3단계: ...
```
```

3~4단계. 용어 정리 후이므로 기호 섞어 써도 됨.
