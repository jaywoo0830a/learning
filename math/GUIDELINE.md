## 1. 핵심 원칙: 방법 → 경험 → 용어

```
[방법 제시 + 충분한 예제] → [연습 (문제만)] → [맨 마지막에 용어와 기호 공개]
        약 60%                 30%              마지막 10%
```

용어와 기호는 세션 끝에서 처음 등장. 세션 제목은 개념명이 아닌 **방법 설명형**.
예: "진리표로 참거짓 판정하기", "극한값 구하기 — 인수분해로 0/0 뚫기"

## 2. 언어적 명료성 원칙 — "따라 하면 저절로 된다"

사람이 글을 읽고 절차를 따라 할 때, 혼동이 생기는 지점은 정해져 있다.
아래 원칙들은 그 지점들을 제거하기 위한 것이다.

### 2-1. 문장 구조: 동작 → 대상 → 결과

모든 절차 문장은 이 순서를 지킨다. 조건은 동작보다 먼저.

```
[조건이 있다면 먼저] → [무엇을] → [어떻게 한다] → [그러면 무엇이 나온다]
```

| 나쁨 | 좋음 |
|------|------|
| "$a$를 $b$로 나눈 나머지가 0이면 인수이다" | "$a$를 $b$로 나눈다. 나머지가 0이면 $b$는 인수다." |
| "$f'(x)=0$인 점에서 극값을 가질 수 있다" | "$f'(x)=0$인 점을 찾는다. 그 점의 좌우에서 $f'$ 부호가 바뀌면 극값이다." |
| "양변을 미분하여 정리한다" | "양변을 $x$로 미분한다. $dy/dx$가 있는 항을 왼쪽으로 옮긴다. $dy/dx$로 묶는다." |
| "행렬을 대각화한다" | "고유벡터를 열로 늘어놓아 $P$를 만든다. $P^{-1}AP$를 계산한다. 대각선에 고유값만 남는다." |

핵심: **한 문장 = 동작 하나**. 두 개 이상의 동작은 문장을 나눈다.

### 2-2. 위치 기반 지시: "어디에 있는 무엇을"

추상 변수명 대신, 시각적·공간적 위치를 가리킨다.

| 나쁨 | 좋음 |
|------|------|
| "$a_n$ = 수열의 $n$번째 항" | "수열의 $n$번째 자리에 적힌 숫자" |
| "기울기 $m$" | "그래프에서 $x$가 1만큼 갈 때 $y$가 올라간 양" |
| "$A_{ij}$ = 행렬의 $(i,j)$ 성분" | "$i$번째 가로줄, $j$번째 세로줄에 적힌 숫자" |
| "$\lambda$ = 고유값" | "$\det(A-\lambda I)=0$을 풀어서 나온 $\lambda$" |
| "$f^{-1}$ = 역함수" | "$y=x$ 선으로 접었을 때 포개지는 함수" |

한 번 위치를 정의했으면, 그 세션 안에서는 **같은 표현만** 쓴다. "$i$번째 가로줄"이라고 정했으면 끝까지 그렇게 부른다. "행"이나 "row"로 중간에 바꾸지 않는다.

### 2-3. 어휘 일관성: 하나의 동작 = 하나의 단어

| 동작 | 이 단어만 쓴다 | 이 단어는 안 쓴다 |
|:---:|:---:|------|
| + | "더한다" | "합한다", "덧셈한다", "플러스한다" |
| − | "뺀다" | "뺄셈한다", "차를 구한다", "마이너스한다" |
| × | "곱한다" | "곱셈한다", "승산한다", "곱하기한다" |
| ÷ | "나눈다" | "나눗셈한다", "제산한다", "나누기한다" |
| 대입 | "넣는다" | "대입한다", "치환한다", "대체한다" |
| 미분 | "미분한다" | "도함수를 구한다", "미분을 취한다" |
| 적분 | "적분한다" | "부정적분을 구한다", "원시함수를 찾는다" |
| 비교 | "비교한다" | "견준다", "대조한다" |
| 이동 | "옮긴다" | "이항한다", "이동한다", "넘긴다" |
| 소거 | "지운다" | "소거한다", "제거한다", "없앤다" |

세션 전체에서 한 동작에 한 단어. 용어 정리 전까지는 이 단어들만 쓴다.

### 2-4. 조건문: 앞에, 짧게, 구체적으로

"만약 ~라면"은 문장 맨 앞에. 중간에 끼워 넣지 않는다.

| 나쁨 | 좋음 |
|------|------|
| "판별식이 0보다 크면 두 실근을 갖는다" | "판별식이 0보다 크다. → 실근 두 개." |
| "분모가 0이 아니라는 조건 하에 약분한다" | "분모가 0인지 먼저 확인한다. 0이 아니면 약분한다." |
| "수렴반경 안이면 멱급수는 수렴한다" | "$\lvert x-a\rvert < R$인지 확인한다. 작으면 수렴한다." |

### 2-5. 부정문 금지 — "하지 않는다" 대신 "~한다"

금지 사항을 말할 때도 긍정문으로 쓴다. "~하지 마라"는 머릿속에 그 행동을 먼저 떠올리게 해서 역효과다.

| 나쁨 | 좋음 |
|------|------|
| "분모를 0으로 나누지 않는다" | "분모가 0이면 그대로 둔다." |
| "행렬식을 전개할 때 부호를 틀리지 마라" | "여인수 전개에서 $+,-,+,-$ 패턴으로 부호를 붙인다." |
| "$x=2$를 해에서 빠뜨리지 않는다" | "$x=2$를 반드시 확인한다." |

### 2-6. 추상→구체 순서: 구체적인 예를 먼저

규칙을 먼저 말하고 예를 드는 것이 아니라, **예를 먼저 보여주고 규칙을 뽑아낸다**.

| 나쁨 | 좋음 |
|------|------|
| "지수법칙: $a^m a^n = a^{m+n}$" | "$2^3 \times 2^4 = 2^7$. $2^3 \times 2^4 = 2^{3+4}$." 그 후에 "이것이 $a^m a^n = a^{m+n}$이다." |
| "연쇄법칙: $\frac{d}{dx}f(g(x))=f'(g(x))g'(x)$" | "$(x^2+1)^3$을 미분해보자. 바깥함수 $(\cdot)^3$, 안쪽함수 $x^2+1$. 바깥 미분 $3(\cdot)^2$에 안쪽 넣고, 안쪽 미분 $2x$를 곱한다. $3(x^2+1)^2\cdot 2x$." 그 후에 연쇄법칙 공식. |

### 2-7. 숫자에 감정을 싣는다 — "딱", "깔끔하게", "한 방에"

추상적 규칙은 차갑게 느껴진다. 결과가 깔끔하게 떨어질 때는 그걸 언어로 표시해준다.

- "나머지가 딱 0이 된다."
- "이렇게 하면 한 방에 약분된다."
- "깔끔하게 정수로 나온다."
- "행렬이 단번에 대각선만 남는다."

### 2-8. 뇌과학: 3단위 청킹 (Miller의 7±2, Sweller의 인지부하)

작업기억은 한 번에 3~5개 항목만 붙잡을 수 있다. **모든 절차는 3단계로 쪼갠다.**
4단계 이상이면 상위 단계 3개 + 각각의 하위 단계 3개로 중첩한다.

| 나쁨 (7단계 나열) | 좋음 (3×3 중첩) |
|------|------|
| ① 식을 인수분해 ② 분모 확인 ③ 약분 ④ 극한 대입 ⑤ 부호 판정 ⑥ 그래프 확인 ⑦ 결론 | **[큰 단계 1: 식 정리]** ① 인수분해 ② 분모≠0 확인 ③ 약분 → **[큰 단계 2: 극한]** ④ 대입 ⑤ 부호 판정 → **[큰 단계 3: 해석]** ⑥ 그래프 ⑦ 결론 |

### 2-9. 뇌과학: 예측 오류를 활용한 각인

뇌는 예측과 다른 정보가 들어올 때 가장 강하게 반응한다 (Friston의 예측처리 이론).
"자주 하는 실수" 코너는 이 원리를 의도적으로 활용한다:

1. **먼저 틀린 답을 보여준다** — "많은 사람이 이렇게 한다: (틀린 방법)"
2. **틀린 이유를 한 줄로** — "하지만 이러면 ___가 성립하지 않는다."
3. **그다음 옳은 방법을 보여준다** — 예측 오류가 발생한 상태에서 제시하면 각인된다.

### 2-10. 언어학: 운동 언어 — "손이 기억하게 한다"

체화인지(embodied cognition) 연구에 따르면, 신체 동작을 묘사하는 단어는 운동피질을 활성화시켜 기억을 강화한다.
추상적 수학 조작도 신체 동사로 표현한다.

| 추상 동사 | 운동 동사로 대체 |
|------|------|
| "이항한다" | "오른쪽으로 **옮긴다**" |
| "대입한다" | "그 자리에 **밀어넣는다**" |
| "소거한다" | "**지운다**" |
| "인수분해한다" | "**찢는다**" |
| "전개한다" | "**펼친다**" |
| "약분한다" | "**접는다**" (분자분모에서 같은 것끼리) |
| "정리한다" | "**모은다**" |
| "행렬을 곱한다" | "가로줄과 세로줄을 **마주치게** 한다" |

### 2-11. 뇌과학: 생성 효과 — "스스로 만들어야 남는다"

정보를 그냥 읽는 것보다 직접 생성할 때 기억이 2~3배 강해진다 (Slamecka & Graf).
연습문제 중 최소 2개는 **템플릿 적용이 아닌 구성형**으로 만든다.

| 템플릿 적용 (약함) | 구성형 (강함) |
|------|------|
| "$2^3 \times 2^4$를 계산하라" | "곱이 $2^7$이 되는 두 지수 쌍을 세 개 만들어보라." |
| "$f(x)=x^2$을 미분하라" | "미분해서 $2x$가 되는 함수를 세 개 쓰고, 공통점을 찾아보라." |
| "행렬식을 계산하라" | "행렬식이 0이 되는 $2\times2$ 행렬을 세 개 만들고, 규칙성을 찾아보라." |

### 2-12. 언어학: 처리 유창성 — "쉽게 읽히면 쉽게 믿긴다"

처리 유창성(processing fluency)이 높으면 내용도 더 옳게 느껴지고 더 잘 기억된다.
- 모든 절차 문장은 같은 리듬: "~을 ~한다. 그러면 ~이 나온다."
- 한 세션 내에서 같은 구조의 문장을 반복해서 쓴다. 변주하지 않는다.
- 문장 길이: 20자를 넘기지 않는다. 넘으면 끊는다.

### 2-13. 뇌과학: 초두·최신 효과 — "처음과 마지막에 핵심을"

사람은 목록의 처음 항목(초두효과)과 마지막 항목(최신효과)을 가장 잘 기억한다.
- **각 절차 목록에서 가장 중요한 단계를 첫 번째에** 배치한다.
- **세션 마지막 "오늘의 절차" 카드에 핵심만 재진술**한다.
- 절차가 3단계면: 1단계(초두) + 마지막 카드(최신) = 두 번 각인.

### 2-14. 뇌과학: 지식의 저주 방지 — "처음 보는 사람이 이해할 수 있는가"

전문가는 자신이 아는 것을 모르는 상태를 상상하지 못한다 (Hinds, 1999).
작성 후 반드시 체크할 것:
- [ ] 변수·기호가 사용되기 전에 **위치 기반**으로 먼저 소개되었는가?
- [ ] "당연히", "쉽게", "자명하게", "trivial" 같은 단어가 없는가? — 이것들은 지식의 저주 신호다.
- [ ] 중간 단계를 하나도 건너뛰지 않았는가? (5→7이 아니라 5→6→7)

## 4. 풀이 분리 규칙

### 4-1. 풀이는 별도 파일에

연습문제의 풀이를 세션 파일에 포함하지 않는다. `solutions/` 폴더 아래에 별도 풀이집 파일을 둔다.

```
math/sessions/phase1/
├── 01-judging-truth-of-sentences.md
├── 02-transforming-sentences-without-tables.md
└── solutions/
    ├── 01-solutions.md
    └── 02-solutions.md
```

### 4-2. 세션 파일의 연습문제 형식

```markdown
## 연습 1

(문제 내용)...

> 풀이: [풀이집](solutions/01-solutions.md#연습-1)
```

`<details>` 블록을 사용하지 않는다.

### 4-3. 풀이집 파일 형식

```markdown
# 풀이집 — 세션 0X: (세션 제목)

## 연습 1
(문제 간략 재진술)

### 풀이
(단계별 풀이. 중간 단계, 함정 포인트, 최종 답 포함)
```

## 6. "자주 하는 실수" 코너

모든 세션의 방법 구간에 최소 1개 포함. §2-9 원칙에 따라 **틀린 방법 먼저 → 이유 → 옳은 방법** 순서.

```markdown
### 자주 하는 실수: (제목)

많은 사람이 이렇게 한다: (틀린 방법)
하지만 이러면 ___가 성립하지 않는다.
옳은 방법은: (옳은 방법)
```

|:------------:|:--------:|:---:|
