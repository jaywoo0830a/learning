## 연습 1

> $\frac{3-i}{2+i}$를 $a+bi$ 꼴로, 그리고 극형식으로.

① 분모 켤레 $2-i$를 곱한다.

$\frac{3-i}{2+i} \cdot \frac{2-i}{2-i} = \frac{(3-i)(2-i)}{(2+i)(2-i)}$.

② 분자: $3 \cdot 2 + 3(-i) + (-i)(2) + (-i)(-i) = 6 - 3i - 2i + i^2 = 6 - 5i - 1 = 5 - 5i$.

③ 분모: $4 - i^2 = 4 + 1 = 5$.

→ $\frac{5-5i}{5} = 1 - i$.

④ 극형식: $a=1, b=-1$. $r = \sqrt{1+1} = \sqrt{2}$.
$\cos\theta = \frac{1}{\sqrt{2}}$, $\sin\theta = -\frac{1}{\sqrt{2}}$ → $\theta = -\frac{\pi}{4}$ (또는 $\frac{7\pi}{4}$).

→ **$z = \sqrt{2}(\cos(-\frac{\pi}{4}) + i\sin(-\frac{\pi}{4}))$.**

## 연습 2

> $z = 1 - i$의 $z^8$.

① 극형식: $r = \sqrt{1+1} = \sqrt{2}$, $\theta = -\frac{\pi}{4}$.

② 드무아브르: $z^8 = (\sqrt{2})^8(\cos(-8 \cdot \frac{\pi}{4}) + i\sin(-8 \cdot \frac{\pi}{4}))$.

③ $(\sqrt{2})^8 = (2^{1/2})^8 = 2^4 = 16$.
$\cos(-2\pi) = \cos 0 = 1$. $\sin(-2\pi) = \sin 0 = 0$.

→ **$z^8 = 16$.**

## 연습 3

> $\vec{a} = (2, -1, 3)$, $\vec{b} = (1, 4, -2)$. 내적과 외적.

**내적**: $\vec{a}\cdot\vec{b} = 2 \cdot 1 + (-1) \cdot 4 + 3 \cdot (-2) = 2 - 4 - 6 = -8$.

**외적**:
$\vec{a} \times \vec{b} = (a_2b_3-a_3b_2,\; a_3b_1-a_1b_3,\; a_1b_2-a_2b_1)$.

① $x$: $(-1)(-2) - (3)(4) = 2 - 12 = -10$.
② $y$: $(3)(1) - (2)(-2) = 3 + 4 = 7$.
③ $z$: $(2)(4) - (-1)(1) = 8 + 1 = 9$.

→ $\vec{a} \times \vec{b} = (-10, 7, 9)$.

**수직 확인**:
$(\vec{a}\times\vec{b})\cdot\vec{a} = (-10)(2) + (7)(-1) + (9)(3) = -20 - 7 + 27 = 0$ ✓.
$(\vec{a}\times\vec{b})\cdot\vec{b} = (-10)(1) + (7)(4) + (9)(-2) = -10 + 28 - 18 = 0$ ✓.

## 연습 4: 구성형

> 등차이면서 등비인 수열은? 일상에서 등비수열 예 2가지.

① 세 항 $a,b,c$가 등차: $2b = a+c$. 등비: $b^2 = ac$.
$(\frac{a+c}{2})^2 = ac$ → $a^2-2ac+c^2=0$ → $(a-c)^2=0$ → $a=c$.
$b = \frac{a+a}{2} = a$. → 모든 항이 같은 상수수열만 가능.

② 실생활 예:
- 복리 이자: 원금이 매년 $r$배. $P, Pr, Pr^2, \dots$
- 세포 분열: 1→2→4→8→16... 매 시간 2배.
- 체스판 쌀알: 1, 2, 4, 8, ..., $2^{63}$.

## 연습 5

> $\sum_{k=1}^{n}(2k-1) = n^2$을 두 방법으로 증명.

**방법1 — 등차합 공식**:
$a_1=1$, $d=2$, $a_n = 2n-1$.
$S_n = \frac{n(1 + (2n-1))}{2} = \frac{n \cdot 2n}{2} = n^2$.

**방법2 — $\sum$ 공식**:
$\sum(2k-1) = 2\sum k - \sum 1 = 2\cdot\frac{n(n+1)}{2} - n = n(n+1)-n = n^2$.

**방법3 — 텔레스코핑** (보너스):
$k^2 - (k-1)^2 = 2k-1$.
$\sum_{k=1}^{n}(2k-1) = \sum_{k=1}^{n}[k^2-(k-1)^2] = n^2 - 0^2 = n^2$.

## 연습 6: 실전

> $z^3 = -8$의 세 근과 삼각형 넓이.

① $-8 = 8(-1) = 8(\cos\pi + i\sin\pi)$.
$r = 8$, $\theta = \pi$.

② 세제곱근: $z_k = 8^{1/3}(\cos\frac{\pi + 2\pi k}{3} + i\sin\frac{\pi + 2\pi k}{3})$, $k=0,1,2$.
$8^{1/3} = 2$.

$k=0$: $z_0 = 2(\cos\frac{\pi}{3} + i\sin\frac{\pi}{3}) = 2(\frac{1}{2} + i\frac{\sqrt{3}}{2}) = 1 + i\sqrt{3}$.
$k=1$: $z_1 = 2(\cos\pi + i\sin\pi) = 2(-1 + 0) = -2$.
$k=2$: $z_2 = 2(\cos\frac{5\pi}{3} + i\sin\frac{5\pi}{3}) = 2(\frac{1}{2} - i\frac{\sqrt{3}}{2}) = 1 - i\sqrt{3}$.

③ 세 점: $(1, \sqrt{3})$, $(-2, 0)$, $(1, -\sqrt{3})$.

삼각형은 밑변 길이 $2\sqrt{3}$ ($y$축 방향), 높이 $3$ ($x$축 방향: $1 - (-2) = 3$).
넓이 = $\frac{1}{2} \cdot 2\sqrt{3} \cdot 3 = 3\sqrt{3}$.

→ **근: $1\pm i\sqrt{3}$, $-2$. 삼각형 넓이: $3\sqrt{3}$.**
