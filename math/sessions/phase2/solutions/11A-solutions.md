# 11A Solutions — Trigonometry Foundations

---

## Practice 1

> $\sin\theta = -\frac{\sqrt{3}}{2}$, $\theta$ in Q4. All six functions.

(1) Q4: $\cos\theta > 0$, $\sin\theta < 0$.

(2) $\cos^2\theta = 1 - \frac{3}{4} = \frac{1}{4}$ → $\cos\theta = \frac{1}{2}$.

(3) $\tan\theta = \frac{\sin\theta}{\cos\theta} = -\sqrt{3}$.

(4) $\sec\theta = \frac{1}{\cos\theta} = 2$. $\csc\theta = \frac{1}{\sin\theta} = -\frac{2\sqrt{3}}{3}$. $\cot\theta = -\frac{\sqrt{3}}{3}$.

→ **$\cos=\frac{1}{2}$, $\tan=-\sqrt{3}$, $\sec=2$, $\csc=-\frac{2\sqrt{3}}{3}$, $\cot=-\frac{\sqrt{3}}{3}$.**

## Practice 2

> $y = 2\sin(3x + \pi) - 1$. Amplitude, period, phase, v-shift, range.

$a=2$, $b=3$, $c=\pi$, $d=-1$.

- Amplitude: $|a| = 2$.
- Period: $\frac{2\pi}{3}$.
- Phase shift: $x = -\frac{\pi}{3}$ (left by $\frac{\pi}{3}$).
- Vertical shift: $-1$ (down by 1).
- Range: $[-3, 1]$. Max = 1, Min = −3.

## Practice 3: Composition

> Sketch $y = -3\cos(2x) + 2$. Explain parameters.

Amplitude: $|a|=3$ (reflected vertically — starts at minimum instead of maximum).
Period: $\frac{2\pi}{2} = \pi$ (compressed horizontally by factor 2).
Vertical shift: $+2$ (center line at $y=2$, range $[-1, 5]$).

From $y=\cos x$: flipped vertically (starts at −3+2=−1 at $x=0$), squeezed horizontally (completes one cycle in $\pi$ instead of $2\pi$), and lifted up by 2.

## Practice 4

> $\sin 210^\circ$, $\cos 315^\circ$, $\tan 240^\circ$ exactly.

$\sin 210^\circ = \sin(180^\circ+30^\circ) = -\sin 30^\circ = -\frac{1}{2}$.
$\cos 315^\circ = \cos(360^\circ-45^\circ) = \cos 45^\circ = \frac{\sqrt{2}}{2}$.
$\tan 240^\circ = \tan(180^\circ+60^\circ) = \tan 60^\circ = \sqrt{3}$.

→ **$-\frac{1}{2}$, $\frac{\sqrt{2}}{2}$, $\sqrt{3}$.**

## Practice 5: Real Battle

> Ferris wheel: radius 30m, period 4 min, lowest point 2m. $h(t)$ from lowest point.

(1) Center height = lowest + radius = $2 + 30 = 32$ m. So $d = 32$.
(2) Amplitude = radius = 30. Starting at lowest point → $a = -30$ (cosine model, or use sine with phase).
(3) Period = 4 → $b = \frac{2\pi}{4} = \frac{\pi}{2}$.

Using cosine (starts at max when $t=0$ for $\cos$, but we start at min):
$h(t) = -30\cos(\frac{\pi}{2}t) + 32$.

Check: $t=0$ → $h = -30(1) + 32 = 2$ (lowest) ✓.
$t=2$ → $h = -30\cos\pi + 32 = 30 + 32 = 62$ (highest) ✓.
$t=4$ → $h = -30\cos(2\pi) + 32 = 2$ (back to lowest) ✓.

→ **$h(t) = -30\cos(\frac{\pi}{2}t) + 32$.**

## Basic Drill

### D1. $150^\circ$, $225^\circ$, $330^\circ$ to radians
$150^\circ = \frac{5\pi}{6}$, $225^\circ = \frac{5\pi}{4}$, $330^\circ = \frac{11\pi}{6}$.

### D2. $\frac{3\pi}{4}$, $\frac{5\pi}{3}$, $\frac{11\pi}{6}$ to degrees
$\frac{3\pi}{4} = 135^\circ$, $\frac{5\pi}{3} = 300^\circ$, $\frac{11\pi}{6} = 330^\circ$.

### D3. $\sin\frac{5\pi}{6}$, $\cos\frac{7\pi}{4}$, $\tan\frac{4\pi}{3}$
$\sin\frac{5\pi}{6} = \frac{1}{2}$. $\cos\frac{7\pi}{4} = \frac{\sqrt{2}}{2}$. $\tan\frac{4\pi}{3} = \sqrt{3}$.

### D4. $\sin\frac{3\pi}{2}$, $\cos\pi$, $\tan\frac{5\pi}{4}$
$\sin\frac{3\pi}{2} = -1$. $\cos\pi = -1$. $\tan\frac{5\pi}{4} = 1$.

### D5. $\sin\theta = \frac{5}{13}$, Q2. $\cos\theta$, $\tan\theta$.
$\cos\theta = -\sqrt{1-\frac{25}{169}} = -\frac{12}{13}$. $\tan\theta = \frac{5/13}{-12/13} = -\frac{5}{12}$.

### D6. $\cos\theta = -\frac{3}{5}$, Q3. All five others.
Q3: $\sin\theta < 0$. $\sin\theta = -\sqrt{1-\frac{9}{25}} = -\frac{4}{5}$.
$\tan\theta = \frac{-4/5}{-3/5} = \frac{4}{3}$.
$\sec\theta = \frac{1}{\cos\theta} = -\frac{5}{3}$. $\csc\theta = \frac{1}{\sin\theta} = -\frac{5}{4}$. $\cot\theta = \frac{3}{4}$.

### D7. Period and amplitude of $y = -4\cos(\frac{\pi}{2}x) + 3$
Amplitude = $|{-4}| = 4$. Period = $\frac{2\pi}{\pi/2} = 4$.

### D8. $y = 5\sin(4x - \pi) - 2$. All four parameters.
$a=5$, $b=4$, $c=-\pi$, $d=-2$. Amplitude = 5. Period = $\frac{2\pi}{4} = \frac{\pi}{2}$.
Phase shift: $4x-\pi=0$ → $x = \frac{\pi}{4}$ (right by $\frac{\pi}{4}$). Vertical shift: $-2$.

### D9. $\frac{\sin x}{\csc x} + \frac{\cos x}{\sec x}$
$\csc x = \frac{1}{\sin x}$ → $\frac{\sin x}{\csc x} = \sin^2 x$. $\sec x = \frac{1}{\cos x}$ → $\frac{\cos x}{\sec x} = \cos^2 x$.
Sum = $\sin^2 x + \cos^2 x = 1$. → **1.**

### D10. $\sin^2 15^\circ + \sin^2 75^\circ$
$\sin 75^\circ = \sin(90^\circ-15^\circ) = \cos 15^\circ$. $\sin^2 15^\circ + \cos^2 15^\circ = 1$. → **1.**

## Advanced Drill

### A1. All six trig functions at $\theta = \frac{5\pi}{3}$
$\frac{5\pi}{3} = 300^\circ$ (Q4). Reference angle = $60^\circ$.
$\sin = -\frac{\sqrt{3}}{2}$, $\cos = \frac{1}{2}$, $\tan = -\sqrt{3}$.
$\csc = -\frac{2\sqrt{3}}{3}$, $\sec = 2$, $\cot = -\frac{\sqrt{3}}{3}$.

### A2. $\sin\theta = \frac{4}{5}$, Q1. $\sin 2\theta$, $\cos 2\theta$.
Q1: $\cos\theta = \sqrt{1-\frac{16}{25}} = \frac{3}{5}$.
$\sin 2\theta = 2 \cdot \frac{4}{5} \cdot \frac{3}{5} = \frac{24}{25}$.
$\cos 2\theta = 1 - 2\sin^2\theta = 1 - \frac{32}{25} = -\frac{7}{25}$.
→ **$\sin 2\theta = \frac{24}{25}$, $\cos 2\theta = -\frac{7}{25}$.**

### A3. $\frac{\sin(-x)}{\cos(-x)} + \frac{\cos(-x)}{\sin(-x)}$
$\sin(-x) = -\sin x$, $\cos(-x) = \cos x$.
$\frac{-\sin x}{\cos x} + \frac{\cos x}{-\sin x} = -\tan x - \cot x$.
→ **$-(\tan x + \cot x)$.**

### A4. $\sin\frac{2\pi}{3}\cos\frac{\pi}{6} + \cos\frac{2\pi}{3}\sin\frac{\pi}{6}$
Pattern: $\sin A\cos B + \cos A\sin B = \sin(A+B)$ with $A=\frac{2\pi}{3}$, $B=\frac{\pi}{6}$.
$= \sin(\frac{2\pi}{3} + \frac{\pi}{6}) = \sin\frac{5\pi}{6} = \frac{1}{2}$.
→ **$\frac{1}{2}$.**

### A5. $y = -2\sin(3x + \frac{\pi}{2}) + 1$ as $a\cos(bx+c)+d$
$\sin(\theta + \frac{\pi}{2}) = \cos\theta$. So $\sin(3x + \frac{\pi}{2}) = \cos(3x)$.
$y = -2\cos(3x) + 1$.
→ **$y = -2\cos(3x) + 1$.** Amplitude 2 (reflected), period $\frac{2\pi}{3}$, v-shift +1.

### A6. $2\sin^2 x - 1 = 0$, $x \in [0, 2\pi]$
$\sin^2 x = \frac{1}{2}$ → $\sin x = \pm\frac{\sqrt{2}}{2}$.
$x = \frac{\pi}{4}, \frac{3\pi}{4}, \frac{5\pi}{4}, \frac{7\pi}{4}$.
→ **$x = \frac{\pi}{4}, \frac{3\pi}{4}, \frac{5\pi}{4}, \frac{7\pi}{4}$.**

### A7. $\tan\theta = 2$, Q3. $\sin\theta$, $\cos\theta$.
Q3: both negative. Right triangle: opposite=2, adjacent=1, hypotenuse=$\sqrt{5}$.
$\sin\theta = -\frac{2}{\sqrt{5}} = -\frac{2\sqrt{5}}{5}$. $\cos\theta = -\frac{1}{\sqrt{5}} = -\frac{\sqrt{5}}{5}$.
→ **$\sin\theta = -\frac{2\sqrt{5}}{5}$, $\cos\theta = -\frac{\sqrt{5}}{5}$.**

### A8. $\frac{1-\cos^2\theta}{\sin\theta} + \frac{1-\sin^2\theta}{\cos\theta}$
$1-\cos^2\theta = \sin^2\theta$ → first term = $\frac{\sin^2\theta}{\sin\theta} = \sin\theta$.
$1-\sin^2\theta = \cos^2\theta$ → second term = $\frac{\cos^2\theta}{\cos\theta} = \cos\theta$.
Sum = $\sin\theta + \cos\theta$.
→ **$\sin\theta + \cos\theta$.**

### A9. $y = 3\cos(\frac{\pi}{4}x) - 1$. All $x \in [0, 16]$ where $y = -1$.
$3\cos(\frac{\pi}{4}x) - 1 = -1$ → $3\cos(\frac{\pi}{4}x) = 0$ → $\cos(\frac{\pi}{4}x) = 0$.
$\frac{\pi}{4}x = \frac{\pi}{2} + n\pi$ → $x = 2 + 4n$.
In $[0, 16]$: $n=0,1,2,3$ → $x = 2, 6, 10, 14$.
→ **$x = 2, 6, 10, 14$.**

### A10. Prove $\sin^4\theta + \cos^4\theta = 1 - \frac{1}{2}\sin^2 2\theta$.
Left: $(\sin^2\theta + \cos^2\theta)^2 - 2\sin^2\theta\cos^2\theta = 1 - 2\sin^2\theta\cos^2\theta$.
$2\sin^2\theta\cos^2\theta = \frac{1}{2}(4\sin^2\theta\cos^2\theta) = \frac{1}{2}(2\sin\theta\cos\theta)^2 = \frac{1}{2}\sin^2 2\theta$.
So left = $1 - \frac{1}{2}\sin^2 2\theta$. Proved.

### D10. $\sin^2 15^\circ + \sin^2 75^\circ$
$\sin 75^\circ = \sin(90^\circ-15^\circ) = \cos 15^\circ$. $\sin^2 15^\circ + \cos^2 15^\circ = 1$. → **1.**
