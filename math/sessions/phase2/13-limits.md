## 예시 1: 직접 대입 — 넣었더니 바로 나온다

극한의 가장 기본적인 아이디어는 단순하다. **그냥 넣어본다.** $x$가 어떤 값으로 다가갈 때 함수값이 어떻게 되느냐고 묻는 게 극한이다. 대부분의 경우, 진짜로 그 값을 $x$ 자리에 넣기만 하면 답이 나온다.

$f(x)=2x+3$에 $x$가 1로 다가간다.

① $f$에 $x=1$을 그대로 밀어넣는다. → $2\cdot1+3=5$.
② 다항함수는 어디서나 끊기지 않는다. → 넣은 값 = 극한값.
→ $\lim_{x\to1}(2x+3)=5$.

손으로 더 해본다:
$\lim_{x\to3}(x^2-4)=9-4=5$.
$\lim_{x\to0}e^x=e^0=1$.
$\lim_{x\to\frac{\pi}{2}}\sin x=\sin\frac{\pi}{2}=1$.
$\lim_{x\to2}\ln x=\ln2$.

**직접대입이 통하는 조건**: 함수가 그 점에서 **연속**일 때.
다항함수, 지수함수, $\sin$/$\cos$, $\ln x$($x>0$), $\sqrt{x}$($x\geq0$) — 정의역 안이면 OK.

## 예시 2: 넣었더니 $\frac{0}{0}$ → 찢어서 약분한다

넣었더니 $\frac{0}{0}$이 나왔다. 이건 "아직 모른다"는 신호일 뿐, 답이 0이라는 뜻이 아니다. 분자와 분모가 둘 다 0으로 가고 있어서, **누가 더 빨리 0으로 가는지 경쟁**하는 중이다. 이 경쟁의 승자를 가리려면 식을 찢어서 공통 인수를 약분해야 한다.

$\lim_{x\to2}\frac{x^2-4}{x-2}$.

① $x=2$를 밀어넣으면 $\frac{0}{0}$. 이건 "아직 결정 안 됨"이라는 신호다.
② 분자를 찢는다: $x^2-4=(x-2)(x+2)$.
③ $(x-2)$가 분자·분모에 둘 다 있다 → 약분! → $x+2$ ($x\neq2$).
④ 이제 $x=2$를 넣는다 → $2+2=4$.

손으로 한 줄: $\frac{x^2-4}{x-2}=\frac{\cancel{(x-2)}(x+2)}{\cancel{x-2}}=x+2 \xrightarrow{x\to2} 4$.

![0/0 극한 구멍](graphs/13a-limit-hole.png)

$\lim_{x\to1}\frac{x^3-1}{x-1}$.
① $x=1$ → $\frac{0}{0}$.
② $x^3-1=(x-1)(x^2+x+1)$. 약분 → $x^2+x+1$.
③ $x=1$ → $1+1+1=3$.

$\lim_{x\to-1}\frac{x^2+3x+2}{x+1}$.
① $x=-1$ → $\frac{1-3+2}{0}=\frac{0}{0}$.
② 분자 찢기: $(x+1)(x+2)$. 약분 → $x+2$.
③ $x=-1$ → $1$.

## 예시 3: $\frac{0}{0}$ 루트 — 켤레를 곱한다

루트가 들어간 식에서 $\frac{0}{0}$이 나왔다. 찢어서 약분하고 싶지만 루트 때문에 찢을 수가 없다. 이럴 때 쓰는 무기가 **켤레**다. $(a-b)(a+b)=a^2-b^2$라는 공식을 이용해 루트를 제곱으로 바꿔 없애는 전략이다. 분자와 분모에 똑같은 켤레를 곱하면 식의 값은 변하지 않는다.

$\lim_{x\to0}\frac{\sqrt{x+4}-2}{x}$.

① $x=0$ → $\frac{\sqrt{4}-2}{0}=\frac{0}{0}$.
② 분자에 **켤레** $\sqrt{x+4}+2$를 분자·분모 모두에 곱한다.
③ $\frac{(\sqrt{x+4}-2)(\sqrt{x+4}+2)}{x(\sqrt{x+4}+2)} = \frac{(x+4)-4}{x(\sqrt{x+4}+2)}$.
④ 분자 = $x$. 약분! → $\frac{1}{\sqrt{x+4}+2}$.
⑤ $x=0$ → $\frac{1}{\sqrt{4}+2}=\frac{1}{4}$.

손으로 한 줄: $\frac{\sqrt{x+4}-2}{x}\cdot\frac{\sqrt{x+4}+2}{\sqrt{x+4}+2} = \frac{x}{x(\sqrt{x+4}+2)} = \frac{1}{\sqrt{x+4}+2} \to \frac{1}{4}$.

$\lim_{x\to1}\frac{\sqrt{x}-1}{x-1}$.
① $x=1$ → $\frac{0}{0}$.
② 분모 찢기: $x-1=(\sqrt{x}-1)(\sqrt{x}+1)$.
③ 약분 → $\frac{1}{\sqrt{x}+1} \to \frac{1}{2}$.

$\lim_{x\to0}\frac{\sqrt{x+1}-1}{\sqrt{x+4}-2}$.
① 분자 분모 각각 켤레 필요 → 분자에 $\sqrt{x+1}+1$, 분모에 $\sqrt{x+4}+2$.
② $\frac{x}{x}\cdot\frac{\sqrt{x+4}+2}{\sqrt{x+1}+1} = \frac{\sqrt{x+4}+2}{\sqrt{x+1}+1} \to \frac{2+2}{1+1}=2$.

## 예시 4: $\frac{0}{0}$ — $\frac{\sin x}{x}\to1$

삼각함수가 들어간 극한에서 가장 많이 쓰는 무기다. $x$가 0으로 갈 때 $\frac{\sin x}{x}$는 1로 수렴한다. 직관적으로 말하면, $x$가 아주 작을 때 $\sin x$와 $x$는 거의 같다는 뜻이다. 이 사실 하나만 알면 $\sin$이 들어간 수많은 극한을 풀 수 있다. 핵심은 $\frac{\sin\square}{\square}$꼴을 만드는 것이다. 분자와 분모의 $\square$가 **완전히 똑같아야** 1이 된다.

$\lim_{x\to0}\frac{\sin 3x}{x}$.

① $x=0$ → $\frac{0}{0}$.
② 분자 분모에 3이 다르다 → $\frac{\sin3x}{x}=3\cdot\frac{\sin3x}{3x}$.
③ $3x=t$라 놓으면 $x\to0 \Rightarrow t\to0$. $\frac{\sin t}{t}\to1$.
→ $3\cdot1=3$.

$\lim_{x\to0}\frac{\sin5x}{\sin2x}$.
① $\frac{\sin5x}{\sin2x} = \frac{\sin5x}{5x}\cdot\frac{2x}{\sin2x}\cdot\frac{5}{2}$.
② 각각 $\to1,1,\frac{5}{2}$. → $\frac{5}{2}$.

$\lim_{x\to0}\frac{\tan x}{x}$.
① $\tan x=\frac{\sin x}{\cos x}$. → $\frac{\sin x}{x}\cdot\frac{1}{\cos x} \to 1\cdot1 = 1$.

$\lim_{x\to0}\frac{1-\cos x}{x^2}$.
① $1-\cos x = 2\sin^2\frac{x}{2}$.
② $\frac{2\sin^2\frac{x}{2}}{x^2}=2\cdot\frac{\sin^2\frac{x}{2}}{(x/2)^2}\cdot\frac{1}{4} = \frac{1}{2}\cdot\left(\frac{\sin\frac{x}{2}}{x/2}\right)^2 \to \frac{1}{2}$.

**손에 새기는 표준값**:
- $\lim_{x\to0}\frac{\sin x}{x}=1$
- $\lim_{x\to0}\frac{\tan x}{x}=1$
- $\lim_{x\to0}\frac{1-\cos x}{x^2}=\frac{1}{2}$
![sinx/x → 1](graphs/13c-sinx-over-x.png)

## 예시 5: $\frac{0}{0}$ — $e$ 관련 표준극한

$\lim_{x\to0}\frac{e^x-1}{x}=1$.

$\lim_{x\to0}\frac{e^{2x}-1}{x}=2\cdot\frac{e^{2x}-1}{2x}\to2\cdot1=2$.

$\lim_{x\to0}\frac{\ln(1+x)}{x}$.
① $\frac{\ln(1+x)}{x}=\ln\big((1+x)^{1/x}\big)$.
② $x\to0$일 때 $(1+x)^{1/x}\to e$. → $\ln e=1$.

$\lim_{x\to0}\frac{a^x-1}{x}=\ln a$ ($a>0$).

**손에 새기는 표준값**:
- $\lim_{x\to0}\frac{e^x-1}{x}=1$
- $\lim_{x\to0}\frac{\ln(1+x)}{x}=1$
- $\lim_{x\to0}\frac{a^x-1}{x}=\ln a$

## 예시 6: $0\cdot\infty$ 꼴 — 곱을 나눗셈으로 바꾼다

$\lim_{x\to0^+} x\ln x$.

① $x\to0^+$ → $0$, $\ln x\to-\infty$. $0\cdot(-\infty)$ 꼴.
② $x\ln x = \frac{\ln x}{1/x}$. 이제 $\frac{-\infty}{\infty}$.
③ 치환 $t=1/x$ ($t\to\infty$): $x\ln x = \frac{\ln(1/t)}{t} = -\frac{\ln t}{t} \to 0$.
→ **0**.

$\lim_{x\to\infty} x\sin\frac{1}{x}$.
① $x\to\infty$, $\sin\frac{1}{x}\to0$. $\infty\cdot0$.
② $x\sin\frac{1}{x} = \frac{\sin(1/x)}{1/x}$. $t=1/x$ → $\frac{\sin t}{t}\to1$.
→ **1**.

> **여기까지**: $\frac{0}{0}$ 해결 무기 4종 — 찢어약분 / 켤레곱 / $\frac{\sin x}{x}\to1$ / $e^x$표준극한.
> $0\cdot\infty$는 $\frac{0}{0}$이나 $\frac{\infty}{\infty}$로 바꾼다.

## 예시 7: $\frac{\infty}{\infty}$ 유리함수 — 최고차항으로 나눈다
$x$가 무한대로 갈 때 분자도 무한대, 분모도 무한대. 누가 더 빨리 커지는지 겨루는 상황이다. 이 경쟁에서 이기는 쪽은 **차수가 가장 높은 항**이다. $x^{100}$은 $x^{99}$보다 훨씬 빠르게 무한대로 가고, 결국 최고차항만 남는다. 그래서 분자·분모를 최고차항으로 나누면, 나머지 항들은 전부 0으로 사라진다.
$\lim_{x\to\infty}\frac{3x^2+2x-1}{x^2+5}$.

① $x\to\infty$ → $\frac{\infty}{\infty}$. 분자·분모를 **최고차항 $x^2$**으로 나눈다.
② $=\frac{3+\frac{2}{x}-\frac{1}{x^2}}{1+\frac{5}{x^2}}$.
③ $x\to\infty$일 때 $\frac{2}{x},\frac{1}{x^2},\frac{5}{x^2}$ 모두 0으로.
④ → $\frac{3+0-0}{1+0}=3$.

**유리함수 $x\to\pm\infty$ 판정표**:

| 조건 | 결과 |
|:---|:---:|
| 분자 차수 > 분모 차수 | $\pm\infty$ (최고차 부호 따라) |
| 분자 차수 = 분모 차수 | $\frac{\text{최고차 계수}}{\text{최고차 계수}}$ |
| 분자 차수 < 분모 차수 | $0$ |

$\lim_{x\to\infty}\frac{2x^3-x}{x^2+4}$: 분자3>분모2 → $\frac{2x^3}{x^2}=2x\to\infty$.
$\lim_{x\to\infty}\frac{x^2+1}{x^3-2}$: 분자2<분모3 → $\frac{x^2}{x^3}=\frac{1}{x}\to0$.

## 예시 8: $x\to-\infty$ — 최고차항 홀수 거듭제곱 주의

$\lim_{x\to-\infty}\frac{3x^2+x}{2x^2-1}$.
① $x^2$으로 나누면 → $\frac{3}{2}$. $x^2$이 지배라 $x\to-\infty$도 동일.

$\lim_{x\to-\infty}\frac{2x^3+1}{x^2+1}$.
① 최고차항만: $\frac{2x^3}{x^2}=2x$.
② $x\to-\infty$ → $2x\to-\infty$. **음의 무한대로 발산.**

$\lim_{x\to-\infty}\frac{\sqrt{4x^2+1}}{x}$.
① $\sqrt{4x^2+1}=\sqrt{x^2(4+1/x^2)}=|x|\sqrt{4+1/x^2}$.
② $x\to-\infty$일 때 $|x|=-x$.
③ $\frac{-x\sqrt{4+1/x^2}}{x}=-\sqrt{4+1/x^2}\to-2$.

## 예시 9: 분모 0 → $\pm\infty$ — 좌우 부호로 판정

$\lim_{x\to2^+}\frac{1}{x-2}$ ($x$가 2보다 큰 쪽).

① 분모 $x-2\to0^+$ (아주 작은 양수). 분자 = 1.
② $\frac{1}{\text{아주 작은 양수}}\to+\infty$.

$\lim_{x\to2^-}\frac{1}{x-2}$ ($x$가 2보다 작은 쪽).
① 분모 $x-2\to0^-$ (아주 작은 음수).
② $\frac{1}{\text{아주 작은 음수}}\to-\infty$.

$\lim_{x\to2}\frac{1}{x-2}$: 왼쪽 $-\infty$, 오른쪽 $+\infty$ → **극한 없음**.

---

## 예시 10: 분모 0 — 부호표로 한 방에

$\lim_{x\to1}\frac{x+2}{(x-1)^2}$.
① 분모 $(x-1)^2\to0^+$ (제곱이라 항상 양수). 분자 $\to3$.
② $\frac{3}{0^+}\to+\infty$. **좌우 모두 $+\infty$** → 극한 존재 ($+\infty$).

$\lim_{x\to-1}\frac{x}{(x+1)(x-2)}$.
① $x\to-1^+$: 분자$\to-1$, 분모$\to(0^+)(-3)=0^-$. $\frac{-1}{0^-}\to+\infty$.
② $x\to-1^-$: 분자$\to-1$, 분모$\to(0^-)(-3)=0^+$. $\frac{-1}{0^+}\to-\infty$.
③ 좌우 다름 → 극한 없음.

$\lim_{x\to0}\frac{1}{x^2}$.
① 분모 $x^2\to0^+$ (좌우 모두). → $+\infty$.
② **제곱분모 = 항상 $+\infty$** (분자 양수일 때).

## 예시 11: $\infty-\infty$ — 유리화하거나 통분

무한대 빼기 무한대. 둘 다 무한대로 가고 있어서 누가 더 큰지 한눈에 안 보인다. 이건 **경합** 상태다. 이럴 땐 둘을 한 덩어리로 묶어야 판단할 수 있다. 묶는 방법은 두 가지: 루트가 있으면 **켤레를 곱해 유리화**, 분수면 **통분**. 둘 다 식을 하나로 합쳐서 진짜 경쟁 결과를 드러내는 전략이다.

$\lim_{x\to\infty}(\sqrt{x^2+x}-x)$.

① $\infty-\infty$ 꼴. **켤레를 곱해 유리화**.
② $\frac{(\sqrt{x^2+x}-x)(\sqrt{x^2+x}+x)}{\sqrt{x^2+x}+x} = \frac{(x^2+x)-x^2}{\sqrt{x^2+x}+x} = \frac{x}{\sqrt{x^2+x}+x}$.
③ $x$로 나누기: $\frac{1}{\sqrt{1+1/x}+1} \to \frac{1}{1+1}=\frac{1}{2}$.

$\lim_{x\to\infty}(\sqrt{x^2+3x}-\sqrt{x^2-2x})$.
① 유리화: $\frac{(x^2+3x)-(x^2-2x)}{\sqrt{x^2+3x}+\sqrt{x^2-2x}} = \frac{5x}{\sqrt{x^2+3x}+\sqrt{x^2-2x}}$.
② $x$로 나누기: $\frac{5}{\sqrt{1+3/x}+\sqrt{1-2/x}} \to \frac{5}{1+1}=\frac{5}{2}$.

## 예시 12: 함수 비교 — 누가 더 빠른가

$x\to\infty$일 때 **빠르기 순위**: 팩토리얼 $\gg$ 지수 $\gg$ 다항식 $\gg$ 로그.

$\lim_{x\to\infty}\frac{e^x}{x^{100}} = \infty$. (지수가 아무리 큰 다항식도 이긴다)

$\lim_{x\to\infty}\frac{\ln x}{x^{0.0001}} = 0$. (아무리 작은 다항식도 로그를 이긴다)

$\lim_{x\to\infty}\frac{2^x}{x!}=0$. (팩토리얼이 지수를 이긴다)

$\lim_{x\to\infty}\frac{x^{100}}{1.01^x}=0$. ($1.01^x$도 결국 $x^{100}$을 이긴다. 지수>다항식)

> **여기까지**: $\frac{\infty}{\infty}$는 최고차 나누기+차수비교. 분모0은 좌우부호.
> $\infty-\infty$는 유리화/통분. 지수>다항식>로그 속도 기억.

## 예시 13: $e$의 극한 — 모든 변주

$\lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n = e$.

변주 1: $\lim_{n\to\infty}\left(1+\frac{k}{n}\right)^n = e^k$.
이유: $\left(1+\frac{k}{n}\right)^n = \left[\left(1+\frac{k}{n}\right)^{n/k}\right]^k \to e^k$.

변주 2: $\lim_{x\to0}(1+x)^{1/x} = e$.

변주 3: $\lim_{n\to\infty}\left(\frac{n+1}{n}\right)^n = \lim\left(1+\frac{1}{n}\right)^n = e$.
$\lim_{n\to\infty}\left(\frac{n+3}{n-1}\right)^n$:
① $\frac{n+3}{n-1}=1+\frac{4}{n-1}$.
② $\left(1+\frac{4}{n-1}\right)^{n-1+1} = \left(1+\frac{4}{n-1}\right)^{n-1}\cdot\left(1+\frac{4}{n-1}\right) \to e^4\cdot1 = e^4$.

## 예시 15: 좌극한·우극한 — 한쪽씩 본다

$$
f(x)=\begin{cases}
x+2, & x<1 \\
x^2, & x\geq1
\end{cases}
$$

① 왼쪽($1^-$): $x<1$ 구간 → $f(x)=x+2$ → $1+2=3$.
② 오른쪽($1^+$): $x\geq1$ 구간 → $f(x)=x^2$ → $1^2=1$.

③ 좌극한 3 ≠ 우극한 1 → $\lim_{x\to1}f(x)$ **존재 안 함**.

## 예시 16: 절댓값이 들어간 극한

$\lim_{x\to0}\frac{|x|}{x}$.

① $x\to0^+$: $|x|=x$ → $\frac{x}{x}=1$.
② $x\to0^-$: $|x|=-x$ → $\frac{-x}{x}=-1$.
③ 좌우 다름 → **극한 없음**.

$\lim_{x\to2}\frac{|x-2|}{x-2}$.
① $x\to2^+$: $x-2>0$ → $|x-2|=x-2$ → $\frac{x-2}{x-2}=1$.
② $x\to2^-$: $x-2<0$ → $|x-2|=-(x-2)$ → $\frac{-(x-2)}{x-2}=-1$.
③ → **극한 없음**.

## 예시 17: 연속 — 세 조건을 확인한다

$f(x)$가 $x=a$에서 연속:
1. $f(a)$가 정의되어 있다.
2. $\lim_{x\to a}f(x)$가 존재한다 (좌=우).
3. $\lim_{x\to a}f(x)=f(a)$.

**제거 가능 불연속(구멍)**: $f(x)=\frac{x^2-1}{x-1}$.
$x=1$에서 정의 안 됨. 약분하면 $x+1\to2$. $(1,2)$에 구멍.

**점프 불연속**: $f(x)=[x]$. 정수에서 왼쪽 극한과 오른쪽 극한이 다름.

**무한 불연속**: $f(x)=\frac{1}{x}$. $x=0$에서 $\pm\infty$.

## 예시 18: 함수가 연속이 되도록 상수 정하기

$f(x)=\begin{cases} x^2+a, & x<2 \\ 3x-1, & x\geq2 \end{cases}$가 $x=2$에서 연속이려면?

① $\lim_{x\to2^-}f(x)=4+a$.
② $\lim_{x\to2^+}f(x)=6-1=5$.
③ $f(2)=5$.
④ $4+a=5$ → $a=1$.

## 예시 19: 샌드위치 정리 — 양쪽에서 조인다

어떤 함수는 직접 극한을 구하기 어렵다. 하지만 그 함수를 **두 개의 쉬운 함수 사이에 가둘 수 있다면**, 양쪽 함수의 극한이 같을 때 가운데 함수도 같은 극한값을 갖는다. 샌드위치처럼 위아래에서 꽉 눌러서 값이 도망갈 곳을 없애는 전략이다. 진동하는 함수를 다룰 때 특히 유용하다.

$\lim_{x\to0}x^2\sin\frac{1}{x}$.

① $\sin\frac{1}{x}$은 $-1$에서 $1$ 사이를 미친 듯이 오간다.
② 하지만 $-x^2 \leq x^2\sin\frac{1}{x} \leq x^2$ (양변에 $x^2\geq0$ 곱함).
③ $\lim_{x\to0}(-x^2)=0$, $\lim_{x\to0}x^2=0$.
④ 양쪽이 0으로 조여오니 가운데도 0.
→ **0**.

$\lim_{x\to\infty}\frac{\sin x}{x}$.
① $-1\leq\sin x\leq1$ → $-\frac{1}{x}\leq\frac{\sin x}{x}\leq\frac{1}{x}$.
② 양쪽 $\to0$ → **0**.

> **여기까지**: 좌극한≠우극한 → 극한 없음. 절댓값은 구간 나눠서.
> 연속 3조건. 샌드위치는 양쪽에서 같은 값으로 조이기.

## Part E: 궁극의 극한 결정 트리

```
극한 문제를 만나면
│
├── ① 일단 넣어본다 (직접대입)
│   └── 숫자 나오면 끝. 다음 꼴이면 해당 가지로:
│       · 0/0 → ②번
│       · ∞/∞ → ③번
│       · ∞-∞ → ④번
│       · 0·∞ → ⑤번
│       · 분모→0(분자≠0) → ⑥번
│
├── ② 0/0 꼴
│   ├── 다항식·유리식 → 인수분해해서 찢고 약분
│   ├── 루트 있음 → 켤레곱해서 유리화
│   ├── sin, cos → sinx/x →1, tanx/x →1, (1-cosx)/x² → 1/2
│   ├── e^x, ln → (e^x-1)/x →1, ln(1+x)/x →1
│   ├── 복잡 → t=x-a 치환해서 0으로 보내기
│   └── 그래도 안 되면 → 로피탈 (Phase 3에서)
│
├── ③ ∞/∞ 꼴
│   ├── 유리함수 → 최고차항으로 분자분모 나누기
│   │   결과: 분자>분모→±∞, 같으면 계수비, 분자<분모→0
│   ├── 지수/다항식 → 지수가 이긴다
│   ├── 지수/팩토리얼 → 팩토리얼이 이긴다
│   └── 루트 섞임 → √(x²+···)=|x|√(1+···)
│
├── ④ ∞-∞ 꼴
│   ├── √A - √B → 켤레곱 유리화
│   ├── 분수 - 분수 → 통분
│   └── 최고차항으로 묶어내기
│
├── ⑤ 0·∞ 꼴
│   └── 곱을 몫으로 바꾼다: f·g = f/(1/g) 또는 g/(1/f)
│       → 0/0이나 ∞/∞로 변신 → ②번 or ③번
│
├── ⑥ 분모→0 (분자≠0)
│   ├── 좌우 부호 확인해서 ±∞ 판정
│   └── 분모가 제곱이면 항상 +∞ (분자 양수일 때)
│
└── ⑦ 조각함수·절댓값·[x]
    └── 좌극한·우극한 따로. 다르면 극한 없음.
```

## 예시 20: 결정 트리 실전 분류

| $\frac{0}{0}$ 다항식 | $\lim_{x\to3}\frac{x^2-9}{x-3}$ | 인수분해 → $x+3\to6$ |
| $\frac{0}{0}$ 루트 | $\lim_{x\to4}\frac{\sqrt{x}-2}{x-4}$ | 분모 분해 → $\frac{1}{\sqrt{x}+2}\to\frac{1}{4}$ |
| $\frac{0}{0}$ 삼각 | $\lim_{x\to0}\frac{\sin7x}{x}$ | $7\cdot\frac{\sin7x}{7x}\to7$ |
| $\frac{\infty}{\infty}$ | $\lim_{x\to\infty}\frac{5x^3-2x}{2x^3+7}$ | $x^3$ 나누기 → $\frac{5}{2}$ |
| $\infty-\infty$ | $\lim_{x\to\infty}(\sqrt{x^2+x}-x)$ | 유리화 → $\frac{1}{2}$ |
| 분모0 | $\lim_{x\to0}\frac{1}{x^2}$ | 제곱분모 → $+\infty$ |
| 절댓값 | $\lim_{x\to0}\frac{|x|}{x}$ | 좌$=-1$, 우$=1$ → 없음 |
| $e$ 변주 | $\lim_{n\to\infty}(1+\frac{3}{n})^n$ | $=e^3$ |
| $0\cdot\infty$ | $\lim_{x\to0^+}x\ln x$ | $\frac{\ln x}{1/x}\to0$ |

## 자주 하는 실수

### 실수 1: $\frac{0}{0}$을 보고 "답 0"이라고 한다

**틀린 길**: "$\frac{0}{0}$이니까 0이다."

**왜 틀렸나**: $\frac{0}{0}$은 "판단 불가" 신호일 뿐. 분자 분모가 0으로 가는 속도 경쟁.

**옳은 길**: 찢고 약분하거나 켤레를 곱해 진짜 값을 찾는다.

---

### 실수 2: $\frac{\sin5x}{x}\to1$로 착각

**틀린 길**: "$\frac{\sin5x}{x}\to1$."

**왜 틀렸나**: $\frac{\sin\square}{\square}\to1$은 분자 분모의 $\square$가 **완전히 같을 때**만.

**옳은 길**: $\frac{\sin5x}{x}=5\cdot\frac{\sin5x}{5x}\to5\cdot1=5$.

---

### 실수 3: $x\to-\infty$에서 $\sqrt{x^2}=x$로 처리

**틀린 길**: "$\sqrt{x^2+1}$을 $x\sqrt{1+1/x^2}$로."

**왜 틀렸나**: $x\to-\infty$일 때 $x$는 음수. $\sqrt{x^2}=|x|=-x$.

**옳은 길**: $\sqrt{x^2+1}=|x|\sqrt{1+1/x^2}$. $x<0$이면 $-x\sqrt{1+1/x^2}$.

---

### 실수 4: 분모 0 근처에서 부호 확인 안 함

**틀린 길**: "$\lim_{x\to0}\frac{1}{x}=\infty$."

**왜 틀렸나**: 왼쪽은 $-\infty$, 오른쪽은 $+\infty$ → 극한 없음.

**옳은 길**: 좌우 따로. 제곱분모($x^2$)일 때만 좌우 같음.

---

### 실수 5: 약분하고 구멍을 잊는다

**틀린 길**: "$\frac{x^2-1}{x-1}=x+1$이니까 $x=1$에서도 $f(1)=2$."

**왜 틀렸나**: 원래 함수는 $x=1$에서 정의 안 됨. $x=1$에서 극한은 2지만, $f(1)$은 없다.

**옳은 길**: 극한값과 함숫값은 다르다. $x=1$은 구멍.

## 방금 우리가 한 일

```
① 일단 넣어본다 → 숫자 나오면 끝.

```

## 용어 정리

지금까지 우리는 "다가간다", "찢어 약분한다", "켤레를 곱한다", "끼워 넣는다", "조인다" 같은 쉬운 말만 썼다.
**방법은 이미 다 배웠다.** 이제 수학에서 쓰는 이름을 소개한다.

| 우리가 써온 말 | 수학 용어 | 기호/설명 |
|:------------:|:--------:|:---:|
| 다가간다 | 극한 | $\lim_{x\to a}f(x)$ |
| 오른쪽에서 | 우극한 | $\lim_{x\to a^+}$ |
| 왼쪽에서 | 좌극한 | $\lim_{x\to a^-}$ |
| 결정 안 된 꼴 | 부정형 | $\frac{0}{0},\frac{\infty}{\infty},\infty-\infty,0\cdot\infty$ |
| 찢어 약분 | 인수분해 후 약분 | $\frac{0}{0}$ 처리 |
| 켤레곱 | conjugate | $\sqrt{a}-\sqrt{b}$ 유리화 |
| 끼워넣기·조이기 | 샌드위치 정리(압착) | squeeze theorem |
| 끊기지 않음 | 연속 | continuous |
| 구멍 | 제거 가능 불연속 | removable discontinuity |
| 점프 | 도약 불연속 | jump discontinuity |
| 발산 | divergence | $\pm\infty$ or 진동 |
| 수렴 | convergence | 유한 극한값 |
| 빠르기 비교 | growth rate | 팩토리얼>지수>다항식>로그 |
