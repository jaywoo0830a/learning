## 예시 1: 숫자를 넣으면 숫자가 나온다

$f(x) = 2x + 3$이라는 상자를 떠올린다.

$x=1$을 넣는다. → 5가 나온다.
$x=4$를 넣는다. → 11이 나온다.
$x=-2$를 넣는다. → −1이 나온다.

들어갈 수 있는 수 전체를 **정의역**이라 부른다.
나오는 수 전체를 **치역**이라 부른다.
이 상자에는 아무 수나 넣을 수 있다. 아무 수나 나온다.

## 예시 2: 못 들어가는 수를 찾는다 — 네 가지 규칙

**규칙 1 — 제곱근**: $\sqrt{x-2}$.
제곱근 안은 0 이상이어야 한다.
$x-2 \geq 0$을 푼다. → $x \geq 2$.
2보다 작은 수는 못 넣는다.

**규칙 2 — 분모**: $\frac{1}{x^2-4}$.
분모가 0이면 터진다.
$x^2-4=0$을 푼다. → $x=2$, $x=-2$.
이 두 수만 빼고 다 넣을 수 있다.

**규칙 3 — 둘이 섞임**: $\frac{\sqrt{x+1}}{x-2}$.
제곱근 조건: $x+1 \geq 0$ → $x \geq -1$.
분모 조건: $x \neq 2$.
두 조건을 겹친다. → $[-1, 2)$와 $(2, \infty)$.

**규칙 4 — 로그**: $\log_3 (2x-5)$.
로그 오른쪽 식은 양수여야 한다.
$2x-5 > 0$을 푼다. → $x > \frac{5}{2}$.

> **여기까지**: 못 들어가는 수를 찾는 규칙 4가지를 배웠다.
> 제곱근 안 ≥ 0, 분모 ≠ 0, 로그 오른쪽 > 0, arcsin은 −1과 1 사이.

## 예시 3: 어떤 수가 튀어나오는가

$f(x) = x^2 + 2$.
$x^2$은 항상 0 이상이다. 거기에 2를 더한다.
→ 나오는 수는 항상 2 이상.

$g(x) = \frac{1}{x-1}$.
$x$가 1에 가까워지면 값이 ±무한대로 치솟는다.
$x$가 ±무한대로 가면 값은 0에 한없이 가까워진다.
→ 나오는 수: 0만 빼고 모든 실수.

$h(x) = \sqrt{4-x^2}$.
들어갈 수 있는 $x$는 −2부터 2까지다.
$x=0$일 때 꼭대기 2. $x=\pm2$일 때 바닥 0.
→ 나오는 수: 0부터 2까지.

> **여기까지**: 정의역과 치역을 찾았다. 정의역은 못 넣는 수를 빼서 찾는다.
> 치역은 그래프 꼭대기·바닥·점근선으로 찾는다.

## Part B: 함수를 연결하고 맞바꾼다

---

## 예시 4: 두 함수를 연결한다

$f(x)=2x+1$, $g(x)=x^2$를 연결한다.

**$f$에 $g$를 연결** — $(f \circ g)(x) = f(g(x))$.
① $g$에 $x$를 넣는다 → $x^2$이 나온다.
② 그 결과를 $f$에 밀어넣는다 → $2x^2+1$이 나온다.

**$g$에 $f$를 연결** — $(g \circ f)(x) = g(f(x))$.
① $f$에 $x$를 넣는다 → $2x+1$이 나온다.
② 그 결과를 $g$에 밀어넣는다 → $(2x+1)^2 = 4x^2+4x+1$.

순서가 바뀌면 결과가 다르다.

---

## 예시 5: 연결하면 정의역이 줄어든다

$f(x) = \sqrt{x}$, $g(x) = x-3$.

**$f \circ g$**: 안쪽 $g$에 $x$를 넣는다 → $x-3$.
바깥 $f$에 $x-3$을 밀어넣는다 → $\sqrt{x-3}$.
$f$는 0 이상만 받는다. $x-3 \geq 0$ → $x \geq 3$.
정의역이 $[3, \infty)$로 줄었다.

**$g \circ f$**: 안쪽 $f$에 $x$를 넣는다 → $\sqrt{x}$.
바깥 $g$에 $\sqrt{x}$를 밀어넣는다 → $\sqrt{x}-3$.
$f$의 정의역은 $[0,\infty)$. $g$는 어떤 값이든 받는다.
정의역은 그대로 $[0, \infty)$.

## 예시 6: 조각난 함수를 연결한다

$$
f(x) = \begin{cases}
x+1, & x < 0 \\
x^2, & x \geq 0
\end{cases}
$$

$g(x) = 2x-1$을 연결한다 — $(f \circ g)(x)$.

① $g$에 $x$를 넣는다 → $2x-1$이 나온다.
② 이 값이 0보다 작은지, 0 이상인지 본다.
③ 작으면 $f$의 윗규칙 $(x+1)$을 쓴다.
   크면 $f$의 아랫규칙 $(x^2)$을 쓴다.

$2x-1 < 0$ → $x < \frac{1}{2}$인 구간: 결과는 $(2x-1)+1 = 2x$.
$x \geq \frac{1}{2}$인 구간: 결과는 $(2x-1)^2$.

> **여기까지**: 합성은 안쪽부터 계산한다. 안쪽 결과를 바깥쪽에 밀어넣는다.

## 예시 7: 입력과 출력을 맞바꾼다 — 역함수

$f(x) = 3x-6$.

① $y = 3x-6$이라고 쓴다.
② $x$에 대해 푼다: $y+6 = 3x$ → $x = \frac{y+6}{3}$.
③ $y$ 자리에 $x$를 쓴다: $f^{-1}(x) = \frac{x+6}{3}$.

검산: $f$에 $f^{-1}(x)$를 넣는다.
$\frac{x+6}{3}$을 $3x-6$에 밀어넣는다 → $3 \cdot \frac{x+6}{3} - 6 = x$.
딱 $x$가 나온다. 맞다.

---

## 예시 8: 분수꼴의 역함수

$f(x) = \frac{2x+1}{x-3}$.

① $y = \frac{2x+1}{x-3}$.
② 양변에 $(x-3)$을 곱한다: $y(x-3) = 2x+1$.
③ 펼친다: $yx - 3y = 2x + 1$.
④ $x$ 항을 왼쪽에 모은다: $yx - 2x = 3y + 1$.
⑤ $x$로 묶는다: $x(y-2) = 3y + 1$.
⑥ $y-2$로 나눈다: $x = \frac{3y+1}{y-2}$.
⑦ $y$ 자리에 $x$를 쓴다: $f^{-1}(x) = \frac{3x+1}{x-2}$.

---

## 예시 9: 맞바꿀 수 없을 때 — 정의역을 싹둑 자른다

$f(x) = x^2$.

$x=2$를 넣으면 4. $x=-2$를 넣어도 4.
서로 다른 입력이 같은 출력을 낸다.
이대로 맞바꾸면 입력 하나에 출력이 둘이 된다. 함수가 아니다.

**오른쪽 절반만 남긴다**: 정의역을 $[0, \infty)$로 자른다.
→ 역함수 $f^{-1}(x) = \sqrt{x}$.

**왼쪽 절반만 남긴다**: 정의역을 $(-\infty, 0]$로 자른다.
→ 역함수 $f^{-1}(x) = -\sqrt{x}$.

> **여기까지**: 역함수는 $y=f(x)$를 $x$에 대해 풀고 $x$와 $y$를 맞바꾼다.
> 하나의 출력에 여러 입력이 있으면 정의역을 잘라야 한다.

## Part C: 그래프를 그리는 궁극의 순서

> **종이와 연필을 준비한다.** 아래 순서대로 한 단계씩 따라 그린다.

```
1단계 ─ 못 그리는 x를 찾는다 (정의역)
2단계 ─ 대칭이면 절반만 그린다
3단계 ─ 축과 만나는 점을 찍는다 (절편)
4단계 ─ 다가가지만 닿지 않는 선을 긋는다 (점근선)
5단계 ─ 축 위인지 아래인지 부호를 판정한다
6단계 ─ 찍은 점들을 곡선으로 잇는다
7단계 ─ 계단·톱니·조각이면 구간마다 따로 그린다
```

## 예시 10: 다항함수 — 대칭과 끝동작으로 그린다

$f(x) = x^3 - 4x$.

**1단계 — 정의역**: 다항함수는 모든 $x$에서 그릴 수 있다.

**2단계 — 대칭**: $f(-x)$를 계산한다.
$(-x)^3 - 4(-x) = -x^3 + 4x = -(x^3-4x) = -f(x)$.
→ 원점 대칭이다. 오른쪽만 그리고 빙 돌려 복사한다.

**3단계 — 절편**: $x$축과 만나는 점을 찾는다.
$x^3 - 4x = 0$ → $x(x^2-4) = 0$ → $x(x-2)(x+2) = 0$.
$x=-2, 0, 2$에서 $x$축을 가로지른다.
$x=0$을 넣으면 $f(0)=0$. 원점을 지난다.

**5단계 — 부호**: 근 −2, 0, 2로 구간 넷을 나눈다.
$x < -2$: 세 인수 모두 음수 → 곱은 음수 → 축 아래.
$-2 < x < 0$: 둘 음수 하나 양수 → 곱은 양수 → 축 위.
$0 < x < 2$: 하나 음수 둘 양수 → 곱은 음수 → 축 아래.
$x > 2$: 셋 다 양수 → 곱은 양수 → 축 위.

**끝동작**: $x \to \infty$ → $x^3$이 지배 → $+\infty$.
$x \to -\infty$ → $x^3$이 지배 → $-\infty$.

**6단계 — 연결**: 왼쪽 아래에서 출발 → $x=-2$에서 위로 축 통과 → 올라갔다 내려와 원점 통과 → $x=2$에서 위로 축 통과 → 오른쪽 위로.

![다항함수 y=x³-4x](graphs/01-cubic-poly.png)

## 예시 11: 유리함수 — 먼저 찢고 약분한다

$f(x) = \frac{x^2 - x - 2}{x^2 - 4}$.

**0단계 — 찢는다**: 분자 $(x-2)(x+1)$, 분모 $(x-2)(x+2)$.
$(x-2)$가 분자 분모에 둘 다 있다. → 약분된다.
$f(x) = \frac{x+1}{x+2}$, **단 $x \neq 2$**.

$x=2$는 원래 분모가 0이었다. 약분됐지만 들어갈 수 없다.
→ $(2, \frac{3}{4})$ 자리에 **빈 동그라미(구멍)**를 뚫는다.

**1단계 — 정의역**: $x \neq -2$ (분모 0), $x \neq 2$ (구멍).

**4단계 — 점근선**:
수직: $x=-2$에서 분모 0.
수평: $x \to \infty$일 때 $\frac{x+1}{x+2} \to 1$. → $y=1$.

**3단계 — 절편**:
$y$절편: $x=0$을 넣는다 → $f(0) = \frac{1}{2}$.
$x$절편: 분자=0 → $x = -1$.

**5단계 — 점근선 옆 부호**:
$x \to -2^+$일 때: 분자 음수, 분모 아주 작은 양수 → $-\infty$.
$x \to -2^-$일 때: 분자 음수, 분모 아주 작은 음수 → $+\infty$.

**6단계 — 연결**:
$x=-2$ 왼쪽: $+\infty$에서 출발, $x$절편 −1 지나, $y=1$에 아래서 다가감.
$x=-2$ 오른쪽: $-\infty$에서 출발, $y$절편 $\frac{1}{2}$ 지나, $y=1$에 아래서 다가감.
$x=2$에 빈 동그라미.

![구멍 있는 유리함수](graphs/02-rational-hole.png)

## 예시 12: 사선 점근선 — 나눗셈이 먼저다

$f(x) = \frac{x^2 + 2x}{x - 1}$.

**나눈다**: $x^2+2x$를 $x-1$로 나눈다.
몫 $x+3$, 나머지 3.
→ $f(x) = x + 3 + \frac{3}{x-1}$.

**수직 점근선**: 분모 0 → $x = 1$.
**사선 점근선**: $x \to \pm\infty$일 때 $\frac{3}{x-1} \to 0$.
→ 그래프는 $y = x+3$에 붙는다.

**절편**: $x=0$ → $f(0)=0$ (원점). $f(x)=0$ → $x(x+2)=0$ → $x=0,-2$.

**점근선 옆**: $x \to 1^+$ → $\frac{3}{x-1} \to +\infty$ → $+\infty$.
$x \to 1^-$ → $\frac{3}{x-1} \to -\infty$ → $-\infty$.

**그리는 순서**:
① 사선 $y=x+3$을 점선으로 먼저 긋는다.
② $x=1$에 수직 점선을 긋는다.
③ $(-2,0)$, $(0,0)$을 찍는다.
④ 점근선에 붙여 곡선을 그린다.

![사선 점근선](graphs/03-slant-asymptote.png)

## 예시 13: 쌍곡선 — $\frac{ax+b}{cx+d}$ 꼴

$f(x) = \frac{2x+1}{x-1}$.

**수직 점근선**: 분모 0 → $x=1$.
**수평 점근선**: $x \to \infty$, $\frac{2x}{x} \to 2$ → $y=2$.

**절편**:
$y$절편: $x=0$ → $y=-1$.
$x$절편: $2x+1=0$ → $x=-\frac{1}{2}$.

**중심**: 두 점근선의 교점 $(1,2)$.
그래프는 이 점을 기준으로 반대편이 똑같이 생긴 쌍곡선.

**점근선 접근 방향**:
$x \to 1^+$: $(+)/(+ 작은수) \to +\infty$.
$x \to 1^-$: $(+)/(- 작은수) \to -\infty$.
$x \to \infty$: $2 + \frac{3}{x-1}$ → 위에서 $y=2$로.
$x \to -\infty$: 아래서 $y=2$로.

## 예시 14: 무리함수 — 반쪽짜리 그래프

$f(x) = \sqrt{x-1} + 2$.

**시작점**: $x=1$에서만 루트 안이 0.
$f(1) = 0 + 2 = 2$. $(1, 2)$에 점을 찍는다.
$x < 1$은 루트 안이 음수 → 그래프 없다.

**증가**: $x$가 커지면 루트 값이 천천히 커진다.
전체 그래프는 오른쪽 위로 퍼진다.

**모양**: $y = \sqrt{x}$를 오른쪽으로 1, 위로 2 옮긴 것.

![제곱근 평행이동](graphs/04-sqrt-shifted.png)

> **여기까지**: 다항·유리·무리함수의 그래프를 7단계로 그렸다.
> 점근선이 뼈대, 절편이 관절, 부호가 살이다.

## 예시 15: 바닥함수 $[x]$ — 계단을 쌓는다

$[x]$는 $x$를 넘지 않는 가장 큰 정수다.

값을 찍어본다:
$[0] = 0$, $[0.3] = 0$, $[0.999] = 0$.
$[1] = 1$, $[1.7] = 1$.
$[-0.3] = -1$, $[-1] = -1$, $[-1.2] = -2$.

**규칙**: $[0, 1)$ 구간은 전부 높이 0.
$[1, 2)$ 구간은 전부 높이 1.
$[-1, 0)$ 구간은 전부 높이 −1.

**그리는 법**:
$[0, 1)$에 높이 0인 수평선을 긋는다. 오른쪽 끝 $(1, 0)$은 빈 동그라미.
$[1, 2)$에 높이 1인 수평선을 긋는다. 왼쪽 끝 $(1, 1)$은 채운 동그라미.
이걸 좌우로 반복한다.

![바닥함수 계단 그래프](graphs/05-floor-function.png)

$[2x]$: 계단 폭이 절반. $[0,0.5)$는 0, $[0.5,1)$은 1.
$[x]+[-x]$: 정수면 0, 아니면 −1.

## 예시 16: 분수부 $\{x\}$ — 톱니가 반복된다

$\{x\} = x - [x]$. 정수 부분을 떼어내고 소수만 남긴다.

$\{3.7\} = 0.7$, $\{5.0\} = 0$, $\{-1.2\} = -1.2 - (-2) = 0.8$.

**그리는 법**:
$[0,1)$ 구간: $\{x\} = x - 0 = x$. 원점에서 $(1,1)$ 직전까지 대각선.
$[1,2)$ 구간: $\{x\} = x - 1$. $(1,0)$에서 $(2,1)$ 직전까지 대각선.
$[-1,0)$ 구간: $\{x\} = x + 1$. $(-1,0)$에서 $(0,1)$ 직전까지 대각선.

톱니가 $[0,1)$ 높이로 무한히 반복된다. 1은 절대 안 찍힌다.

## 예시 17: 천장함수와 부호함수

**$\lceil x \rceil$**: $x$보다 작지 않은 가장 작은 정수.
$\lceil 3.2 \rceil = 4$, $\lceil -1.2 \rceil = -1$.
$(0,1]$에서 1, $(1,2]$에서 2. 바닥함수와 좌우가 반대.

**$\operatorname{sgn}(x)$**: 부호만 남긴다.
$x<0$이면 −1. $x=0$이면 0. $x>0$이면 1.
그래프는 −1, 0, 1 세 높이에 수평선 세 조각.

![천장함수와 부호함수](graphs/07-ceiling-sign.png)

> **여기까지**: $[x]$는 계단, $\{x\}$는 톱니, $\lceil x \rceil$은 역계단, $\operatorname{sgn}(x)$는 세 조각.
> 모두 구간마다 따로 그리는 것이 핵심이다.

## 예시 18: 그래프째로 옮긴다

기본 재료: $f(x) = |x|$. V자, 꼭짓점은 원점.

**오른쪽으로 3**: $f(x-3) = |x-3|$.
$x$ 자리에 $x-3$을 밀어넣는다. → 꼭짓점이 $(3,0)$으로 간다.

**위로 2**: $f(x)+2 = |x|+2$.
전체에 2를 더한다. → 꼭짓점이 $(0,2)$로 간다.

**왼쪽 1, 아래 4**: $f(x+1)-4 = |x+1|-4$.
→ 꼭짓점이 $(-1,-4)$로 간다.

**손으로**: 원래 그래프를 그리고, 꼭짓점을 옮겨서 다시 그린다.

## 예시 19: 뒤집고 접는다

재료: $f(x) = \sqrt{x}$. $x \geq 0$에서만 존재, 오른쪽 위로 퍼진다.

**$x$축으로 뒤집기**: $y = -\sqrt{x}$.
$(4, 2)$가 $(4, -2)$로 내려간다. 그래프가 아래를 향한다.

**$y$축으로 뒤집기**: $y = \sqrt{-x}$.
$x \leq 0$에서만 존재. 오른쪽 그래프의 거울상.

**원점으로 뒤집기**: $y = -\sqrt{-x}$.
두 번 뒤집은 것. 3사분면에만 존재.

## 예시 20: 축 아래를 접어 올린다

**$y = |f(x)|$ — $x$축 아래를 위로 접는다**.

재료: $f(x) = x^2 - 1$.
$x=0$에서 −1까지 내려가는 포물선.

$|f(x)| = |x^2-1|$:
$-1 < x < 1$ 구간은 원래 축 아래였다.
이 부분을 $x$축 기준으로 위로 접어 올린다.
→ $(-1,0)$과 $(1,0)$ 사이가 위로 볼록한 언덕.

**$y = f(|x|)$ — 오른쪽을 왼쪽에 복사한다**.

재료: $f(x) = x^2 - 2x$.
$f(|x|) = |x|^2 - 2|x| = x^2 - 2|x|$.

$x \geq 0$ 구간은 원래 그래프 그대로.
$x < 0$ 구간은 오른쪽 그래프를 $y$축에 비춰 붙인다.
→ W자 모양.

## 예시 21: 늘이고 줄인다

재료: $f(x) = \sin x$. 주기 $2\pi$, 높이 1.

**세로 늘이기**: $2\sin x$ → 높이가 2배.
**세로 줄이기**: $\frac{1}{2}\sin x$ → 높이가 반.
**가로 늘이기**: $\sin(\frac{x}{2})$ → 주기가 $4\pi$로 2배.
**가로 줄이기**: $\sin(2x)$ → 주기가 $\pi$로 반.

**규칙**: $a \cdot f(bx)$에서
$a$는 높이를 $a$배. $b$는 가로 속도를 $b$배.
$b>1$이면 쪼그라들고, $b<1$이면 늘어진다.

## 예시 22: 조각난 함수 — 따로 그려 붙인다

$$
f(x) = \begin{cases}
x+2, & x \leq 0 \\
4 - x^2, & 0 < x \leq 2 \\
\frac{1}{x-2}, & x > 2
\end{cases}
$$

**경계를 먼저 확인한다**:
$x=0$: 첫 조각은 2. 둘째 조각은 4. → **불연속!**
$(0,2)$에 채운 점, $(0,4)$에 빈 점을 찍는다.

$x=2$: 둘째 조각은 0에서 끝. 셋째 조각은 $x=2$에서 분모 0.
→ $x=2$는 수직 점근선.

**조각별로 그린다**:
조각1: $x \leq 0$, 직선 $y=x+2$. $(0,2)$에서 끝.
조각2: $0 < x \leq 2$, 아래로 볼록 포물선. $(0,4)$ 빈 점에서 시작, $(2,0)$에서 끝.
조각3: $x > 2$, $y=\frac{1}{x-2}$. $x=2$에 벽, 오른쪽으로 가며 0에 접근.

## 예시 23: $[x]$와 $\{x\}$가 섞이면

**$f(x) = x + [x]$**.

$x$를 $n + \delta$ ($0 \leq \delta < 1$, $n$은 정수)로 쓴다.
$f(x) = n + \delta + n = 2n + \delta$.

$[0,1)$: $f(x) = 0 + \delta = \delta$. $(0,0)$에서 $(1,1)$ 직전까지 대각선.
$[1,2)$: $f(x) = 2 + \delta$. $(1,2)$에서 $(2,3)$ 직전까지.
정수 $x$에서 값이 1만큼 뛴다.

**$f(x) = x\{x\} = x(x-[x])$**.
$[0,1)$: $x \cdot x = x^2$. 포물선 한 조각.
$[1,2)$: $x(x-1) = x^2-x$. 또 다른 포물선 한 조각.
정수에서 0으로 툭 떨어진다.

## 예시 24: 종합 — 절댓값 + 유리함수

$f(x) = \frac{|x-1|}{x^2-1}$.

**정의역**: 분모 $x^2-1 = (x-1)(x+2)$ → $x \neq 1, -1$.

**절댓값을 푼다**:
$x \geq 1$일 때 $|x-1| = x-1$ → $f(x) = \frac{x-1}{(x-1)(x+1)} = \frac{1}{x+1}$ ($x \neq 1$).
$x < 1$일 때 $|x-1| = -(x-1)$ → $f(x) = \frac{-1}{x+1}$ ($x \neq -1$).

**구멍**: $x=1$은 약분됐지만 원래 못 넣는 점.
$x \geq 1$ 쪽 식에 $x=1$을 넣으면 $\frac{1}{2}$.
→ $(1, \frac{1}{2})$에 빈 동그라미.

**점근선**: 수직 $x=-1$, 수평 $y=0$ (양쪽 다).

**그리기**:
$x < -1$: $y = -\frac{1}{x+1}$. $x \to -1^-$에서 $+\infty$, $x \to -\infty$에서 0.
$-1 < x < 1$: $y = -\frac{1}{x+1}$. $x \to -1^+$에서 $-\infty$, $x=0$에서 −1.
$x \geq 1$: $y = \frac{1}{x+1}$. 구멍 $(1,\frac{1}{2})$, $x \to \infty$에서 0.

![절댓값 유리함수 종합](graphs/11-abs-rational.png)

## 자주 하는 실수

### 실수 1: 역함수 합성 순서를 거꾸로 한다

**틀린 길**: "$(f \circ g)^{-1} = f^{-1} \circ g^{-1}$" ← 틀렸다.

**왜 틀렸나**: 합성의 역함수는 순서가 뒤집힌다.
$(f \circ g)^{-1} = g^{-1} \circ f^{-1}$.
신발 신고 양말 신었으면, 벗을 땐 양말 먼저, 신발 나중이다.

**옳은 길**: 역함수를 취하면 안쪽부터 바깥쪽 순서가 뒤집힌다.

---

### 실수 2: 약분한 뒤 구멍을 안 뚫는다

**틀린 길**: "$\frac{(x-1)(x+2)}{x-1} = x+2$니까 직선이다." ← 불완전.

**왜 틀렸나**: $x=1$은 원래 분모가 0이라 들어갈 수 없다.
약분된 식으로 $(1,3)$을 찍으면 안 된다.

**옳은 길**: $(1,3)$ 자리에 빈 동그라미를 뚫는다.

---

### 실수 3: $[x]$의 오른쪽 끝을 채운다

**틀린 길**: "$[1, 2]$에서 값이 1이다." ← 틀렸다.

**왜 틀렸나**: $[2.0]=2$다. $[x]=1$인 구간은 $1 \leq x < 2$.
$x=2$는 이미 다음 계단에 들어간다.

**옳은 길**: $[1,2)$ 구간의 오른쪽 끝은 빈 동그라미.

---

### 실수 4: 점근선을 절대 못 가로지른다고 믿는다

**틀린 길**: "수평 점근선 $y=1$이 있으니 $y=1$을 절대 안 지난다." ← 꼭 그렇진 않다.

**왜 틀렸나**: 점근선은 $x \to \pm\infty$에서의 동작만 말한다.
$x$가 유한할 때는 점근선을 가로지를 수 있다.
예: $y = \frac{x}{x^2+1}$은 $y=0$이 수평 점근선이지만 원점에서 관통.

**옳은 길**: $x \to \pm\infty$일 때만 점근선에 붙는다.

## 방금 우리가 한 일

```
① 들어갈 수 없는 x를 모두 찾는다. (제곱근·분모·로그·arcsin)
② 두 함수를 연결할 땐 안쪽부터 계산해 바깥쪽에 밀어넣는다.
③ 역함수는 y=f(x)를 x에 대해 풀고 x↔y를 맞바꾼다.
   하나의 출력에 여러 입력이 있으면 정의역을 자른다.
④ 그래프는 7단계로 그린다:
   정의역→대칭→절편→점근선→부호→연결→특수처리.
⑤ 변형은 기본 그래프를 옮기고(±h,±k),
   뒤집고(−f, f(−x)), 접고(|f|, f(|x|)), 늘인다(a·f(bx)).
⑥ [x]는 계단, {x}는 톱니, 조각함수는 구간별로 그린다.
```

## 용어 정리

지금까지 우리는 "넣는다", "밀어넣는다", "옮긴다", "뒤집는다", "접는다", "싹둑 자른다", "붙인다" 같은 쉬운 말만 썼다.
**방법은 이미 다 배웠다.** 이제 수학에서 쓰는 이름을 소개한다.

| 우리가 써온 말 | 수학 용어 | 기호/설명 |
|:------------:|:--------:|:---:|
| 넣을 수 있는 수 | 정의역 | domain |
| 나오는 수 | 치역 | range |
| 함수 연결 | 합성함수 | $(f \circ g)(x) = f(g(x))$ |
| 입력-출력 맞바꾸기 | 역함수 | $f^{-1}(x)$, $y=x$ 선 대칭 |
| 하나씩만 나온다 | 단사함수 | injective |
| 원점 대칭 | 기함수 | $f(-x) = -f(x)$ |
| $y$축 대칭 | 우함수 | $f(-x) = f(x)$ |
| 계단 함수 | 바닥함수 | $\lfloor x \rfloor = [x]$ |
| 올림 함수 | 천장함수 | $\lceil x \rceil$ |
| 소수만 남기기 | 분수부 | $\{x\} = x - [x]$ |
| 부호만 남기기 | 부호함수 | $\operatorname{sgn}(x)$ |
| 조각난 함수 | 조각 정의 함수 | piecewise |
| 다가가지만 닿지 않는 선 | 점근선 | asymptote |
| 수직 벽 | 수직 점근선 | $x=a$에서 분모 0 |
| 먼 곳 높이 | 수평 점근선 | $x \to \infty$ 때 $y$값 |
| 기울어진 길 | 사선 점근선 | 분자 차수 = 분모+1 |
| 그래프째 옮기기 | 평행이동 | $f(x-h)+k$ |
| 축으로 뒤집기 | 대칭이동 | $-f(x), f(-x)$ |
| 축 아래 접어올리기 | 절댓값 변형 | $\lvert f(x)\rvert$ |
| 오른쪽 복사 | 우함수화 | $f(\lvert x\rvert)$ |
| 늘이고 줄이기 | 스케일링 | $a \cdot f(bx)$ |
| 그래프 구멍 | 제거 가능 불연속 | removable discontinuity |
