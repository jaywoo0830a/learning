# 풀이 07: 실험식과 분자식

---

## 연습 1

Na 32.4%, S 22.5%, O 45.1%. (Na=23.0, S=32.1, O=16.0)

100g 기준 → g을 칸 숫자로 나누기:
Na mol = $32.4 \div 23.0 = 1.409$
S mol = $22.5 \div 32.1 = 0.701$
O mol = $45.1 \div 16.0 = 2.819$

가장 작은 값 0.701로 나누기:
Na = $1.409 \div 0.701 = 2.01 \approx 2$
S = $0.701 \div 0.701 = 1.00 = 1$
O = $2.819 \div 0.701 = 4.02 \approx 4$

**실험식: $\text{Na}_2\text{SO}_4$**

---

## 연습 2

실험식 $\text{CH}$, 실험식량 = 12.0 + 1.0 = 13.0
$n = 78.0 \div 13.0 = 6$

**분자식: $\text{C}_6\text{H}_6$**

## 연습 3

C 85.6%, H 14.4%. 분자량 56.0. (C=12.0, H=1.0)

100g 기준 → g을 칸 숫자로 나누기:
C mol = $85.6 \div 12.0 = 7.133$
H mol = $14.4 \div 1.0 = 14.4$

가장 작은 값 7.133으로 나누기: C = 1.00, H = 2.02 ≈ 2
실험식: $\text{CH}_2$, 실험식량 = 14.0
$n = 56.0 \div 14.0 = 4$

**실험식: $\text{CH}_2$, 분자식: $\text{C}_4\text{H}_8$**

## 연습 4

0.250mol → 22.0g → 분자량 = $22.0 \div 0.250 = 88.0$
C 54.5%, H 9.1%, O 36.4%. (C=12.0, H=1.0, O=16.0)

100g 기준 → g을 칸 숫자로 나누기:
C mol = $54.5 \div 12.0 = 4.542$
H mol = $9.1 \div 1.0 = 9.1$
O mol = $36.4 \div 16.0 = 2.275$

가장 작은 값 2.275로 나누기:
C = $4.542 \div 2.275 = 2.00$
H = $9.1 \div 2.275 = 4.00$
O = $2.275 \div 2.275 = 1.00$

실험식: $\text{C}_2\text{H}_4\text{O}$, 실험식량 = 24.0+4.0+16.0 = 44.0
$n = 88.0 \div 44.0 = 2$

**분자식: $\text{C}_4\text{H}_8\text{O}_2$**

## 연습 5: 태워서 분석

시료 3.00g → $\text{CO}_2$ 4.40g, $\text{H}_2\text{O}$ 1.80g

C: $\text{CO}_2$ mol = $4.40 \div 44.0 = 0.100$ mol → C mol = 0.100
C g = $0.100 \times 12.0 = 1.20$ g

H: $\text{H}_2\text{O}$ mol = $1.80 \div 18.0 = 0.100$ mol → H mol = $0.100 \times 2 = 0.200$
H g = $0.200 \times 1.0 = 0.20$ g

O: O g = $3.00 - 1.20 - 0.20 = 1.60$ g
O mol = $1.60 \div 16.0 = 0.100$ mol

비: C : H : O = 0.100 : 0.200 : 0.100
가장 작은 값 0.100으로 나누기: C=1, H=2, O=1

**실험식: $\text{CH}_2\text{O}$**

---

## 연습 6: 실전

시료 2.20g → $\text{CO}_2$ 4.40g, $\text{H}_2\text{O}$ 1.80g. 분자량 88.0.

C: $\text{CO}_2$ mol = $4.40 \div 44.0 = 0.100$ → C mol = 0.100, C g = 1.20g
H: $\text{H}_2\text{O}$ mol = $1.80 \div 18.0 = 0.100$ → H mol = 0.200, H g = 0.20g
O: O g = $2.20 - 1.20 - 0.20 = 0.80$ g → O mol = $0.80 \div 16.0 = 0.050$

비: C : H : O = 0.100 : 0.200 : 0.050
가장 작은 값 0.050으로 나누기: C=2, H=4, O=1

**(a) 실험식: $\text{C}_2\text{H}_4\text{O}$**
실험식량 = 24.0+4.0+16.0 = 44.0
$n = 88.0 \div 44.0 = 2$
**(b) 분자식: $\text{C}_4\text{H}_8\text{O}_2$**
