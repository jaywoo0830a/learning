# 풀이 02: g과 mol 바꾸기

---

## 연습 1

(a) NaCl = 23.0 + 35.5 = **58.5 g/mol**
(b) $\text{H}_2\text{SO}_4$ = 1.0×2 + 32.1 + 16.0×4 = 2.0 + 32.1 + 64.0 = **98.1 g/mol**
(c) $\text{Ca(OH)}_2$ = 40.1 + (16.0+1.0)×2 = 40.1 + 34.0 = **74.1 g/mol**
(d) $\text{C}_6\text{H}_{12}\text{O}_6$ = 12.0×6 + 1.0×12 + 16.0×6 = 72.0 + 12.0 + 96.0 = **180.0 g/mol**

---

## 연습 2

(a) NaCl 117g ÷ 58.5 = **2.00 mol**
(b) $\text{H}_2\text{SO}_4$ 196g ÷ 98.1 = **2.00 mol**
(c) NaOH 칸 숫자 = 23.0+16.0+1.0 = 40.0. 80g ÷ 40.0 = **2.00 mol**

---

## 연습 3

(a) NaCl 0.500mol × 58.5 = **29.3 g**
(b) $\text{H}_2\text{O}$ 칸 숫자 = 18.0. 5.00mol × 18.0 = **90.0 g**
(c) $\text{CO}_2$ 칸 숫자 = 44.0. 0.250mol × 44.0 = **11.0 g**

---

## 연습 4

$\text{C}_6\text{H}_{12}\text{O}_6$ 칸 숫자 = 180.0 g/mol
45.0g ÷ 180.0 = **0.250 mol**

---

## 연습 5

$\text{Al}_2(\text{SO}_4)_3$ 칸 숫자 = 27.0×2 + (32.1+16.0×4)×3 = 54.0 + 96.1×3 = 54.0 + 288.3 = 342.3
0.200mol × 342.3 = **68.5 g**

---

## 연습 6: 실전

(a) NaOH 칸 숫자 = 23.0+16.0+1.0 = 40.0. 0.250mol × 40.0 = **10.0 g**

(b) KOH 칸 숫자 = 39.1+16.0+1.0 = 56.1. 0.250mol × 56.1 = **14.0 g**

(c) 칸 숫자가 다르기 때문. NaOH는 40.0, KOH는 56.1. 같은 mol이어도 칸 숫자가 크면 g도 커진다.
