# 풀이 03: 반응식 계수 맞추기

---

## 연습 1

$\text{CH}_4 + \text{O}_2 \rightarrow \text{CO}_2 + \text{H}_2\text{O}$

복잡한 $\text{CH}_4$ 계수 1.
C: 왼1 오1 ✓ ($\text{CO}_2$ 계수 1)
H: 왼4 오2 → $\text{H}_2\text{O}$ 계수 2.
$\text{CH}_4 + \text{O}_2 \rightarrow \text{CO}_2 + 2\text{H}_2\text{O}$
O: 오른쪽 O=2+2=4 → $\text{O}_2$ 계수 2.

**$\text{CH}_4 + 2\text{O}_2 \rightarrow \text{CO}_2 + 2\text{H}_2\text{O}$**

---

## 연습 2

$\text{H}_2 + \text{O}_2 \rightarrow \text{H}_2\text{O}$

$\text{H}_2\text{O}$ 계수 1.
H: 왼2 오2 ✓. O: 왼2 오1 → $\text{H}_2\text{O}$ 계수 2.
$\text{H}_2 + \text{O}_2 \rightarrow 2\text{H}_2\text{O}$
H: 왼2 오4 → $\text{H}_2$ 계수 2.

**$2\text{H}_2 + \text{O}_2 \rightarrow 2\text{H}_2\text{O}$**

---

## 연습 3

$\text{Fe} + \text{Cl}_2 \rightarrow \text{FeCl}_3$

$\text{FeCl}_3$ 계수 1. Fe:1=1 ✓. Cl: 왼2 오3.
최소공배수 6 → $\text{FeCl}_3$ 계수 2 (오 Cl=6), $\text{Cl}_2$ 계수 3 (왼 Cl=6).
$\text{Fe} + 3\text{Cl}_2 \rightarrow 2\text{FeCl}_3$
Fe: 왼1 오2 → Fe 계수 2.

**$2\text{Fe} + 3\text{Cl}_2 \rightarrow 2\text{FeCl}_3$**

---

## 연습 4

$\text{NaOH} + \text{HCl} \rightarrow \text{NaCl} + \text{H}_2\text{O}$

Na:1=1, O:1=1, H:2=2, Cl:1=1. 이미 맞음.

**$\text{NaOH} + \text{HCl} \rightarrow \text{NaCl} + \text{H}_2\text{O}$**

---

## 연습 5

$\text{Ca(OH)}_2 + \text{H}_3\text{PO}_4 \rightarrow \text{Ca}_3(\text{PO}_4)_2 + \text{H}_2\text{O}$

복잡한 $\text{Ca}_3(\text{PO}_4)_2$ 계수 1.
Ca: 왼1 오3 → $\text{Ca(OH)}_2$ 계수 3.
$\text{PO}_4$: 왼1 오2 → $\text{H}_3\text{PO}_4$ 계수 2.
$3\text{Ca(OH)}_2 + 2\text{H}_3\text{PO}_4 \rightarrow \text{Ca}_3(\text{PO}_4)_2 + \text{H}_2\text{O}$
H: 왼 H=3×2+2×3=12. 오 H=2 → $\text{H}_2\text{O}$ 계수 6.
O 검산: 왼 O=3×2+2×4=14. 오 O=8+6=14 ✓.

**$3\text{Ca(OH)}_2 + 2\text{H}_3\text{PO}_4 \rightarrow \text{Ca}_3(\text{PO}_4)_2 + 6\text{H}_2\text{O}$**

## 연습 6: 실전

(a) $\text{C}_3\text{H}_8 + \text{O}_2 \rightarrow \text{CO}_2 + \text{H}_2\text{O}$
C:3 → $\text{CO}_2$ 3. H:8 → $\text{H}_2\text{O}$ 4. O: 오=6+4=10 → $\text{O}_2$ 5.
**$\text{C}_3\text{H}_8 + 5\text{O}_2 \rightarrow 3\text{CO}_2 + 4\text{H}_2\text{O}$**

(b) $\text{C}_2\text{H}_5\text{OH} + \text{O}_2 \rightarrow \text{CO}_2 + \text{H}_2\text{O}$
C:2 → $\text{CO}_2$ 2. H:6 → $\text{H}_2\text{O}$ 3. O: 오=4+3=7. 왼 $\text{C}_2\text{H}_5\text{OH}$에 O 1개 → $\text{O}_2$에서 6개 → 계수 3.
**$\text{C}_2\text{H}_5\text{OH} + 3\text{O}_2 \rightarrow 2\text{CO}_2 + 3\text{H}_2\text{O}$**

(c) $\text{C}_4\text{H}_{10} + \text{O}_2 \rightarrow \text{CO}_2 + \text{H}_2\text{O}$
C:4 → $\text{CO}_2$ 4. H:10 → $\text{H}_2\text{O}$ 5. O: 오=8+5=13 → $\text{O}_2$ 13/2. 전체 ×2.
**$2\text{C}_4\text{H}_{10} + 13\text{O}_2 \rightarrow 8\text{CO}_2 + 10\text{H}_2\text{O}$**
