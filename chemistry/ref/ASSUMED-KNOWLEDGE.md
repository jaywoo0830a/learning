## 3. Ions — Where ~70% of problem-blocking happens

### Polyatomic Ions (MUST memorize — assumed in naming, solutions, titration)

| Ion | Name | Ion | Name |
|---|---|---|---|
| $\text{NH}_4^+$ | ammonium | $\text{OH}^-$ | hydroxide |
| $\text{NO}_3^-$ | nitrate | $\text{NO}_2^-$ | nitrite |
| $\text{SO}_4^{2-}$ | sulfate | $\text{SO}_3^{2-}$ | sulfite |
| $\text{PO}_4^{3-}$ | phosphate | $\text{CO}_3^{2-}$ | carbonate |
| $\text{HCO}_3^-$ | bicarbonate | $\text{CH}_3\text{COO}^-$ (or $\text{C}_2\text{H}_3\text{O}_2^-$) | acetate |
| $\text{ClO}_4^-$ | perchlorate | $\text{ClO}_3^-$ | chlorate |
| $\text{ClO}_2^-$ | chlorite | $\text{ClO}^-$ | hypochlorite |
| $\text{CrO}_4^{2-}$ | chromate | $\text{Cr}_2\text{O}_7^{2-}$ | dichromate |
| $\text{MnO}_4^-$ | permanganate | $\text{CN}^-$ | cyanide |
| $\text{C}_2\text{O}_4^{2-}$ | oxalate | $\text{O}_2^{2-}$ | peroxide |

> **-ate vs -ite rule:** the -ate ion has one more oxygen than the -ite ion ($\text{NO}_3^-$ vs $\text{NO}_2^-$).
> **per- / hypo-:** per- = most oxygens, hypo- = fewest (chlorine family: $\text{ClO}_4^-$ > $\text{ClO}_3^-$ > $\text{ClO}_2^-$ > $\text{ClO}^-$).

### Transition Metal Charges (the basis of Roman-numeral naming)

| Metal | Possible charges | Notes |
|---|---|---|
| Ag | +1 | always +1 |
| Zn, Cd | +2 | always +2 |
| Fe | **+2, +3** | Fe²⁺ = ferrous, Fe³⁺ = ferric |
| Cu | **+1, +2** | Cu⁺ = cuprous, Cu²⁺ = cupric |
| Sn, Pb | **+2, +4** | Sn²⁺/Sn⁴⁺, Pb²⁺/Pb⁴⁺ |
| Cr | +2, +3, +6 | +6 appears in chromate/dichromate |
| Mn | +2, +4, +7 | +7 appears in permanganate |

### Main Monatomic Ions
- **+1:** $\text{Li}^+, \text{Na}^+, \text{K}^+, \text{Rb}^+, \text{Cs}^+$
- **+2:** $\text{Be}^{2+}, \text{Mg}^{2+}, \text{Ca}^{2+}, \text{Sr}^{2+}, \text{Ba}^{2+}$
- **+3:** $\text{Al}^{3+}$
- **−1:** $\text{F}^-, \text{Cl}^-, \text{Br}^-, \text{I}^-, \text{H}^-$
- **−2:** $\text{O}^{2-}, \text{S}^{2-}$
- **−3:** $\text{N}^{3-}, \text{P}^{3-}$

## 4. Acids & Bases

### The 7 Strong Acids (fully dissociate — $[\text{H}^+] = [\text{acid}]$)
$$\text{HCl},\ \text{HBr},\ \text{HI},\ \text{HNO}_3,\ \text{H}_2\text{SO}_4,\ \text{HClO}_4,\ \text{HClO}_3$$

### Representative Weak Acids (partial dissociation — need $K_a$)
$$\text{HF},\ \text{H}_3\text{PO}_4,\ \text{CH}_3\text{COOH},\ \text{H}_2\text{CO}_3,\ \text{H}_2\text{SO}_3,\ \text{H}_2\text{S}$$

### Strong Bases (fully dissociate)
$$\text{LiOH},\ \text{NaOH},\ \text{KOH},\ \text{RbOH},\ \text{CsOH},\ \text{Ca(OH)}_2,\ \text{Sr(OH)}_2,\ \text{Ba(OH)}_2$$
Weak base: $\text{NH}_3$ (the representative one)

### Acid Naming (assumed in naming problems)
| Anion ending | Acid prefix/suffix | Example |
|---|---|---|
| -ide → | **hydro-** + root + **-ic acid** | Cl⁻ → **HCl** hydrochloric acid |
| -ate → | root + **-ic acid** | NO₃⁻ → **HNO₃** nitric acid |
| -ite → | root + **-ous acid** | NO₂⁻ → **HNO₂** nitrous acid |

## 5. Reaction Types & Skeletons (where coefficients come from)

> Knowing the type fixes the **skeleton**; you only fill in the coefficients (Session 05).

| Type | Skeleton | Example |
|---|---|---|
| Synthesis | $A + B \to AB$ | $2\text{H}_2 + \text{O}_2 \to 2\text{H}_2\text{O}$ |
| Decomposition | $AB \to A + B$ | $2\text{H}_2\text{O}_2 \to 2\text{H}_2\text{O} + \text{O}_2$ |
| Single replacement | $A + BC \to AC + B$ | $\text{Zn} + \text{CuSO}_4 \to \text{ZnSO}_4 + \text{Cu}$ |
| Double replacement | $AB + CD \to AD + CB$ | $\text{AgNO}_3 + \text{NaCl} \to \text{AgCl}\downarrow + \text{NaNO}_3$ |
| Combustion | $\text{C}_x\text{H}_y + \text{O}_2 \to \text{CO}_2 + \text{H}_2\text{O}$ | $\text{C}_3\text{H}_8 + 5\text{O}_2 \to 3\text{CO}_2 + 4\text{H}_2\text{O}$ |
| Neutralization | acid + base → salt + water | $\text{HCl} + \text{NaOH} \to \text{NaCl} + \text{H}_2\text{O}$ |
| Precipitation | two solutions → insoluble solid | $\text{Pb(NO}_3\text{)}_2 + 2\text{KI} \to \text{PbI}_2\downarrow + 2\text{KNO}_3$ |

> **Combustion balance order is ALWAYS C → H → O.** Never start with oxygen.

### Metal Activity Series (the more active metal displaces the less active)
$$\text{K} > \text{Na} > \text{Ca} > \text{Mg} > \text{Al} > \text{Zn} > \text{Fe} > \text{Ni} > \text{Sn} > \text{Pb} > \text{H} > \text{Cu} > \text{Ag} > \text{Pt} > \text{Au}$$
> Above H = reacts with acids to release H₂. Below H = no reaction with acids.
> **Halogen activity:** $\text{F}_2 > \text{Cl}_2 > \text{Br}_2 > \text{I}_2$ (an upper halogen displaces a lower one).

## 6. Solubility Rules — the whole precipitation story

| Rule | Exceptions |
|---|---|
| ① All Group 1 (alkali metal) salts are soluble | none |
| ② All $\text{NH}_4^+$ salts are soluble | none |
| ③ All nitrates $\text{NO}_3^-$ are soluble | none |
| ④ Acetates $\text{CH}_3\text{COO}^-$ and chlorates $\text{ClO}_3^-$ are soluble | none |
| ⑤ Most halides (Cl⁻, Br⁻, I⁻) are soluble | **Ag⁺, Pb²⁺, Hg₂²⁺** |
| ⑥ Most sulfates $\text{SO}_4^{2-}$ are soluble | **Ca²⁺, Sr²⁺, Ba²⁺, Pb²⁺, Ag⁺** |
| ⑦ Most carbonates $\text{CO}_3^{2-}$ are **insoluble** | Group 1, NH₄⁺ are soluble |
| ⑧ Most phosphates $\text{PO}_4^{3-}$ are **insoluble** | Group 1, NH₄⁺ are soluble |
| ⑨ Most hydroxides $\text{OH}^-$ are **insoluble** | Group 1, Ba²⁺, Sr²⁺, Ca²⁺ (slightly) |
| ⑩ Most sulfides $\text{S}^{2-}$ are **insoluble** | Group 1, Group 2, NH₄⁺ are soluble |

> **Spectator ions** (stay in solution, cancel in net-ionic equations): $\text{Na}^+, \text{K}^+, \text{NO}_3^-, \text{ClO}_4^-, \text{CH}_3\text{COO}^-$.

## 7. Oxidation States (for redox & electrochemistry later)

| Rule | Content |
|---|---|
| ① Free element | 0 |
| ② Monatomic ion | = its charge |
| ③ F | always −1 |
| ④ O | usually −2 (peroxides −1, in $\text{OF}_2$ +2) |
| ⑤ H | usually +1 (in metal hydrides −1) |
| ⑥ Group 1 +1, Group 2 +2, Al +3 | fixed |
| ⑦ Sum in a neutral compound | 0 |
| ⑧ Sum in a polyatomic ion | = ion charge |

## 8. Concentration & pH Quick Reference (solutions, titration, acid/base)

- $\text{pH} = -\log[\text{H}^+]$ · $\text{pOH} = -\log[\text{OH}^-]$ · $\text{pH} + \text{pOH} = 14$
- $K_w = [\text{H}^+][\text{OH}^-] = 1.0\times10^{-14}$ (25°C)
- **Strong acid:** $[\text{H}^+] = [\text{acid}]$ (fully dissociates) → pH = $-\log[\text{acid}]$
- **Strong base:** $[\text{OH}^-] = [\text{base}]$ (per OH⁻)
- **Diprotic acid ($\text{H}_2\text{SO}_4$) titration:** moles of base needed = moles of acid × 2 (Session 08's key trap)
- Molarity $M = \frac{\text{mol}}{\text{L}}$ · $M_1V_1 = M_2V_2$ (dilution) · $M_aV_a = M_bV_b$ (neutralization, 1:1)
