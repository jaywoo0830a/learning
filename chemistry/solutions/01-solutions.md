### A6

**The trick:** A student measures a box: $L = 10.0$ cm, $W = 5.0$ cm, $H = 2.00$ cm. They calculate surface area twice: once with ×/÷ rule (wrong) and once with +/− rule (right).

Each face: $L \times W = 10.0 \times 5.0 = 50$ cm² (2 sf)
Each face: $L \times H = 10.0 \times 2.00 = 20.0$ cm² (3 sf)
Each face: $W \times H = 5.0 \times 2.00 = 10.0$ cm² (2 sf)

Total SA = $2(50 + 20.0 + 10.0) = 2(80.0) = 160.0$

**Wrong way (×/÷ rule on everything):**
Round each area first: 50 (2 sf), 20. (2 sf), 10. (2 sf)
$2(50 + 20 + 10) = 2(80) = 160$ → 160 cm² (2 sf)

**Right way (+/− rule first, then ×/÷):**
The sum $50 + 20.0 + 10.0 = 80.0$ uses the decimal places rule: 50 (0 dp), 20.0 (1 dp), 10.0 (1 dp) → 0 dp → **80**.
Then $2 \times 80 = 160$ → 160 cm² (2 sf from 80, but 2 is exact).

Wait, actually both give the same answer here. Let me think of a better example.

A simpler trap: A student calculates $12.5 - 1.5 = 11.0$ (subtraction → 1 dp). Then multiplies: $11.0 \times 3.0 = 33.0$.

If they used ×/÷ rule on the subtraction: $12.5 \times 3.0 = 37.5$ (3 sf) then $-1.5 \times 3.0 = -4.5$ (2 sf). $37.5 - 4.5 = 33.0$ (1 dp). Both methods give 33 but the intermediate steps differ.

A better clear example:
**Problem:** $(25.00 - 24.5) \times 10.0$

**Right way:**
$25.00 - 24.5 = 0.5$ (1 dp, limited by 24.5)
$0.5 \times 10.0 = 5.0$ (2 sf, limited by 0.5)

**Wrong way (×/÷ rule on everything):**
Treat the subtraction as multiplication: 25.00 (4 sf), 24.5 (3 sf) → "3 sf"
$25.00 - 24.5 = 0.5$ → "round to 3 sf" → $0.500$
$0.500 \times 10.0 = 5.00$ (3 sf)
Answer: 5.00 (wrong — overstates precision)

**Why wrong:** Subtraction uses decimal places, not sig figs. 25.00 has 2 dp, 24.5 has 1 dp → answer has 1 dp → 0.5 (1 sf). The ×/÷ rule only applies to the multiplication step, not the subtraction.

$$\boxed{\text{Right: } 5.0 \quad \text{Wrong: } 5.00 \text{ (overstates precision)}}$$
