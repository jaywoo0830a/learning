## Basic Drill Solutions (B1–B10)

### B1

(a) KCl — Potassium (Group 1, one charge) + chloride → **potassium chloride**
(b) MgO — Magnesium (Group 2, one charge) + oxide → **magnesium oxide**
(c) $Na_2S$ — Sodium (Group 1) + sulfide → **sodium sulfide**
(d) $CaBr_2$ — Calcium (Group 2) + bromide → **calcium bromide**

$$\boxed{\text{(a) Potassium chloride} \quad \text{(b) Magnesium oxide} \quad \text{(c) Sodium sulfide} \quad \text{(d) Calcium bromide}}$$

---

### B2

(a) $Fe_2O_3$ — O is −2, three O = −6. Two Fe must sum to +6 → each Fe is +3 → **iron(III) oxide**
(b) $CuCl_2$ — Cl is −1, two Cl = −2. Cu must be +2 → **copper(II) chloride**
(c) $SnCl_4$ — Cl is −1, four Cl = −4. Sn must be +4 → **tin(IV) chloride**
(d) $PbO$ — O is −2. Pb must be +2 → **lead(II) oxide**

$$\boxed{\text{(a) Iron(III) oxide} \quad \text{(b) Copper(II) chloride} \quad \text{(c) Tin(IV) chloride} \quad \text{(d) Lead(II) oxide}}$$

---

### B3

(a) $KNO_3$ — Potassium + nitrate → **potassium nitrate**
(b) $Na_2CO_3$ — Sodium + carbonate → **sodium carbonate**
(c) $NH_4Cl$ — Ammonium + chloride → **ammonium chloride**
(d) $CaSO_4$ — Calcium + sulfate → **calcium sulfate**

$$\boxed{\text{(a) Potassium nitrate} \quad \text{(b) Sodium carbonate} \quad \text{(c) Ammonium chloride} \quad \text{(d) Calcium sulfate}}$$

---

### B4

(a) Sodium phosphate — $Na^+$ + $PO_4^{3-}$ → criss-cross: $Na_3PO_4$

(b) Magnesium nitrate — $Mg^{2+}$ + $NO_3^-$ → criss-cross: $Mg(NO_3)_2$

(c) Iron(III) hydroxide — $Fe^{3+}$ + $OH^-$ → criss-cross: $Fe(OH)_3$

(d) Ammonium sulfate — $NH_4^+$ + $SO_4^{2-}$ → criss-cross: $(NH_4)_2SO_4$

$$\boxed{\text{(a) } Na_3PO_4 \quad \text{(b) } Mg(NO_3)_2 \quad \text{(c) } Fe(OH)_3 \quad \text{(d) } (NH_4)_2SO_4}$$

---

### B5

(a) $N_2O$ — Two N = di- + nitrogen, one O = monoxide → **dinitrogen monoxide**
(b) $SO_3$ — One S, three O = tri- + oxide → **sulfur trioxide**
(c) $CCl_4$ — One C, four Cl = tetra- + chloride → **carbon tetrachloride**
(d) $P_4O_{10}$ — Four P = tetra- + phosphorus, ten O = deca- + oxide → **tetraphosphorus decoxide**

$$\boxed{\text{(a) Dinitrogen monoxide} \quad \text{(b) Sulfur trioxide} \quad \text{(c) Carbon tetrachloride} \quad \text{(d) Tetraphosphorus decoxide}}$$

### B6

(a) $HNO_2$ — $NO_2^-$ is nitrite (-ite → -ous) → **nitrous acid**
(b) $H_2CO_3$ — $CO_3^{2-}$ is carbonate (-ate → -ic) → **carbonic acid**
(c) $HBr$ — $Br^-$ is bromide (-ide → hydro- + -ic) → **hydrobromic acid**
(d) $H_3PO_4$ — $PO_4^{3-}$ is phosphate (-ate → -ic) → **phosphoric acid**

$$\boxed{\text{(a) Nitrous acid} \quad \text{(b) Carbonic acid} \quad \text{(c) Hydrobromic acid} \quad \text{(d) Phosphoric acid}}$$

### B7

$HCl + NaOH \to NaCl + H_2O$ (1:1 ratio)

mol NaOH = $0.150 \times 0.02000 = 0.00300$ mol
mol HCl = $0.00300$ mol (1:1)
$M_{HCl} = 0.00300 / 0.02500 = 0.120$ M

$$\boxed{0.120 \text{ M HCl}}\quad\text{(3 sig figs)}$$

---

### B8

$H_2SO_4 + 2NaOH \to Na_2SO_4 + 2H_2O$ (2:1 ratio)

Using $n_a M_a V_a = n_b M_b V_b$:
$n_a = 2$, $n_b = 1$

$2 \times 0.200 \times 0.01500 = 1 \times 0.100 \times V_b$
$0.00600 = 0.100 \times V_b$
$V_b = 0.0600 \text{ L} = 60.0 \text{ mL}$

$$\boxed{60.0 \text{ mL of 0.100 M NaOH}}$$

---

### B9

(a) $HNO_3$ has only **one** acidic hydrogen → **monoprotic**.
(b) $H_3PO_4$ has **three** acidic hydrogens → **triprotic**.

(c) $H_3PO_4 + 3NaOH \to Na_3PO_4 + 3H_2O$

Using $n_a M_a V_a = n_b M_b V_b$:
$3 \times 0.100 \times 0.03000 = 1 \times M_b \times 0.09000$
$0.00900 = 0.09000 \times M_b$
$M_{NaOH} = 0.100$ M

$$\boxed{\text{(a) Monoprotic} \quad \text{(b) Triprotic} \quad \text{(c) } 0.100 \text{ M NaOH}}$$

### B12

(a) Formulas from names — hypochlorous acid has the FEWEST oxygens, perchloric the MOST:

| Name | Formula |
|:-----|:-------:|
| hypochlorous acid | $HClO$ |
| chlorous acid | $HClO_2$ |
| chloric acid | $HClO_3$ |
| perchloric acid | $HClO_4$ |

(b) Names from formulas:
$HClO$ = hypochlorous, $HClO_2$ = chlorous, $HClO_3$ = chloric, $HClO_4$ = perchloric

(c) **$HClO_4$ (perchloric acid)** is the strong acid. Its conjugate base $ClO_4^-$ has four oxygens that spread out (delocalize) the negative charge, making the base very stable — so the acid readily gives up its $H^+$.

$$\boxed{\text{(a) } HClO, HClO_2, HClO_3, HClO_4 \quad \text{(c) } HClO_4 \text{ — most oxygens stabilize the conjugate base}}$$

### A4

### A5

(a) mol NaOH = $0.150 \times 0.03560 = 0.005340$ mol.

$$\boxed{0.005340 \text{ mol NaOH}}$$

(b) Diprotic acid: each mole of acid reacts with 2 moles of NaOH.
mol acid = $0.005340 \div 2 = 0.002670$ mol.
Molar mass = $0.750 \text{ g} / 0.002670 \text{ mol} = 280.9$ g/mol.

$$\boxed{281 \text{ g/mol}}$$

(c) **Identification:** None of the listed acids match 280.9 g/mol:

- Malonic $H_2C_3H_2O_4$ = 104.06 — too low
- Succinic $H_2C_4H_4O_4$ = 118.09 — too low
- Tartaric $H_2C_4H_4O_6$ = 150.09 — too low

This must be a different diprotic acid not in the given list.

(d) If treated as monoprotic:
mol acid = $0.005340$ mol (no division by 2).
Molar mass = $0.750 / 0.005340 = 140.4$ g/mol.

$$\boxed{\text{Monoprotic assumption: } 140 \text{ g/mol (half of correct value)}}$$

The monoprotic assumption gives exactly **half** the correct molar mass — off by 50%. This is because treating a diprotic acid as monoprotic overestimates the moles of acid by 2×.

### A6

(a) $H_3PO_4 + 3NaOH \to Na_3PO_4 + 3H_2O$

$$\boxed{H_3PO_4 + 3NaOH \to Na_3PO_4 + 3H_2O}$$

(b) **Step-by-step method:**
mol NaOH = $0.200 \times 0.04500 = 0.00900$ mol.
mole ratio: $3$ NaOH : $1$ $H_3PO_4$.
mol $H_3PO_4 = 0.00900 \div 3 = 0.00300$ mol.
$M_{H_3PO_4} = 0.00300 / 0.02500 = 0.120$ M.

$$\boxed{0.120 \text{ M } H_3PO_4}$$

(c) **Shortcut ($n_a M_a V_a = n_b M_b V_b$):**
$n_a = 3$ (triprotic), $n_b = 1$.
$3 \times M_a \times 0.02500 = 1 \times 0.200 \times 0.04500$
$0.07500 \times M_a = 0.00900$
$M_a = 0.120$ M. ✓ Matches.

(d) **First equivalence point** (only one $H^+$ neutralized):
$H_3PO_4 + NaOH \to NaH_2PO_4 + H_2O$ (1:1 ratio)
mol $H_3PO_4 = 0.00300$ mol → needs $0.00300$ mol NaOH.
$V_{NaOH} = 0.00300 / 0.200 = 0.01500$ L = 15.00 mL.

$$\boxed{15.00 \text{ mL of NaOH (first eq. point)}}$$

### A9

(a) $H_2SO_4 + Ba(OH)_2 \to BaSO_4\downarrow + 2H_2O$

Note: $Ba(OH)_2$ provides 2 $OH^-$ per formula unit, so it reacts 1:1 with $H_2SO_4$ (which provides 2 $H^+$).

(b) mol $Ba(OH)_2 = 0.150 \times 0.02400 = 0.003600$ mol
From 1:1 ratio: mol $H_2SO_4 = 0.003600$ mol
$M_{H_2SO_4} = 0.003600 / 0.01000 = 0.360$ M

(c) $Ba(OH)_2$ — **barium hydroxide**

(d) $BaSO_4$ — **barium sulfate**

(e) $BaSO_4$ is insoluble — it precipitates out of solution during the titration. This means:
- The endpoint may be harder to detect because the precipitate can mask indicator color changes.
- The reaction goes to completion because the product is continuously removed from solution.
- This is actually a **precipitation titration**, not just an acid-base titration.

$$\boxed{\text{(a) } H_2SO_4 + Ba(OH)_2 \to BaSO_4 + 2H_2O \quad \text{(b) } 0.360 \text{ M} \quad \text{(c) Barium hydroxide} \quad \text{(d) Barium sulfate}}$$
