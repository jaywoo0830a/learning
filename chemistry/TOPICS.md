# Chemistry Curriculum v3: From Calculator to Oxtoby

> **Ultimate Goal:** Build a seamless bridge from high school chemistry through AP Chemistry into foundational organic/inorganic chemistry — culminating in the ability to reason from the microscopic world (atoms, molecules, electrons) to macroscopic observations (reactions, properties, energy changes) as presented in **Oxtoby's Principles of Modern Chemistry**.
>
> **Method:** **Problems first, concepts later.** Every session opens with a calculation you cannot yet do — by the end, you can do 20+ problems at exam speed.
>
> **Primary Reference:** *Everything You Need to Ace Chemistry in One Big Fat Notebook* (Jennifer Swanson) — **100% coverage**.
>
> **Secondary References:** AP Chemistry Course & Exam Description, Oxtoby's *Principles of Modern Chemistry*, Clayden's *Organic Chemistry*, Housecroft's *Inorganic Chemistry*.
>
> **Drill Structure:** Every session = 5~8 worked examples + **10 Basic Drills** + **10 Advanced Drills** = exam-level fluency.
>
> **Scale:** ~40 sessions, approximately 100 hours. ~800 total drill problems across the curriculum.
>
> **Duration:** 120–180 minutes per session (50% worked examples, 50% drills).

---

## Course Philosophy: From Macroscopic → Microscopic

The entire curriculum follows this progression:

```
Phase 1: MACROSCOPIC NUMBERS     → Measurements, units, moles (calculation first)
Phase 2: MACROSCOPIC REACTIONS   → Stoichiometry, solutions, gases (calculation first)
Phase 3: MICROSCOPIC STRUCTURE   → Atoms, bonding, periodic trends (concept + calculation)
Phase 4: MICROSCOPIC ENERGETICS  → Thermodynamics, equilibrium, kinetics (calculation + reasoning)
Phase 5: MACRO FROM MICRO        → Acids/bases, electrochemistry, nuclear (micro explains macro)
Phase 6: BEYOND GENERAL          → Organic fundamentals, inorganic fundamentals
Phase 7: TO OXTDBY               → Synthesis, multi-concept integration, microscopic reasoning
```

### Learning Mode Shift Across Phases

```
Phase 1-2: CALCULATION FIRST
  "Do the math. Speed and accuracy are the only goals."
  → If you can't calculate it, you haven't learned it.

Phase 3-5: CONCEPT + CALCULATION
  "Calculate, then interpret what the number means."
  → You must BOTH calculate correctly AND explain the physical meaning.

Phase 6-7: MEMORIZE + REASON
  "Learn the patterns, then reason from structure to property."
  → If you can't draw the structure or mechanism, you haven't learned it.

Phase 8: SYNTHESIS
  "Integrate everything — recall, calculate, reason, and explain."
  → If you can't connect concepts across domains, you haven't learned it.
```

> **In Phases 1-2, a student who can calculate but can't explain has succeeded.**
>
> **In Phases 6-7, a student who can explain but can't draw a mechanism has failed.**
>
> **The bar shifts progressively from pure calculation to pure reasoning.**

## The Identity of This Curriculum — v3

```
What sets this curriculum apart:

1. CALCULATION FIRST (Phases 1-2):
   Open every topic with a problem the learner cannot yet solve.
   Work through it with numbers. Extract the pattern. Automate with drills.
   Only then read the concept chapter.
   No explaining required yet — just fast, accurate calculation.

2. CONCEPT + CALCULATION (Phases 3-5):
   Build the microscopic picture of atoms, bonds, and electrons.
   Use that picture to explain every macroscopic observation.
   "Why is copper conductive? Why is water liquid? Why is HCl a strong acid?"
   Calculation fluency is still required, but now interpretation is also tested.

3. MEMORIZE + REASON (Phases 6-7):
   Organic chemistry: nomenclature, functional groups, mechanisms.
   Inorganic chemistry: coordination, transition metals, solid state.
   These are not "extras" — they are the natural extension of the same principles.
   Calculation fades; structure drawing and mechanism reasoning become central.

4. SYNTHESIS (Phase 8):
   Multi-concept synthesis problems require integrating stoichiometry,
   thermodynamics, kinetics, equilibrium, and spectroscopy into a single solution.
   This is what Oxtoby demands — and this curriculum builds to it.
   Learners must fluidly recall facts, perform calculations, and reason from first principles.

The Learning Mode Progression:
```
Phase  | Primary Mode      | Secondary Mode    | Bar
1-2    | Calculate         | Recognize patterns | Can you do the math? Speed + accuracy.
3-5    | Calculate + Reason| Interpret numbers | Can you calculate AND explain what it means?
6-7    | Memorize + Reason | Draw + predict    | Can you draw the structure AND predict properties?
8      | Synthesize        | Integrate + infer | Can you connect everything into one solution?
```

40 sessions x 20 drills = 800 problems.
Phase 1-2: ~160 drill problems (pure calculation fluency)
Phase 3-5: ~220 drill problems (calculation + interpretation)
Phase 6-7: ~120 drill problems (structure + mechanism reasoning)
Phase 8: ~80 drill problems (multi-concept synthesis)

The calculator comes first. The concept seals it in.
The microscopic picture makes it permanent.
The synthesis makes it Oxtoby-ready.
```

## How to Use This Curriculum

### For Each Session:

1. **Open the session file.** Attack the Opening Problem. Get stuck.
2. **Work through the worked examples.** The pattern reveals itself through numbers.
3. **Read the Common Trap.** Watch someone else make the mistake — so you won't.
4. **Extract the 3-Step Procedure.** Write it down. Memorize it.
5. **Do 10 Basic Drills.** Speed and fluency. Under 2 minutes each by the end.
6. **Do 10 Advanced Drills.** Exam readiness. Multi-step. Time pressure.
7. **Read the Big Fat Notebook chapter.** Concepts lock into place.
8. **For Phase 6-7:** Read the corresponding organic/inorganic text.
9. **For Phase 8:** Attempt the Oxtoby-style problem. If stuck, review prerequisite sessions.
