# 화학 교재 작성 가이드라인 v6

> **v6 핵심:** 뇌과학·언어학 원칙을 화학 교재에 맞게 도입.
> "종이 위 어느 숫자를, 어떻게 조작하는지"로만 구성. 추상 설명 절대 금지.

---

## 1. 유일한 원칙

```
추상적이거나 현실과 동떨어진 설명 → 절대 금지.
"종이 위 어느 숫자를, 어떻게 조작하는지"로만 설명 → 허용.

모든 설명은 이 틀을 따른다:
"왼쪽에 있는 ___ 숫자를 ___ 한다. 그러면 ___ 가 나온다."

"왜"는 Phase 6까지 묻지 않는다.
Phase 1~5의 모든 설명은 "이렇게 조작하라"로 끝난다.
```

---

## 2. 설명 금지 목록

아래 개념들에 대해 **어떤 비유·은유·직관 설명도 하지 않는다.** 오직 계산법만 제시한다.

| 개념 | 금지된 설명 (예시) | 허용된 설명 |
|:---:|------|------|
| 몰 | "묶음", "계란 판", $N_A$, 역사적 정의 | **g ÷ 주기율표 숫자 = mol. mol × 숫자 = g.** |
| 엔탈피 | "열 함량", "에너지 저장고" | **$\Delta H = \sum n\Delta H_f^\circ(P) - \sum n\Delta H_f^\circ(R)$. 음수=발열.** |
| 엔트로피 | **"무질서도"** | **$\Delta G = \Delta H - T\Delta S$에 넣는 숫자.** |
| $\Delta G$ | "자발성의 원동력" | **$\Delta G<0$: 반응 진행. $\Delta G>0$: 반응 안 함.** |
| $K$ (평형 상수) | "반응의 선호도" | **$K = [\text{P}]^{\text{계수}}/[\text{R}]^{\text{계수}}$. $K>1$: 생성물 우세.** |
| 르샤틀리에 | **"계가 스트레스에 저항" (의인화 금지)** | **농도↑ → 소비. 압력↑ → 기체 적은 쪽. 온도↑ → 흡열 쪽.** |
| 산화수 | "진짜 전하", "전자 소유권" | **규칙 5가지로 할당. 합 = 분자 전하. 변하면 산화환원.** |
| $E^\circ$ (전위) | "전자 압력" | **$E^\circ_{\text{cell}} = E^\circ_{\text{환원}} - E^\circ_{\text{산화}}$. 양수=자발.** |
| 오비탈 | "전자 구름", "확률 분포" | **Phase 6에서만 등장. 계산 없음.** |
| 공명 | "구조가 왔다 갔다" | **Phase 6에서만 등장. 계산 없음.** |

## 3. 직관적 위치 기반 설명법

**모든 방법은 "숫자가 적힌 위치 + 조작법"으로만 설명한다.** 변수명을 앞세우지 않는다.

| 금지된 설명 스타일 | 허용된 설명 스타일 |
|:---|------|
| $p^+ = Z$ | "주기율표 칸 위에 적힌 정수를 그대로 쓴다" |
| $n = A - Z$ | "원소 기호 왼쪽 위 숫자에서, 위 정수를 뺀다" |
| mol = g ÷ M | "저울로 잰 g을, 주기율표 칸 숫자로 나눈다" |
| $n = m/M$ | "g을 주기율표 숫자로 나누면 mol이 나온다" |
| $M_1V_1 = M_2V_2$ | "처음 농도×처음 부피 = 나중 농도×나중 부피. 세 개 알면 나머지 하나가 나온다" |

**작성 규칙:**
1. 주어는 항상 **종이 위 위치**: "왼쪽 위 숫자", "주기율표 아래 숫자", "화살표 오른쪽 계수"
2. 동사는 항상 **구체적 조작**: "더한다", "뺀다", "곱한다", "나눈다", "비교한다", "그대로 쓴다"
3. 추상 기호($Z$, $A$, $M$, $n$)는 **괄호 안에만** 표기. 본문 주역 금지.
4. 표 컬럼 헤더도 위치 기반 말로: "위 정수", "왼쪽 위", "칸 숫자", "오른쪽 계수"

## 4. 언어적 명료성 원칙 — "따라 하면 저절로 된다"

### 4-1. 문장 구조: 동작 → 대상 → 결과

```
[조건이 있다면 먼저] → [무엇을] → [어떻게 한다] → [그러면 무엇이 나온다]
```

| 나쁨 | 좋음 |
|------|------|
| "몰 질량으로 나누면 몰 수를 구할 수 있다" | "g을 칸 숫자로 나눈다. 그러면 mol이 나온다." |
| "계수의 비율을 이용하여 생성물의 몰을 계산한다" | "아는 mol에 (오른쪽 계수 ÷ 왼쪽 계수)를 곱한다. 그러면 구할 mol이 나온다." |
| "한계 반응물을 결정한 후 이론 수득량을 구한다" | "각 mol을 자기 계수로 나눈다. 몫이 가장 작은 쪽이 먼저 사라진다. 그쪽으로 생성물 g을 계산한다." |

핵심: **한 문장 = 동작 하나**. 두 동작은 문장을 나눈다.

### 4-2. 어휘 일관성: 하나의 동작 = 하나의 단어

| 동작 | 이 단어만 쓴다 | 이 단어는 안 쓴다 |
|:---:|:---:|------|
| + | "더한다" | "합한다", "덧셈한다" |
| − | "뺀다" | "차를 구한다", "마이너스한다" |
| × | "곱한다" | "곱셈한다", "곱하기한다" |
| ÷ | "나눈다" | "나눗셈한다", "나누기한다" |
| 대입 | "넣는다" | "대입한다", "치환한다" |
| 비교 | "비교한다" | "견준다", "대조한다" |
| 측정 | "잰다" | "측정한다", "계량한다" |
| 균형 | "맞춘다" | "균형을 잡는다", "밸런싱한다" |

### 4-3. 조건문: 앞에, 짧게

"만약 ~라면"은 문장 맨 앞에. 중간에 끼워 넣지 않는다.

| 나쁨 | 좋음 |
|------|------|
| "분모가 0이 아니면 약분한다" | "분모가 0인지 확인한다. 0이 아니면 약분한다." |
| "$K>1$이면 생성물 우세" | "$K$를 계산한다. 1보다 크면 생성물 쪽에 더 많다." |

### 4-4. 부정문 금지 — "하지 않는다" 대신 "~한다"

| 나쁨 | 좋음 |
|------|------|
| "아래첨자를 바꾸지 마라" | "아래첨자는 그대로 둔다. 앞 계수만 바꾼다." |
| "몰 질량 계산 시 괄호를 빠뜨리지 않는다" | "$\text{Ca(OH)}_2$: Ca 1개, O 2개, H 2개임을 반드시 센다." |

### 4-5. 추상→구체: 예를 먼저

| 나쁨 | 좋음 |
|------|------|
| "몰 농도 M = mol ÷ L" | "3.0mol의 NaCl을 물에 녹여 2.0L로 만들었다. 3.0 ÷ 2.0 = 1.5M." 그 후에 "이것이 M = mol ÷ L이다." |

## 5. 뇌과학·언어학 원칙

### 5-1. 3단위 청킹

작업기억은 3~5개 항목만 붙잡을 수 있다. **모든 절차는 3단계로 쪼갠다.**

| 나쁨 (5단계) | 좋음 (3단계) |
|------|------|
| ① g 잰다 ② 칸 숫자로 나눈다 ③ 계수 비 곱한다 ④ 칸 숫자 곱한다 ⑤ 답 | **[큰 단계 1]** g→mol: g ÷ 칸 숫자 **[큰 단계 2]** mol→mol: ×계수비 **[큰 단계 3]** mol→g: ×칸 숫자 |

### 5-2. 예측 오류 각인 — "자주 하는 실수" 코너

뇌는 예측과 다른 정보가 들어올 때 가장 강하게 반응한다.
"자주 하는 실수" 코너는 이 원리를 의도적으로 활용한다:

1. **먼저 틀린 방법을 보여준다** — "많은 사람이 이렇게 한다: (틀린 계산)"
2. **틀린 이유를 한 줄로** — "하지만 이러면 ___가 안 맞는다."
3. **그다음 옳은 방법을 보여준다.**

### 5-3. 운동 언어 — "손이 기억하게 한다"

추상적 조작도 신체 동사로 표현한다.

| 추상 동사 | 운동 동사 |
|------|------|
| "대입한다" | "그 자리에 **밀어넣는다**" |
| "소거한다" | "**지운다**" |
| "추출한다" | "**꺼낸다**" |
| "적정한다" | "한 방울씩 **떨어뜨린다**" |
| "정리한다" | "**모은다**" |
| "희석한다" | "물을 **붓는다**" |

### 5-4. 생성 효과 — 구성형 문제

연습문제 중 최소 2개는 템플릿 적용이 아닌 **구성형**으로.

| 템플릿 적용 (약함) | 구성형 (강함) |
|------|------|
| "NaCl 117g은 몇 mol?" | "칸 숫자가 58.5인 물질 A가 117g 있다. 물질 A의 mol을 구하고, 물질 A가 NaOH라면 몇 g이 필요한지 구하라." |
| "$K_c$를 계산하라" | "평형에서 생성물이 반응물보다 많은 상황을 $K_c$ 값으로 증명하라." |

### 5-5. 처리 유창성 + 초두·최신 효과

- 같은 리듬 반복: "~을 ~한다. 그러면 ~이 나온다."
- 문장 20자 이내
- 가장 중요한 단계를 첫 번째에
- 세션 마지막 "오늘의 절차" 카드로 두 번 각인

### 5-6. 지식의 저주 방지

- [ ] "당연히", "쉽게", "자명하게" 금지
- [ ] 변수·기호 사용 전에 위치 기반으로 먼저 소개
- [ ] 중간 단계 건너뛰기 금지

## 6. 세션 구조

```
[들어가기] 이 계산이 왜 필요한가 (실용적 이유만)
[방법]     ① → ② → ③ 절차. 각 단계마다 구체적 숫자 예시.
           "자주 하는 실수" 코너 최소 1개 (틀린 방법 먼저 → 이유 → 옳은 방법)
[연습]     5~6문제. 마지막 "실전". 최소 2개는 구성형.
[용어]     "방법은 이미 다 배웠다. 이름만 소개한다."
[카드]     코드 블록 3~4단계.
```

## 7. 시간 배분 원칙

| 복잡도 | 기준 | 시간 |
|:---:|------|:---:|
| 간단 | 공식 1~2개, 연산 1~2단계 | **최소 10분** |
| 보통 | 절차 3~4단계, 하위 개념 1~2개 | **30~60분** |
| 복잡 | 다단계 파이프라인, 하위 개념 3개 이상 | **최대 2시간** |

- 계산 2단계 이하 → 간단 (10~30분)
- 계산 3~4단계 → 보통 (30~90분)
- 계산 5단계 이상 or 독립 하위 주제 3개 이상 → 복잡 (90~120분)
