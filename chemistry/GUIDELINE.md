# 화학 교재 작성 가이드라인 v5

> **v5 핵심:** 모든 설명은 "종이 위 어느 숫자를, 어떻게 조작하는지"로만 구성한다.
> "왼쪽 위 숫자에서 오른쪽 숫자를 뺀다" 같은 위치 기반 지시문만 허용.
> 추상 기호($Z$, $n$)는 용어 정리 전까지 괄호 안에만 쓴다.

---

## 1. 유일한 원칙

```
추상적이거나 현실과 동떨어진 설명 → 금지.
"종이 위 어느 숫자를, 어떻게 조작하는지"로만 설명 → 허용.

모든 설명은 이 틀을 따른다:
"왼쪽에 있는 ___ 숫자를 ___ 한다. 그러면 ___ 가 나온다."

"왜"는 Phase 6까지 묻지 않는다.
Phase 1~5의 모든 설명은 "이렇게 조작하라"로 끝난다.
```

---

## 1.5 직관적 위치 기반 설명법 (v5 신설)

**모든 방법은 "숫자가 적힌 위치 + 조작법"으로만 설명한다.** 변수명을 앞세우지 않는다.

| 금지된 설명 스타일 | 허용된 설명 스타일 |
|:---|------|
| $p^+ = Z$ | "주기율표 칸 위에 적힌 정수를 그대로 쓴다" |
| $n = A - Z$ | "원소 기호 왼쪽 위 숫자에서, 주기율표 위 정수를 뺀다" |
| mol = g ÷ M | "저울로 잰 g을, 주기율표 칸에 적힌 숫자로 나눈다" |
| $n = m/M$ | "g을 주기율표 숫자로 나누면 mol이 나온다" |

**작성 규칙:**
1. 설명문의 주어는 항상 **종이 위 위치**다: "왼쪽 위 숫자", "주기율표 아래 숫자", "화살표 오른쪽 숫자"
2. 동사는 항상 **구체적 조작**이다: "더한다", "뺀다", "곱한다", "나눈다", "비교한다", "그대로 쓴다"
3. 추상 기호($Z$, $A$, $M$, $n$)는 **괄호 안에만** 표기한다. 본문 설명의 주역이 될 수 없다.
4. 표의 컬럼 헤더도 위치 기반 말로 쓴다: "위 정수", "왼쪽 위", "칸 숫자"

## 2. 설명 금지 목록

아래 개념들에 대해 **어떤 비유·은유·직관 설명도 하지 않는다.** 오직 계산법만 제시한다.

| 개념 | 금지된 설명 (예시) | 허용된 설명 |
|:---:|------|------|
| 몰 | "묶음", "계란 판", $N_A$, 역사적 정의 | **g ÷ 주기율표 숫자 = mol. mol × 숫자 = g.** |
| 엔탈피 | "열 함량", "에너지 저장고" | **$\Delta H = \sum n\Delta H_f^\circ(P) - \sum n\Delta H_f^\circ(R)$. 음수=발열.** |
| 엔트로피 | **"무질서도"** | **$\Delta G = \Delta H - T\Delta S$에 대입하는 숫자.** |
| $\Delta G$ | "자발성의 원동력" | **$\Delta G<0$: 반응 진행. $\Delta G>0$: 반응 안 함.** |
| $K$ (평형 상수) | "반응의 선호도", 속도론적 유도 | **$K = [\text{P}]^{\text{계수}}/[\text{R}]^{\text{계수}}$. $K>1$: 생성물 우세.** |
| 르샤틀리에 | **"계가 스트레스에 저항" (의인화 금지)** | **농도↑ → 소비. 압력↑ → 기체 적은 쪽. 온도↑ → 흡열 쪽.** |
| 산화수 | "진짜 전하", "전자 소유권" | **규칙 5가지로 할당. 합 = 분자 전하. 변하면 산화환원.** |
| $E^\circ$ (전위) | "전자 압력", "반쪽 전지 절대값" | **$E^\circ_{\text{cell}} = E^\circ_{\text{환원}} - E^\circ_{\text{산화}}$. 양수=자발.** |
| 오비탈 | "전자 구름", "확률 분포" | **Phase 6에서만 등장. 계산 없음.** |
| 공명 | "구조가 왔다 갔다" | **Phase 6에서만 등장. 계산 없음.** |

## 3. 세션 구조

```
[들어가기] 이 계산이 왜 필요한가 (실용적 이유만)
[방법]     ① → ② → ③ 절차. 각 단계마다 구체적 숫자 예시.
[연습]     5~6문제. 마지막 "실전".
[용어]     "방법은 이미 다 배웠다. 이름만 소개한다."
[카드]     코드 블록 3~4단계.
```

## 3.5 시간 배분 원칙

세션 시간은 방법의 복잡도에 따라 유기적으로 배분한다.

| 복잡도 | 기준 | 시간 |
|:---:|------|:---:|
| 간단 | 공식 1~2개, 연산 1~2단계 | **최소 10분** |
| 보통 | 절차 3~4단계, 하위 개념 1~2개 | **30~60분** |
| 복잡 | 다단계 파이프라인, 하위 개념 3개 이상 | **최대 2시간** |

**판단 규칙:**
- 계산 단계가 2단계 이하 → 간단 (10~30분)
- 계산 단계가 3~4단계 → 보통 (30~90분)
- 계산 단계가 5단계 이상이거나, 독립된 하위 주제 3개 이상 → 복잡 (90~120분)

**총 시간은 78시간에서 유기적으로 재분배한다.** 각 세션의 실제 필요 시간에 맞춰 총량이 조정된다.

## 4. 언어 규칙

- 본문 설명은 반드시 **위치 기반**으로: "주기율표 위 숫자", "왼쪽 위 숫자", "오른쪽 계수"
- 추상 기호($Z$, $M$, $n$)는 괄호 안에만. 본문 주역 금지.
- 절차는 "~한다, ~해라" 명령형
- 모든 예시는 구체적 물질: NaCl, $\text{H}_2\text{O}$, $\text{CH}_4$ (Na, Cl 같은 추상 변수 금지)
- 표 헤더도 위치 기반 쉬운 말: "위 정수", "왼쪽 위", "칸 숫자", "오른쪽 계수"
