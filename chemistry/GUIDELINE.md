# 화학 교재 작성 가이드라인 v1

> 모든 세션은 이 문서의 규칙을 따른다. 수학 GUIDELINE v4를 기반으로 화학에 맞게 조정.

---

## 1. 핵심 원칙: 방법 → 경험 → 용어

```
[방법 제시 + 충분한 예제] → [연습 (문제만)] → [맨 마지막에 용어와 기호 공개]
        약 60%                 30%              마지막 10%
```

용어와 기호는 세션 끝에서 처음 등장. 세션 제목은 개념명이 아닌 **방법 설명형**.

---

## 2. 언어 규칙

### 2-1. 용어 금지 (용어 정리 전까지)

| 금지 | 대신 사용 |
|:----:|------|
| 원자, 분자, 이온, 전자, 양성자 | "알갱이", "가장 작은 조각", "전기를 띤 조각", "무거운 알갱이" (처음 배울 때만) |
| 몰, 아보가드로 수 | "개수를 세는 묶음 단위", "$6.02 \times 10^{23}$개 묶음" |
| VSEPR, 루이스 구조, 옥텟 | "모양 예측법", "점 찍기 그림", "8개 채우기 규칙" |
| 산, 염기, pH, $K_a$ | "신맛 물질", "쓴맛 물질", "산의 세기 숫자", "산이 나누어지는 정도" |
| 엔탈피, 엔트로피, 깁스 자유에너지 | "열 출입량", "무질서도", "스스로 일어날지 판단하는 값" |
| 르샤틀리에 원리, 평형 상수 | "평형 이동 규칙", "반응의 치우침 정도" |

### 2-2. 이미 배운 용어는 쓸 수 있다

한 세션에서 해금된 용어는 이후 모든 세션에서 자유롭게 사용한다. 예: 세션 01에서 "원자"를 해금했으면, 세션 02부터는 "원자"라고 쓸 수 있다.

### 2-3. 절차는 명령형·구어체

"~한다, ~해라" 형태. 실험 절차도 동일한 어조로.

## 3. 풀이 분리 규칙

연습문제 풀이는 세션 파일에 포함하지 않는다. `solutions/` 폴더에 별도 풀이집.

```
chemistry/sessions/phase1/
├── 01-counting-subatomic-particles.md
├── 02-writing-electron-configurations.md
└── solutions/
    ├── 01-solutions.md
    └── 02-solutions.md
```

세션 파일의 연습문제 끝에는 반드시:

```markdown
> 풀이: [풀이집](solutions/0X-solutions.md#연습-N)
```

## 5. 표와 그림 규칙

### 5-1. 표

표 헤더에 전문 용어 금지. 구체적인 숫자와 물질명 사용.

잘못된 예:
| 원소 | 전기음성도 | 이온화 에너지 |
|:---:|:--------:|:----------:|

올바른 예:
| 원소 | 전자 당기는 세기 | 전자 떼어내는 데 필요한 힘 |
|:---:|:------------:|:------------------:|

### 5-2. 분자 구조 그림

ASCII art나 간단한 도형으로 표현.

```
물 분자의 굽은 모양:
    O
   / \
  H   H
 (비공유 전자쌍 2개는 보이지 않음)
```

## 6. 예시 규칙

### 6-1. 구체적인 물질로 시작

항상 실제 원소, 실제 화합물을 사용한다.

| 추상 (금지) | 구체 (사용) |
|:----------:|------|
| "금속 M과 비금속 X" | "나트륨(Na)과 염소(Cl)" |
| "산 HA" | "아세트산($CH_3COOH$)" |
| "반응물 A, B" | "$H_2$와 $O_2$" |

### 6-2. 좋은 예시 물질 고르는 법

1. **일상에서 접하는 물질**: 물, 소금, 설탕, 베이킹소다, 식초
2. **위험하지 않은 물질**: 진한 황산 대신 묽은 식초
3. **결과가 깔끔한 반응**: 계수가 복잡하지 않은 것

### 6-3. 들어가기는 실생활 현상

"왜 아이스팩을 흔들면 차가워질까?"
"왜 콜라 뚜껑을 따면 거품이 날까?"
"왜 비누로 기름때가 씻길까?"

## 7. "자주 하는 실수" 코너

모든 세션에 최소 1개 포함.

화학에서 흔한 실수 예시:
- 몰과 몰농도 혼동
- 산화수 계산에서 수소를 +1이 아닌 -1로
- ICE 표에서 변화량 부호 반대로
- pH 계산에서 $-\log$ 대신 $\log$ 사용

## 9. 용어 정리

```markdown
이제 화학에서 쓰는 이름을 소개한다.

| 우리가 써온 말 | 화학 용어 |
|:------------:|:--------:|
```
