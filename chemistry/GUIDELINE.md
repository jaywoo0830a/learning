# 화학 교재 작성 가이드라인 v4

> **v4 핵심:** 추상적·현실과 다른 설명은 하지 않는다. 모든 것은 계산 절차다.

---

## 1. 유일한 원칙

```
추상적이거나 현실과 동떨어진 설명 → 금지.
순수한 계산 절차만 → 허용.

"왜"는 Phase 6까지 묻지 않는다.
Phase 1~5의 모든 설명은 "이렇게 계산하라"로 끝난다.
```

---

## 2. 설명 금지 목록

아래 개념들에 대해 **어떤 비유·은유·직관 설명도 하지 않는다.** 오직 계산법만 제시한다.

| 개념 | 금지된 설명 (예시) | 허용된 설명 |
|:---:|------|------|
| 몰 | "묶음", "계란 판", $N_A$, 역사적 정의 | **g ÷ 주기율표 숫자 = mol. mol × 숫자 = g.** |
| 엔탈피 | "열 함량", "에너지 저장고" | **$\Delta H = \sum n\Delta H_f^\circ(P) - \sum n\Delta H_f^\circ(R)$. 음수=발열.** |
| 엔트로피 | **"무질서도"** | **$\Delta G = \Delta H - T\Delta S$에 대입하는 숫자.** |
| $\Delta G$ | "자발성의 원동력" | **$\Delta G<0$: 반응 진행. $\Delta G>0$: 반응 안 함.** |
| $K$ (평형 상수) | "반응의 선호도", 속도론적 유도 | **$K = [\text{P}]^{\text{계수}}/[\text{R}]^{\text{계수}}$. $K>1$: 생성물 우세.** |
| 르샤틀리에 | **"계가 스트레스에 저항" (의인화 금지)** | **농도↑ → 소비. 압력↑ → 기체 적은 쪽. 온도↑ → 흡열 쪽.** |
| 산화수 | "진짜 전하", "전자 소유권" | **규칙 5가지로 할당. 합 = 분자 전하. 변하면 산화환원.** |
| $E^\circ$ (전위) | "전자 압력", "반쪽 전지 절대값" | **$E^\circ_{\text{cell}} = E^\circ_{\text{환원}} - E^\circ_{\text{산화}}$. 양수=자발.** |
| 오비탈 | "전자 구름", "확률 분포" | **Phase 6에서만 등장. 계산 없음.** |
| 공명 | "구조가 왔다 갔다" | **Phase 6에서만 등장. 계산 없음.** |

## 3. 세션 구조

```
[들어가기] 이 계산이 왜 필요한가 (실용적 이유만)
[방법]     ① → ② → ③ 절차. 각 단계마다 구체적 숫자 예시.
[연습]     5~6문제. 마지막 "실전".
[용어]     "방법은 이미 다 배웠다. 이름만 소개한다."
[카드]     코드 블록 3~4단계.
```

---

## 4. 언어 규칙

- 표·예시에 전문 용어 대신 쉬운 말 (용어 정리 전까지)
- 절차는 "~한다, ~해라" 명령형
- 모든 예시는 구체적 물질: NaCl, $H_2O$, $CH_4$ (Na, Cl 같은 추상 변수 금지)
