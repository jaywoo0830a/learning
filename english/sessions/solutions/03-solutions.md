## Basic Drills

### B1. (수학)
The length of the side of a square is equal to the diameter of a circle inscribed in the square. The area of the square is equal to the square of the length of its side. The area of the circle is equal to one quarter of pi times the square of the diameter.

- **수식어 묶기:**
  - S1: ( `of the side` ) ( `of a square` ) → length를 꾸밈 / ( `of a circle` ) ( `inscribed in the square` ) → diameter를 꾸밈
  - S2: ( `of the length of its side` ) → square를 꾸밈
  - S3: ( `of the diameter` ) → square를 꾸밈
- **topic sentence:** S1 (정사각형 변과 내접원 지름의 관계)
- **단락 요약 (2줄):** 정사각형에 내접한 원의 지름은 정사각형의 한 변의 길이와 같다. 정사각형 넓이는 변², 원 넓이는 (π/4)×지름²이다.

### B2. (물리)
The speed of the car moving along the straight road increased steadily. The acceleration of the car, which was constant, was measured by the driver. The distance traveled by the car was recorded at regular intervals.

- **수식어 묶기:**
  - S1: ( `moving along the straight road` ) → car를 꾸밈
  - S2: [ `which was constant` ] → acceleration을 꾸밈
  - S3: ( `traveled by the car` ) → distance를 꾸밈
- **topic sentence:** S1 (속도 증가)
- **단락 요약 (2줄):** 직선 도로를 달리는 자동차의 속도는 꾸준히 증가했다. 가속도는 일정했고, 자동차가 이동한 거리는 일정 간격으로 기록되었다.

### B3. (생물)
The blood vessels carrying oxygen-rich blood away from the heart are called arteries. The vessels carrying blood back to the heart are called veins. The tiny vessels connecting arteries and veins are called capillaries, and it is here that the exchange of materials with the tissues occurs.

- **수식어 묶기:**
  - S1: ( `carrying oxygen-rich blood away from the heart` ) → blood vessels를 꾸밈
  - S2: ( `carrying blood back to the heart` ) → vessels를 꾸밈
  - S3: ( `connecting arteries and veins` ) → vessels를 꾸밈
- **topic sentence:** S1 (동맥 정의)
- **단락 요약 (2줄):** 산소가 풍부한 혈액을 심장 밖으로 운반하는 혈관은 동맥, 심장으로 되돌리는 혈관은 정맥이라 한다. 동맥과 정맥을 잇는 가는 혈관이 모세혈관이며, 여기서 조직과 물질 교환이 일어난다.

### B4. (화학)
The electrons in the outermost shell of an atom determine its chemical properties. Atoms with a full outermost shell, such as the noble gases, are very stable. Atoms that need one or two electrons to complete their shell tend to form bonds with other atoms.

- **수식어 묶기:**
  - S1: ( `in the outermost shell` ) ( `of an atom` ) → electrons를 꾸밈
  - S2: ( `with a full outermost shell` ) → atoms를 꾸밈, ( `such as the noble gases` ) → 예시
  - S3: [ `that need one or two electrons to complete their shell` ] → atoms를 꾸밈
- **topic sentence:** S1 (바깥 껍질 전자와 화학적 성질)
- **단락 요약 (2줄):** 원자의 가장 바깥 껍질에 있는 전자가 화학적 성질을 결정한다. 바깥 껍질이 가득 찬 원자(비활성 기체)는 매우 안정하고, 전자가 1~2개 부족한 원자는 다른 원자와 결합하려 한다.

### B5. (수학)
The point at which the derivative of a function is zero is called a critical point. The value of the function at a critical point may be a local maximum, a local minimum, or neither. The classification of the critical point is determined by the sign of the second derivative.

- **수식어 묶기:**
  - S1: [ `at which the derivative of a function is zero` ] → point를 꾸밈
  - S2: ( `of the function` ) ( `at a critical point` ) → value를 꾸밈
  - S3: ( `of the critical point` ) → classification을 꾸밈, ( `of the second derivative` ) → sign을 꾸밈
- **topic sentence:** S1 (임계점 정의)
- **단락 요약 (2줄):** 도함수가 0이 되는 점을 임계점이라고 한다. 임계점에서 함수값은 국소 최대·국소 최소·그 외 중 하나이며, 이차 도함수의 부호로 분류한다.

## Advanced Drills

### A1. (물리)
The magnitude of the force exerted by a spring is proportional to the distance by which the spring is stretched or compressed. This relationship, known as Hooke's law, holds as long as the spring is not stretched beyond its elastic limit. When the spring is released, it returns to its original length. The energy stored in the stretched spring is equal to the work done to stretch it.

- **수식어 묶기:**
  - S1: ( `exerted by a spring` ) → force를 꾸밈, [ `by which the spring is stretched or compressed` ] → distance를 꾸밈
  - S2: ( `known as Hooke's law` ) → relationship를 꾸밈, [ `as long as ... its elastic limit` ] → 조건
  - S4: ( `stored in the stretched spring` ) → energy를 꾸밈, ( `done to stretch it` ) → work를 꾸밈
- **topic sentence:** S1 (훅의 법칙)
- **단락 요약 (3줄):** 용수철이 가하는 힘의 크기는 늘어나거나 압축된 거리에 비례한다(훅의 법칙). 이 관계는 탄성 한계를 넘지 않을 때만 성립하며, 용수철을 놓으면 원래 길이로 돌아온다. 늘어난 용수철에 저장된 에너지는 늘리는 데 한 일과 같다.

### A2. (수학)
The value of the integral of a continuous function over a closed interval can be estimated by the sum of the areas of the rectangles inscribed under the curve. As the width of the rectangles decreases, the estimate approaches the true value of the integral. This limiting process defines the definite integral. The connection between integration and differentiation is stated in the Fundamental Theorem of Calculus.

- **수식어 묶기:**
  - S1: ( `of the integral` ) ( `of a continuous function` ) ( `over a closed interval` ) → value를 꾸밈, ( `inscribed under the curve` ) → rectangles를 꾸밈
  - S2: ( `of the rectangles` ) → width를 꾸밈
  - S4: ( `between integration and differentiation` ) → connection를 꾸밈
- **topic sentence:** S1 (적분의 근사)
- **단락 요약 (3줄):** 닫힌구간 위 연속함수의 적분값은 곡선 아래 내접 직사각형 넓이의 합으로 추정한다. 직사각형 폭이 좁아질수록 추정값은 참값에 가까워지며, 이 극한 과정이 정적분을 정의한다. 적분과 미분의 연결은 미적분의 기본 정리에 담겨 있다.

### A3. (화학)
The energy released when a chemical bond is broken is equal to the energy required to form the same bond. In a reaction, the total energy change depends on the difference between the energy needed to break the bonds in the reactants and the energy released when new bonds form in the products. A reaction that releases energy overall is called exothermic, while one that absorbs energy is called endothermic.

- **수식어 묶기:**
  - S1: ( `released when a chemical bond is broken` ) → energy를 꾸밈, ( `required to form the same bond` ) → energy를 꾸밈
  - S2: ( `needed to break the bonds in the reactants` ) → energy를 꾸밈, ( `released when new bonds form in the products` ) → energy를 꾸밈
  - S3: [ `that releases energy overall` ] → reaction를 꾸밈, [ `that absorbs energy` ] → one를 꾸밈
- **topic sentence:** S1 (결합 에너지의 대칭성)
- **단락 요약 (2줄):** 결합을 끊을 때 필요한 에너지와 같은 결합을 만들 때 방출되는 에너지는 같다. 반응의 총 에너지 변화는 반응물 결합을 끊는 에너지와 생성물 결합이 생기며 방출되는 에너지의 차이로 결정되며, 전체적으로 방출하면 발열, 흡수하면 흡열 반응이다.

### A4. (생물)
The neurons transmitting signals from the brain to the muscles release chemicals called neurotransmitters at the junction between two cells. The neurotransmitters diffuse across the narrow gap between the cells and bind to receptors on the surface of the next cell. This binding triggers a new electrical signal in the receiving cell. The entire process allows rapid communication between the nervous system and the muscles.

- **수식어 묶기:**
  - S1: ( `transmitting signals from the brain to the muscles` ) → neurons를 꾸밈, ( `called neurotransmitters` ) → chemicals를 꾸밈, ( `at the junction between two cells` ) → 장소
  - S2: ( `across the narrow gap between the cells` ) → 이동 경로, ( `on the surface of the next cell` ) → receptors를 꾸밈
  - S3: ( `in the receiving cell` ) → signal를 꾸밈
- **topic sentence:** S1 (신경전달물질 방출)
- **단락 요약 (2줄):** 뇌에서 근육으로 신호를 보내는 뉴런은 두 세포 사이 접합부에서 신경전달물질을 방출한다. 이 물질은 좁은 틈을 확산해 다음 세포 표면의 수용체에 결합하고, 이 결합이 새 전기 신호를 일으켜 신경계와 근육 사이의 빠른 소통을 가능하게 한다.

### A5. (수학)
The slope of the tangent line drawn to a curve at a given point is equal to the value of the derivative of the function at that point. The tangent line, which touches the curve at exactly one point, provides the best linear approximation of the curve near that point. As the point moves along the curve, the slope of the tangent line changes, and the derivative function describes this change.

- **수식어 묶기:**
  - S1: ( `drawn to a curve at a given point` ) → tangent line를 꾸밈, ( `of the derivative` ) ( `of the function` ) ( `at that point` ) → value를 꾸밈
  - S2: [ `which touches the curve at exactly one point` ] → tangent line를 꾸밈, ( `of the curve near that point` ) → approximation를 꾸밈
  - S3: ( `of the tangent line` ) → slope를 꾸밈
- **topic sentence:** S1 (접선 기울기 = 도함수)
- **단락 요약 (2줄):** 곡선 위 한 점에 그은 접선의 기울기는 그 점에서의 도함수 값과 같다. 접선은 그 점 근처에서 곡선의 최선의 선형 근사이며, 점이 곡선을 따라 움직이면 접선 기울기가 변하고 도함수가 이 변화를 나타낸다.
