# STRATEGY — 학습·연구 전략 (뇌과학 기반)

> **내 뇌:** 깊이 검토는 강점, 빠른 처리는 약점.
> **전략 한 줄:** *깊이는 아낌없이, 속도는 설계로.*

---

## 1. 뇌과학 근거 — 이 전략이 왜 효과적인가

| 뇌 메커니즘 | 뜻 | 여기서 쓰는 전략 |
|---|---|---|
| **수초화 (Myelin)** | 같은 경로를 반복하면 신경섬유가 수초로 감싸져 신호 전달이 빨라진다 | §3 복습, §5 속도 드릴 |
| **자동화** | 반복된 기술은 전두엽(느림) → 기저핵·소뇌(빠름)로 이동해 "생각 없이" 실행된다 | §5 체크리스트·템플릿 |
| **청킹 (Chunking)** | 작업기억은 한 번에 약 4덩어리. 덩어리로 묶으면 같은 용량으로 훨씬 많이 처리 | §3 지도·스키마·공식집 |
| **인지부하 (Cognitive Load)** | 잡음·멀티태스킹 같은 외부 부하가 처리 용량을 빼앗는다 | §5 외부화·단일 작업 |
| **DMN 과활성** | 오버씽킹 = 멍때리는 뇌 네트워크(DMN)가 일하는 뇌를 점거한 상태 | §2 3질문, §4 의문 메모 |
| **속도-정확 트레이드오프** | "결론을 얼마나 빨리 내릴지"는 뇌가 조절하는 기준값. 연습으로 조정 가능 | §5 정확도 하한 있는 드릴 |
| **수면·유산소 운동** | 수면은 시냅스 정리로 처리 효율 회복, 운동은 백질 개선으로 전달 속도 ↑ | §5 몸 관리 |
| **인출 연습 (Retrieval)** | 꺼내 쓰는 연습이 저장을 강화하고 다음 인출을 빠르게 만든다 | §3 복습(즉답) |
| **프라이밍 (Priming)** | 미리 본 정보는 처리 문턱이 낮아져 더 빨리 처리된다 | §3 준비(예습·지도) |

> **요점:** 처리속도는 "의지로 빠르게"가 아니라, **뇌가 적게 처리하고 더 자동화하도록 만드는 구조**(덩어리화·자동화·부하 제거)와 **신호 전달 자체를 빠르게 하는 반복**(수초화)에서 나온다. 이 문서는 그 둘만 다룬다.

## 2. 깊이 배분 — "언제 깊이, 언제 충분" (DMN 스위치)

| 작업 유형 | 깊이 | 근거 | 방법 |
|---|---|---|---|
| 문제 풀이 · 증명 · 연구 질문 | **최대** | 깊이 검토가 강점 | 시간 블록을 정하고 깊이를 쏟는다 |
| 읽기 · 이해 · 압축 | 중간 | 부하 분산 | 훑기(속도) → 정독(깊이) 2패스 |
| 계산 · 정리 · 형식 · 반복 | **최소** | 부하 낭비 | 도구 · 템플릿 · 체크리스트 |

**시작 전 3질문 (오버씽킹 스위치):**

1. 지금 완벽해야 하나?
2. 나중에 고칠 수 있나?
3. 대충하면 치명적인가?

> **예제 1 (수학 문제):** 식 세우기 단계 — "지금 완벽해야 하나? → 예(개념 검증이 목적)" → 깊이 100%, 경계조건·정의역까지 검토한다. 계산 단계 — "대충하면 치명적인가? → 아니오(검토로 고칠 수 있음)" → 깊이 최소, 종이에 쓰고 단순 계산은 바로 넘긴다.
> **예제 2 (이메일):** "고칠 수 있나? → 예" → 결론 문장부터 치고, 다듬기는 보내기 전 한 번만.

## 3. 학습 파이프라인 — 준비 → 입력 → 압축 → 복습

### ① 준비 (프라이밍) — 10분

- **근거:** 미리 본 정보는 처리 문턱이 낮아진다. 실시간에 "처음 보는 것"을 없애면 처리속도 부담이 급감한다.
- **실행:** 목차·인덱스로 지도 먼저. 공식·용어를 훑는다.
- **예제:** "물리 12장(운동량) 세션 전 10분: 목차에서 '운동량·충격량·충돌' 3항목을 찾아 제목만 읽고 들어간다. 세션 중 처음 보는 개념이 0개가 되게."

### ② 입력 (훑기 = 속도 패스) — 시간의 20%

- **근거:** 처음부터 정독하면 전두엽이 모든 문장을 깊이 처리해 느려진다. 첫 패스는 구조만.
- **실행:** 밑줄 없이 훑기. "이 단락이 대충 뭘 말하는가"만.
- **예제:** "영어 원서 단락 1개를 2분 안에 훑는다. 밑줄 금지. 끝나고 '이건 ~에 대한 정의다' 한 줄만 적는다."

### ③ 압축 (깊이 패스 ★강점) — 시간의 50%

- **근거:** 깊이 검토가 강점으로 작용하는 자리. 압축(골격 뽑기)은 청킹을 강화해 다음 인출도 빠르게 만든다.
- **실행:** 2~3줄 요약·골격. 정의·공식·조건만 뽑기. **이때만 깊이 100%.**
- **예제:** "그 단락을 2~3줄로: '충격량 = 힘 × 시간 = 운동량 변화. 짧은 시간 큰 힘과 긴 시간 작은 힘이 같은 충격량을 준다.' — 예외(완전탄성충돌)까지 메모."

### ④ 복습 (인출 = 속도를 '저장'으로) — 매일 5분

- **근거:** 인출 연습은 저장을 강화하고 다음 인출을 빠르게 만든다. **아는 내용은 처리속도와 무관해진다.**
- **실행:** 플래시카드·즉답. 3초 안에 못 떠올리면 재학습.
- **예제:** "다음 날 아침 3분: '충격량이 뭐였지?' → 종이에 한 줄 쓰고 답과 대조. 즉답이 안 되면 카드를 다시 학습."

## 4. 연구 파이프라인 — 질문 → 수집 → 초안 → 검증 → 전달

### ① 질문 1문장 (오버씽킹 방지)

- **근거:** 질문이 넓으면 DMN이 무한 검토를 시작한다. 질문을 한 문장으로 못 박으면 출구가 없다.
- **예제:** ❌ "A와 B에 대해 조사하자" (넓음 → 무한 검토) → ✅ "왜 A 방법이 B보다 느린가?" (좁음 · 가설 가능)

### ② 빠른 수집 (수집과 판단 분리)

- **근거:** 수집하면서 평가하면 자료마다 깊이 검토가 발동한다. 수집은 순수 입력이어야 한다.
- **실행:** 타이머 10분, 모으기만. 평가 금지.
- **예제:** "관련 자료 5개를 10분 안에 링크·페이지로 모은다. '이거 쓸 만한가' 판단은 다음 단계에서."

### ③ 초안 (버전 0)

- **근거:** 완성형을 요구하면 전두엽이 막힌다. 버전 0은 "만들기 모드" — 떠오르는 대로.
- **실행:** 10분, 수정 금지, 순서 무시.
- **예제:** "가설 → 근거 2개 → 숫자 → 결론 순서를 무시하고, 떠오르는 대로 10분 동안 쓴다."

### ④ 검증 (깊이 패스 ★강점) — 별도 패스

- **근거:** 정확성·예외 검토가 강점인 자리. 초안이 있으니 '고치기'만 하면 된다.
- **실행:** 각 주장의 출처·숫자·예외 확인.
- **예제:** "A가 느린 이유를 '캐시 미스'라고 썼다면 → 실측 데이터와 대조, 캐시 미스율 수치 확인, 예외(데이터가 작을 때) 메모."

### ⑤ 전달 (결론 먼저)

- **근거:** 상대는 내 검토 과정을 못 본다. 결론 한 줄이 부담을 없앤다.
- **예제:** "한 줄: 'A가 느린 이유는 캐시 미스다.' → 근거 2개 → 상대가 물으면 그때 깊이."

## 5. 매일 운영 규칙

| 규칙 | 뇌과학 근거 | 실행 · 예제 |
|---|---|---|
| **데드라인** | 마감이 없으면 DMN이 무한 검토 | 세션 문제당 5분. 초과 = 답 보기. 예: "3번 문제 5분 초과 → 답 본다" |
| **초안 먼저** | 완성형 압박이 처리속도를 죽임 | 버전 0을 3분 안에. 검토는 별도 패스. 예: "풀이도 답부터 적고 정리한다" |
| **외부화** | 작업기억(약 4덩어리)이 병목 | 머릿속 3줄 = 필기. 계산은 종이·도구로. 예: "머릿속 적분 3줄째 → 종이에" |
| **자동화** | 자동화된 기술은 생각 없이 실행 | 두 번 이상 같은 고민 = 템플릿·체크리스트. 예: "단위 변환 체크리스트, 풀이 절차 템플릿" |
| **속도 드릴** | 수초화 + 트레이드오프 조정 | 매일 5분, 쉬운 문제를 타이머로, 정답률 80% 하한. 예: "5분에 20문제 암산" |
| **하루 1개 대충** | 트레이드오프 기준을 '충분'으로 이동 | 의도적으로 대충하는 작업 하나. 예: "메모 1개를 2분 안에 어설프게" |
| **몸 관리** | 수면·운동이 처리속도에 직결 | 취침 시간 고정 + 주 3회 유산소 30분. 예: "시험 전날 1시간 더 자기" |

## 6. 위기 상황 (시간 압박 시)

1. **쉬운 것 먼저** — 점수부터 확보. 처리속도가 낮을수록 순서 전략이 실력을 결정한다.
2. **문제당 예산:** 남은 시간 ÷ 남은 문제. 초과 = 즉시 스킵.
3. **3분 규칙:** 접근(무엇을 구하는 문제인지)이 안 보이면 버린다.
4. **초안 빠르게, 검토로 정확성:** 남은 시간은 전부 검토에 쓴다.

> **예제 (100분·20문제):** 문제당 5분. 배점 큰 것부터. 5분 넘는 순간 표시만 하고 넘어간다 → 남은 20분은 전부 검토. "느리고 정확한" 뇌는 검토 단계에서 제 역할을 한다.

- [ ] 가장 중요한 작업 1개: 미니 데드라인 + 버전 0

> **마지막 한 줄:** 처리속도는 "빨리 하려는 의지"가 아니라 **뇌가 덜 처리하고 더 자동화하도록 만드는 설계**에서 나온다. 깊이는 강점인 곳에만, 나머지는 구조로.
